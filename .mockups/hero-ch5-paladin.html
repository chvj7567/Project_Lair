4. 전투 미니 프리뷰 — 정면 교전 + 디버프 정화 + 스킬 3종

금색 점선 = 공격 사거리 1.6 · 청백 실선 = 성역 반경 2.6. 보라 몬스터(디버퍼)가 근접하면 영웅 머리 위에 디버프 점(보라)이 쌓이고, 3개가 되면 정화의 빛이 전부 지운다. 고유 패시브로 디버프 지속이 ×0.6 이라 쌓여도 금방 빠진다 — 디버프 빌드의 효율이 떨어지는 것을 눈으로 보는 프리뷰. 몬스터는 데모 블록(청회 탱커 6HP / 붉은 근접 3 / 보라 디버퍼 2 / 연두 스웜 1)이며 실제 몬스터 시안이 아니다.

7. 핵심 결정 요약

  • 같은 "해골" 세계관: 뼈 색 · 형광 눈 · 검은 외곽선 유지. 정체성은 몸 앞을 가리는 큰 연 방패 + 한 손 철퇴 + 날개 투구 + 십자 휘장 + 바닥까지 끌리는 망토. 다섯 직업 중 유일하게 방패를 든다.
  • 공격 = slash01 9프레임 15fps(0.600s): F0 철퇴 들기 → F1~F2 머리 위로 크게 감기 → F3 앞으로 내려찍기 = strike → F4 성광 충격 링(연출) → F5~F7 복귀 → F8 = 대기 F0. 방패는 공격 내내 앞을 가린다.
  • 5단계: 머리(사슬 두건 → 코가드 투구 + 깃털 → 통투구 + 작은 날개 → 큰 날개 투구 + 후광 → 날개 왕관 + 큰 후광) · 방패(둥근 목방패 → 연 방패 → 문장 발광 → 대형 → 태양 문장 거대 방패) · 철퇴(곤봉 → 날 철퇴 → 발광 → 대형 → 성광 전쟁망치) · 망토(짧음 → 긴 망토 → 털 깃 → 이중 → 날개 망토).
  • 5단계 규약은 기존과 같다: 외곽선 베이크(5-2 #F8FAFC · 5-4 팔레트별 · 5-5 #FDE047), 발광(5-3~5-5), 5-5 만 루트 스케일 1.30.
