규칙 짙은 안개최고 2:51.3
  • 세그먼트 — 칸마다 도트 아이콘(방패 · 쌍검 · 해골)과 배율 한 줄. 선택 칸은 난이도색(Easy 소울 · Normal 금 · Hard 적)으로 채워지고 빛 + 아래 꼬리 표시가 붙는다.
  • 잠금 칸 — 빗금 바탕 + 자물쇠 아이콘으로 "잠김"이 한눈에 보이고, 눌러도 선택은 안 되지만 살짝 흔들리며 안내 카드가 내려온다(지금은 회색 칸 + 무반응에 가까운 토스트).
  • 효과 줄 — "영웅 HP ×1.15 · 공격력 ×1.1" 문장 대신 HP / ATK 칩(▲ 증가 표시, 난이도색). Easy 는 기준값(–)으로 회색.
  • 헤더 — 좌측 "난이도", 우측 "최고 Normal" (이 스테이지 최고 난이도 기록이 있을 때만, 난이도색).
  • 잠금 안내 카드 — 자물쇠 + "Normal 잠김" + "Easy 클리어 시 해금" + 진행 점 3칸(클리어한 난이도는 초록, 다음 목표는 금 줄무늬) + 아래로 줄어드는 2.4초 타이머 바. 기존 한 줄 문구 id 1331 은 그대로 쓰고 제목 문구 1줄만 추가한다("{0} 잠김").
  • 구현 범위(승인 시): WorldMapDifficultySegmentView 프리팹 개편(아이콘·배율 라벨·잠금 표시, 위젯은 private 유지) + 효과 칩 2개 + 잠금 카드 프리팹 1개(WorldMapPopup 안 정적 배치) + 도트 아이콘 스프라이트 4장(방패·쌍검·해골·자물쇠). 로직(해금 판정)은 변경 없음.
