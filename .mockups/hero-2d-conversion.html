5. 핵심 결정 요약

  • 스테이지 1 은 카드 일러스트(Fear/Bleed/TimeStop) 픽셀 해골을 그대로 기준형으로 채택 — 재디자인 없음.
  • 스테이지 2~5 는 색(hero-stage-variant.md §1.2 값 불변)뿐 아니라 머리장식·무기·의복 3모티프 escalation으로 실루엣부터 분화한다(캡→후드→반투구→풀헬름→왕관, 소검→장검→양손검→대검, 헝겊→튜닉→영묘망토→정예망토→화염망토).
  • Spawn·Slash01·Slash02·Stab 4클립은 기존 3D 클립과 동일 실시간 초(1.333s·1.133s·1.133s·1.633s)를 Animator State Speed 로 정확히 재현 — OnAttackStrike/OnAttackEnd/OnSpawnAnimEnd 이벤트 시점·게임플레이 타이밍 계약 완전 불변.
  • 스테이지 파츠는 몬스터 2D 가 이미 구현한 `MonsterTierOverlay` 를 그대로 재사용 — 오버레이는 별도 Animator 없이 몸 스프라이트 이름(프레임 인덱스)을 매 프레임 미러링만 한다(신규 동기화 코드 0). 영웅은 티어가 4개(S2~S5)라 `_tier4Frames` 분기만 additive 로 확장한다.
  • 스테이지 5 만 기존 승인값대로 루트 스케일 1.4배 — 몬스터와 달리 "몸 스케일업 금지" 제약을 적용하지 않는다(여러 스테이지가 동시에 화면에 섞일 일이 없어 픽셀 밀도 불일치 문제 자체가 없음).
  • 전투 판정·타이밍·스탯 배수 불변: 공격 개시→strike→회복 흐름, 스폰 게이트, 피격 억제, HP/Power 배수 모두 기존 hero-animation-timing-sync.md/hero-stage-variant.md 계약 그대로.
