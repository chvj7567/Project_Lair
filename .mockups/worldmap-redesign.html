침입 지도 팝업(WorldMapPopup) 리디자인 시안

기존(상단 가로 탭 + 좌 지도 / 우 상세)을 3단 구성: 좌 챕터 카드 레일 / 중앙 풍경 지도 / 우 상세 카드로 재배치했습니다. 기능·데이터(WorldMapViewModel)는 그대로이고 표시 방식만 바뀝니다. 아래 바에서 진행도·게이트를 바꿔 상태별 모습을 확인하세요.
  1. 챕터 탭 → 세로 카드 레일 - 큰 챕터 번호 + 챕터명 + 영웅 직업 + 진행 칩 5칸신규 표시. 잠금/준비 중은 어둡게, 4·5장은 "???" 카드(정보 비노출). 지도 위쪽 제목 줄이 없어져 지도가 커집니다.
  2. 지도 = 챕터 풍경 + 굽이치는 길 - 챕터 색조(1장 청회색 / 2장 녹색 / 3장 보라)로 배경 분위기를 바꾸고, 노드를 지그재그 경로로 배치. 클리어 구간은 금색 실선, 미개척 구간은 점선. 선택 노드는 금색 테두리 + 회전 점선 프레임 + ▼ 마커. 보스는 더 크고 적갈색.
  3. 상세 = 카드형 - 상단 초상 배너(챕터색 그라데이션) 위에 스테이지 번호·이름·별, 그 아래 내 기록, 규칙, 보스 페이즈(적색 띠)를 흐름 배치. 기존 규칙 문구 그대로.
  4. 하단 바 - 안내 문구는 좌측, "이 스테이지로 선택" 버튼은 우측 상세 열 폭에 정렬(시선이 상세 → 버튼으로 이어짐).
  5. 동작 변경 없음 - 잠금 탭/노드 클릭 시 토스트, dim/X 닫기, 선택 확정 후 닫기 모두 동일. 신규 문구 0건(진행 칩은 문구 없는 도형). 진행 칩 값은 ClearedStage 로 계산 가능해 VM 에 챕터별 클리어 수 getter 만 추가하면 됩니다.

규격: 1280x720, 팝업 패널 (72,40) 1136x640, 배경 dim a0.55. 영역: 헤더 64 / 레일 (88,120) 200x472 / 지도 (304,120) 520x472 / 상세 (840,120) 352x472 / 하단 바 y=608.
Unity 매핑(기존 필드 유지): 챕터 카드 ← _tabs[5](WorldMapChapterTabView, 번호·영웅·칩 위젯 추가) · 노드 ← _nodes[5](위치만 재배치, 연결선은 정적 이미지 5조각) · 제목/테마 ← _chapterTitleText/_chapterThemeText(지도 좌상단 오버레이) · 상세 ← 기존 _detail* 그대로 · 버튼 ← _selectButton. 신규 위젯: 진행 칩(카드당 5 Image), 지도 배경 Image(챕터 색조 틴트).
