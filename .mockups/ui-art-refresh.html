0. 화면별 GPT 시안 (도감 S0 화풍, 16:9, 글자 없음) - 3판 기준

기획서 3판(화면 단위 전용 고해상도 GPT 세트)의 화면별 시안입니다. 화풍 기준은 도감 S0와 마을 HUD 시안이며, 모두 gpt-6-sol로 만들었습니다. 이 시안은 화풍과 배치를 확인하는 용도이고, 실제 스프라이트는 승인 후 요소 시트로 따로 만듭니다. 월드맵 일러스트, 카드 그림, 유물·몬스터·영웅 그림은 범위 밖이라 시안에서도 자리만 표시했습니다. 레이아웃 참고 표시가 없는 화면은 프리팹 구조를 글로 설명해 그린 것이라 실제 배치와 다를 수 있습니다.
아래 1~5절은 1판(폐기) 자료입니다. 같은 파일명으로 제자리 교체하던 계획의 구조 확인용이며, 기록으로만 남겨 둡니다.
실제 시안은 아직 생성 전입니다. 현재 모드는 지금 화면의 구조·색을 CSS 로 재현한 것이고, 시안(자리) 모드는 기획서 §4 의 새 화풍 기준(면 3톤 + 위·왼쪽 밝은 베벨 + 금 3톤)을 CSS 로 근사해 어디가 교체되는지 점선 칸(스프라이트 파일명)으로 보여 줍니다. 최종 그림은 GPT 생성물이며 이 CSS 와 다릅니다. 현재 실제 PNG 를 나란히 보려면 Phase 0 에서 복사한 이미지를 .mockups/assets/ui/<파일명>.png 에 두세요(없으면 CSS 재현만 보임).
교체 원칙: 같은 파일명 · 같은 GUID · 같은 크기/9-slice/PPU - 프리팹·코드 변경 없음
