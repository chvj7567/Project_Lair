공통 UI 아트 교체 - 변경 전/후 비교 (구조 확인용)

실제 시안은 아직 생성 전입니다. 현재 모드는 지금 화면의 구조·색을 CSS 로 재현한 것이고, 시안(자리) 모드는 기획서 §4 의 새 화풍 기준(면 3톤 + 위·왼쪽 밝은 베벨 + 금 3톤)을 CSS 로 근사해 어디가 교체되는지 점선 칸(스프라이트 파일명)으로 보여 줍니다. 최종 그림은 GPT 생성물이며 이 CSS 와 다릅니다. 현재 실제 PNG 를 나란히 보려면 Phase 0 에서 복사한 이미지를 .mockups/assets/ui/<파일명>.png 에 두세요(없으면 CSS 재현만 보임).
