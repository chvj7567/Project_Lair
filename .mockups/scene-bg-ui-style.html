로딩·마을·배틀 배경 — UI풍 시안

UI 리디자인 팔레트(석재 stone0~4 · 금 gold · 소울그린 soul)를 배경에 적용. 도트 캔버스 + 발광/먼지 애니메이션. 승인 후 PNG 시트로 추출해 교체.

① 배틀 배경 (1600×704, 도트 2배 확대)

  • 투기장 림 — 평평한 회색 테두리 → 금 인레이 라인 + 12개 금 리벳 + 두께감 있는 측면 석벽
  • 바닥 — 동심원 벽돌 유지, 중심으로 갈수록 소울그린 은은한 반사광(제단 빛)
  • 룬 링 — 중간 링에 소울그린 점선 룬이 천천히 맥동 · 중앙 제단 링은 소울 발광
  • 상단 벽 — 금 코니스 + 기둥 4개에 소울 횃불(깜빡임)
  • 분위기 — 비네트(가장자리 암전) + 떠오르는 소울 먼지. HUD 가독성 위해 가장자리·상단은 어둡게 유지
  • 6개 스포너 제단 자리는 어두운 금 링만 표시(제단 본체·색 수정은 기존 스프라이트 그대로)

② 로딩 배경 (640×270, 도트 2배 확대)

LAIRPROJECT LAIR
던전 준비 중0%
TIP · 영웅 HP 10%마다 패시브 카드를 고를 수 있습니다
  • 신전 — 페디먼트·기둥 상단에 금 장식선, 문 안쪽 소울그린 빛이 새어나오며 맥동
  • 바닥 마법진 — 소울그린 이중 링이 천천히 회전하는 듯 밝기 이동 + 바닥 반사광
  • 하늘/숲 — 청록 어둠 그라데이션 + 별 반짝임 + 반딧불(소울 먼지)
  • 로딩 바는 UI와 같은 금테 유리 패널 + 소울 게이지(실제 UI 프리팹이 아닌 시안 표현)

③ 마을 배경 (640×270, 도트 2배 확대)

  • 옥좌의 방 — 석벽 하단에 금 웨인스코트 레일, 배너 6장에 금 술, 천장 사슬 유지
  • 옥좌 — 보라 장막 + 금 왕관 + 뒤편 소울그린 후광이 맥동 (영주 레벨 상징)
  • 카펫 — 붉은 카펫에 금 테두리 + 금 문양, 바닥 석판은 원근 + 반사광
  • 소품 — 포션 선반 병들이 소울그린/금으로 발광, 가마솥 기포, 서고·게시판·금고 대에 은은한 림라이트
  • 분위기 — 벽 횃불 따뜻한 금빛 + 소울 먼지, 비네트. 마을 HUD(상점·영주성 아이콘) 자리는 아래쪽 어둡게 비워 둠
