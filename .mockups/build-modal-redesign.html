  1. 모달 패널 - 금테 이중 프레임 + 모서리 장식 4곳 + 상단 유리 광택 + 어두운 내측 비네트. 뒤 dim(#000 α0.6)은 그대로, 클릭 시 닫힘 동작 유지.
  2. 헤더 - 타이틀 플레이트(320x52)는 금테 이중 프레임 + 양끝 마름모 보석 + 금빛 글로우 글자. 닫기 X는 붉은 입체 버튼(눌림 2px, 호버 밝아짐).
  3. 섹션 헤더 - 종류색 마름모(패시브 녹색 / 액티브 금색) + 라벨 + 금색 페이드 구분선, 오른쪽에 N/9 · N/5 칩(종류색 발광 테두리). 섹션 배경은 어두운 유리 inset, 가운데 세로 구분선은 금색 그라데이션.
  4. 카드 셀 - 좌측 종류색 띠 + 일러스트 프레임(52x52, 종류색 테두리 + 안쪽/바깥 발광 + 모서리 보석), 이름은 뼈색 글자, 효과 문구는 유리 inset 박스(2줄 말줄임).
  5. 중복 배지(×N) - 금테 + 어두운 유리 배지 + 금빛 글로우 글자, 2개 이상일 때만 표시. 위치(우상단)·크기 동일.
  6. 스크롤 영역 - 금색 슬림 스크롤바(6px, 트랙 흑색 + 금 그라데이션 썸). 내용이 넘칠 때만 활성, 휠/썸 드래그 가능. 빈 상태는 마름모 장식 + 기존 문구.
  7. 구현 메모 - Image 스프라이트(그라데이션·프레임·보석)와 Outline/Shadow 재사용, Rule 03 §3 BuildModalPopup/PoolingScrollView/Cell 3종 구조 유지. 셀은 80px 피치 안에서 본체를 상하 2px 안쪽으로 그려 셀 사이가 2+2px 틈새로 보임(좌표 불변). 스크롤바는 섹션 우측 바깥 2px 여유(x+284)에 배치.
