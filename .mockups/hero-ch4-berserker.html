챕터 4 광전사(Berserker) 5단계 외형 - 방향 시안

기획서 docs/design/chapter-4.md §3.5. 이 시안은 방향 합의용 단순 부위 조합이다(기사/궁수/암살자 시안의 9행 시트 리그를 그대로 재사용하지 않음). 시트 베이크·클립(slash01 9프레임)·실루엣 실측 R2'/R3' 은 승인 후 별도 작업이다. 팔레트 토글(A/B)과 색상각 표는 hex 에서 직접 계산한다.

5단계 외형 (4-1 ~ 4-5)

  • 배경 줄: 4장 배경(scene-bg-ch4-ember.html)의 엠버 톤을 깐 셀. 4-5 발광(#FF6A3D)이 배경 발광과 같은 계열이라 묻히는지 여기서 확인한다 (금 림과 흑철 몸이 윤곽을 잡는지)
  • 무기: 단계마다 날 크기 4.4 / 5.6 / 6.6 / 8.0 / 10.5 (기획서 표). 2단계부터 양날, 3단계부터 날 발광, 5단계에 금 날밑
  • 5단계 루트 스케일 1.35 (기획서 D-C4-7), 바닥 용암 오라
  • "범위 베기 연출" 버튼: 영웅 중심 반경 2.2 의 베기 원이 0.6초 클립 주기(strike 0.2초)로 번쩍임

색상각 실측 (기존 영웅 점유 색상각과의 최소 이격)

기존 유채색 점유 각도(기획서 기록값): 기사 0 / 142 / 199 / 271, 궁수 36.4 / 37.7 / 82.7 / 328.6, 암살자 171.2 / 238.7 / 300. 채도 0.15 미만은 무채색으로 판정 제외. 25° 이상이면 충족(기사·궁수·암살자 선례 규약).
