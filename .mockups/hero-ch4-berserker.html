0. 사용자 선택 — 광전사 팔레트 2안 (아래 모든 화면이 선택안으로 바뀐다)

판정은 각 단계 대표색(chip)·발광색의 색상각(hue). 초록(ok) = 31° 이상, 주황(warn) = 25° 이상 31° 미만, 빨강(ng) = 25° 미만. 무채색은 판정 제외. 비교 대상 = 기획서 §3.5 의 기존 영웅 점유 색상각 11개(기사 0°·142°·199°·271° / 궁수 36.4°·37.7°·82.7°·328.6° / 암살자 171.2°·238.7°·300°). 발광색은 면적이 작아 판정을 완화한다(참고 표기).

4. 전투 미니 프리뷰 — 군집 돌진 + 범위 베기 + 스킬 3종

금색 점선 = 공격 사거리 1.8 · 주홍 실선 = 범위 베기 반경 2.2(최대 4마리) · 푸른 점선 = 사냥 반경 10.0. 몬스터 위 주홍 마름모 = 현재 목표(그 몬스터 중심 반경 2.2 안 몬스터 수 = clusterScore 최대). 1.0초마다 재평가해 현재 군집보다 2마리 이상 큰 군집이 생기면 갈아탄다. 자동 시전 우선순위: 사슬 갈고리(반경 5.0 안 4마리 이상) > 피의 광란(반경 2.2 안 3마리 이상) > 분쇄 도약(군집 무게중심이 3.0~8.0 거리). 몬스터는 데모 블록(청회 탱커 6HP / 붉은 근접 3 / 보라 빠른 2 / 연두 스웜 1)이며 실제 몬스터 시안이 아니다. 수치는 연출 확인용 단순 모델이라 참고만, 판정은 qa-simulator G8.

7. 핵심 결정 요약

  • 같은 "해골" 세계관: 뼈 색 · 형광 눈(4-1·4-2 는 기존 영웅과 같은 초록, 4-3~4-5 는 단계 발광색) · 검은 외곽선 유지. 정체성은 양손 양날 도끼(가로로 가장 넓은 실루엣) + 쌍뿔 투구 + 두꺼운 견갑 + 모피 망토 + 사슬. 네 직업 중 몸통이 가장 두껍다.
  • 공격 = slash01 행 9프레임 15fps(0.600s): F0~F2 도끼를 어깨 뒤로 감아 웅크림 → F3 앞으로 휘두름 = strike(0.200s) → F4~F6 회전 궤적(연출) → F7~F8 복귀(F8 = 대기 F0 와 같은 포즈라 이음새 없음). slash02 · stab 행은 slash01 복제(D-C4-6).
  • 이동 = walk(0.8s 루프)·run(0.571s 루프). 분쇄 도약 · 사슬 갈고리는 run 클립 + FX 로 표현(별도 클립 없음).
  • 5단계 규약은 기존 영웅과 같다: 외곽선 베이크(4-2 #F8FAFC · 4-4 #FDBA74 · 4-5 #FDE047), 발광(4-3~4-5), 4-5 만 루트 스케일 1.35.
  • 단계별 파츠: 머리(상투 + 가죽 머리띠 → 철 투구 + 코가드 → 짧은 쌍뿔 → 긴 뿔 → 3쌍 왕관 뿔 + 금 띠) · 견갑(없음 → 앞 1 → 양쪽 → 가시 → 거대 겹) · 도끼(손도끼 → 양날 → 발광 양날 → 대형 → 초대형 흑철 + 금) · 망토(없음 → 모피 → 큰 모피 → 모피 + 등 사슬 → 사슬 망토 + 흑모피).
