현재 사용자 에디터 배치(좌상단 메뉴 / 우상단 전적 / 우하단 침입자 카드 / 하단 중앙 영웅·방어하기, 홀로그램 영웅 중앙 노출)는 좌표 그대로 두고, 침입 지도 v2 와 같은 톤(금색 포인트 + 입체 그라데이션 + 은은한 글로우)으로 통일했습니다. 기능·문구·VM 불변.
  1. 상단바 - 그라데이션 + 하단 금색 라인. 영주 아바타는 금테 메달리온, 경험치 바는 금빛 광택 게이지, 소울은 녹색 테두리 칩, 계정 버튼 빨간 점은 맥동.
  2. 메뉴 타일 6종 - 입체 그라데이션 버튼 + 아이콘 뒤 은은한 원형 후광, 호버 시 살짝 떠오름. (지도 버튼은 침입 지도 아이콘 사용 — 기존 영웅 아이콘 슬롯)
  3. 전적 패널 - 금테 이중 프레임 + 모서리 장식, 항목마다 금색 마름모 불릿, 항목 사이 금색 구분선.
  4. 침입자 카드 - 같은 프레임. STAGE 제목 글로우 + 위협도 ★ 발광, 5칸 점은 마름모 보석(선택 단계까지 금빛 발광). 현상수배서·◀▶ 화살표(금색 쉐브론 + 은은한 발광) 위치는 동일.
  5. 하단 CTA - 방어하기는 광택 + 붉은 글로우가 천천히 숨 쉬듯 맥동(잠금 시 무광 회색), 영웅 버튼은 일반 입체 버튼.
  6. 구현 메모 - Image 스프라이트(그라데이션·프레임·보석)와 Outline/Shadow, 단순 트윈(맥동)으로 구현 가능. 침입 지도 v2 에서 만든 프레임/그라데이션/모서리 스프라이트와 UILoopMotion 재사용. 레이아웃·문구·동작 변경 없음.
