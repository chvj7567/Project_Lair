배틀 HUD(BattleHud) 비주얼 리디자인 시안 — 현재 좌표 유지, 마감 업그레이드

현재 에디터 배치(상단 좌 타이머 / 상단 중앙 보스 HP / 상단 우 액티브 카운트다운 / 우측 시너지+빌드 / 하단 스포너 6셀)는 좌표·크기 그대로 두고, 마을 HUD·침입 지도와 같은 톤(금색 포인트 + 입체 그라데이션 + 은은한 글로우)으로 통일했습니다. 전투 가시성을 위해 패널은 반투명 유리 톤이며 중앙 원형 경기장은 가리지 않습니다. 기능·문구·VM 불변.
  1. 타이머 패널 - 금테 이중 프레임 + 모서리 장식 + 상단 유리 광택. 30초 이하가 되면 프레임·숫자가 붉게 맥동.
  2. 보스 HP 바 - 금테 이중 테두리 + 유리 광택 fill(상단 하이라이트 띠, 체력 30% 이하는 주황으로 전환) + 지연(Lag) 잔상 띠. 눈금은 마름모 보석, 해당 구간을 넘으면 금빛 발광. 상태 아이콘은 테두리 발광 슬롯.
  3. 액티브 카운트다운 - 타이머와 같은 프레임. 미니바는 금빛 광택 fill, 카드 등장 5초 전부터 금색 발광 맥동.
  4. 시너지 패널 - 행마다 축 색 띠 + 아이콘 + 색 발광 칩(활성 단계만큼 점등, 활성 행은 은은한 글로우), 비활성 행은 어둡게. 접힘 탭은 같은 프레임 + 색 점.
  5. 빌드 패널 - 유리 패널 + 금테 프레임, 슬롯은 종류색(패시브 녹색/액티브 금색) 테두리 + 발광, 빈 슬롯은 해칭 inset. 개수 배지는 금테 미니 라벨.
  6. 스포너 셀 6종 - 금 헤어라인 프레임 + 색 띠(발광) + 원형 아이콘 슬롯, Lv 배지는 금색 라벨, 진행바는 광택 fill. 위치·간격 동일.
  7. 구현 메모 - Image 스프라이트(그라데이션·프레임·보석)와 Outline/Shadow, UILoopMotion 맥동 재사용. 레이아웃·문구·동작 변경 없음. 단 보스 눈금 보석은 바 상단 경계선(y=40) 중심으로 정렬해 제목 글자와 겹침을 줄였고 시각 보정 외 좌표 변경 없음.
경과 시간100s 슬라이더를 움직여 타이머·카운트다운·보스 HP·스포너 진행을 확인
