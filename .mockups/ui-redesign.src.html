Art/UI 리디자인 시안: 도트 던전 스타일 (32종)

Assets/_Lair/Art/UI 의 프리팹 32종을 하나의 비주얼 언어로 다시 그린 시안입니다. 몬스터·카드·영웅 도트 에셋과 톤을 맞췄습니다. 계단형 픽셀 테두리, 석판 패널, 소울(청록)·금화(금)·저주(보라) 3색 강조를 쓰고, 한글은 도트 폰트 Galmuri11 로 표시했습니다.

프레임 1장은 16:9 (960×540) 기준입니다. 셀 프리팹은 실제 사용되는 화면 안에 넣고, 아래 트레이에서 상태별 단독 모습도 보여 줍니다. 텍스트 값은 샘플입니다.
