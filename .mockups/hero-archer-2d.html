4. 전투 미니 프리뷰 — 카이팅 루프 + 스킬 3종

금색 점선 = 사거리 6.0 · 붉은 점선 = 후퇴 진입 3.0 · 청색 점선 = 후퇴 해제 4.5(히스테리시스). 가장 가까운 몬스터가 3.0 안이면 위협 중심 반대로 뒷걸음(시선은 몬스터 쪽 고정 = 좌우 반전 없이 walk 클립 재생), 4.5 이상 + 0.4s 유지 후 사격 재개. 0.5s 동안 0.3 미만 이동하면 갇힘 → 후퇴 중단 + 사격 + 회피 도약. 몬스터(청회색 탱커 0.9 / 붉은 일반 1.5 / 보라 빠른 2.4)는 데모용 블록이며 실제 몬스터 시안이 아니다. 화면은 가독성을 위해 세로 12.8u·스프라이트 ×1.6 로 확대했다.

7. 핵심 결정 요약

  • 같은 "해골" 세계관: 뼈 색 · 형광 눈(2-1·2-2 는 기사와 같은 초록, 2-3~2-5 는 단계 발광색) · 검은 외곽선 유지. 기사의 "낮은 캡 + 대각 소검" 대신 뾰족 후드 + 세로 호 활 + 등 뒤 화살통이 정체성이다.
  • 사격 = stab 행 9프레임 15fps(0.600s): F0 화살 메김 → F1~F3 당김(F3 완전 당김) → F4 시위 놓음 = strike(0.267~0.333s) → F5~F8 여운·복귀(F8 = 대기 F0 와 같은 포즈라 이음새 없음). 총 0.6s 이내.
  • 후퇴 = walk(0.8s 루프)·run(0.571s 루프) 재사용, 몸을 뒤로 젖히고 활을 든 채 시선 고정. 좌우 반전 없음(왼쪽으로 걸으며 오른쪽을 본다).
  • 5단계 규약은 기사와 같다: 외곽선 베이크(2-2 #F8FAFC · 2-4 팔레트별 · 2-5 #FDE047), 발광(2-3~2-5), 2-5 만 루트 스케일 1.25(콜라이더 영향 없음 표기는 기획서 §5.6).
  • 단계별 파츠: 활(단궁 → 복합궁 → 장궁 → 대형 장궁 → 사슴뿔 활) · 화살통(2개 화살 → 5개 + 허리 통) · 두건(낡은 두건 → 뾰족 후드 → 깃털 후드 → 사슴뿔 → 사슴 두개골 투구) · 망토(없음 → 짧은 → 긴 → 더 긴 → 깃털 대망토).
