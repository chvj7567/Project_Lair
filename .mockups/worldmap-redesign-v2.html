침입 지도 팝업 비주얼 폴리시 v2 — 레이아웃 동일, 마감만 업그레이드

기존(상단 가로 탭 + 좌 지도 / 우 상세)을 3단 구성: 좌 챕터 카드 레일 / 중앙 풍경 지도 / 우 상세 카드로 재배치했습니다. 기능·데이터(WorldMapViewModel)는 그대로이고 표시 방식만 바뀝니다. 아래 바에서 진행도·게이트를 바꿔 상태별 모습을 확인하세요.
  1. 프레임 - 금색 이중 테두리 + 네 모서리 금색 장식 + 제목 글로우와 룬 라인. 헤더는 그라데이션.
  2. 챕터 카드 - 번호 배지에 입체 그라데이션, 진행 칩을 사선 보석(클리어 시 금빛 발광)으로, 선택 카드는 금색 글로우 + ▶ 포인터.
  3. 지도 - 챕터별 실루엣(1장 성벽, 2장 숲, 3장 성채 첨탑) + 달 + 흐르는 안개 + 비네트. 노드는 원형 메달리온(클리어는 금빛 + ★ 뱃지, 보스는 붉게 맥동), 길은 금색 발광 실선 / 점 점선, 노드 이름은 반투명 명패.
  4. 상세 - 초상 실루엣에 챕터색 발광, 이름 아래 금색 구분선, 규칙·페이즈는 그라데이션 띠, 섹션 라벨에 구분선.
  5. 버튼 - 광택 하이라이트 + 붉은 글로우 CTA. 잠금 시 무광 회색.
  6. 구현 메모 - 모두 Unity 에서 Image(그라데이션/실루엣 스프라이트)·Outline/Shadow 로 구현 가능. 안개 이동·보스 맥동·회전 프레임은 단순 트윈이며 부담되면 정적으로 대체 가능. 레이아웃·좌표·문구·동작은 v1 과 동일.
