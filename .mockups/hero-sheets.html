영웅 25종 전신 시트 - 전투 시안

직업 5 x 단계 5 의 새 일러스트 시트를 게임 규칙(타격 시각·크기 정규화)대로 재생해 보는 합의용 프리뷰입니다. 원본 시트는 서버의 읽기 전용 경로 /herosrc/ 에서 불러옵니다(복사본 없음). 기획서: docs/design/hero-sheets.md

1. 동작 미리보기 (게임 클립 시각표 그대로)

시트 전체 (6열 x 6행, 게임 행 순서가 아닌 원본 순서: Idle / Attack / Death / Spawn / Move / Hit)

행 -> 게임 상태: 1행 Idle, 2행 Attack(F3 = 타격 프레임), 3행 Death, 4행 Spawn, 5행 Move(걷기·달리기 공용), 6행 Hit.

2. 같은 직업 5단계 비교 (대기 F0, 높이 정규화)

단계마다 대기 그림의 높이를 그 직업 1단계의 월드 높이(1.00u)에 맞춥니다. 5단계는 현행과 같이 크기 배수(Knight x1.4 / Archer x1.25 / Assassin x1.2 / Berserker x1.35 / Paladin x1.3)가 곱해집니다. 아래 수치는 브라우저가 원본 이미지에서 직접 잰 값입니다(192 셀 환산).
