챕터 3 "그림자 성채" 탭 활성화 목업 (침입 지도 팝업 / WorldMapPopup)

기존 승인 목업 chapter-worldmap.html 과 레이아웃·톤·좌표 동일. 바뀌는 점은 3장 탭 개방과 3-1~3-5 노드·상세. 아래 항목에 승인/수정 의견을 주세요.
  1. 탭 구성 - 탭 5칸 유지: 1장 / 2장 / 3장 그림자 성채 개방, 4장·5장은 기존대로 "???" 자리표시자(정보 비노출). 탭 폭·간격 변경 없음.
  2. 3장 탭 상태 3종 - (a) 2장 보스 미클리어: "잠금" 보조 표기, 클릭 시 토스트 "3장은 2장 보스를 클리어하면 열립니다" (b) 해금: 정상 탭 (c) 출격 게이트 닫힘(현재 빌드): "준비 중" 표기. 아래 "출격 게이트" 토글로 (c)와 활성화 후를 비교할 수 있습니다. 이번 작업으로 (c)가 사라집니다(승격 범위 확인 필요).
  3. 노드 표기 - 2장과 동일 규약: 잠금 / 해금 / 클리어(황동 + 클리어 태그) / 선택(금색 외곽 + ▼) / 3-5 보스(96px, 적갈색, BOSS 태그). 노드 배치 좌표 변경 없음.
  4. 영웅 초상 - 상세 패널 초상은 선택 스테이지의 암살자 외형 단계(3-1 = Assassin, 3-2 = _S2, ... 3-5 = _S5)로 바뀝니다. 기사/궁수 때와 같은 방식입니다. 이 목업에서는 HeroIcons/Assassin*.png 를 서빙하는 경로가 없어 CSS 실루엣(단계 색)으로 대체했습니다.
  5. 규칙 문구 - 3-1 규칙 없음 / 3-2 봉인된 둥지(역병귀) / 3-3 성수 샘 / 3-4 봉인된 둥지(저주술사) + 짙은 안개 / 3-5 수호 결계(HP 75%) + 덫(HP 35%) 은 보스 페이즈 영역. 문구는 코드(StageRuleText)와 같은 템플릿에서 수치를 넣어 출력한 결과입니다. 신규 문구는 0건(모두 Strings_Ko 기존 id).
  6. 3-5 상세의 "스테이지 규칙" 영역 - 3-5 는 상시 규칙이 없고 페이즈 2개만 있어 "특수 규칙 없음" + 보스 페이즈 2건으로 나옵니다(2-5 와 같은 패턴). 페이즈 2건이 들어가도록 규칙 영역을 세로로 이어 붙이는 흐름 배치로 했는데, 기존 목업의 고정 좌표(규칙 112px / 페이즈 96px)와 달라지므로 승인이 필요합니다.
  7. 챕터 해금 연출 후보 제안 / 이월 - (A) 마을 HUD 지도 버튼에 빨간 점, (B) 지도 팝업을 열었을 때 3장 탭 점멸. 둘 다 "3장을 한 번도 열어보지 않았을 때"만 표시하고 3장 탭을 누르면 해제됩니다. 방문 여부 저장 필드가 새로 필요하므로 이번 구현에 넣을지, 이월할지 결정해 주세요. 문구는 필요 없습니다.
  8. 챕터 배경 썸네일 제안 - 지도 영역 뒤에 Battle_Backdrop_ShadowCitadel 을 어둡게 깔지 여부(상단 토글). 기존 1·2장 지도는 배경 이미지가 없으므로 넣으면 챕터 간 톤이 달라집니다. 기본값은 사용 안 함.
  9. 범위 밖(이 목업에 없음) - 기록 팝업, 랭킹 팝업, 4·5장, ★ 목표, 악몽.
