0. 사용자 선택 — 그림자 성채 팔레트 2안 (아래 모든 화면이 선택안으로 바뀐다)

판정은 각 단계 대표색(chip)의 색상각(hue). 초록(ok) = 31° 이상, 주황(warn) = 25° 이상 31° 미만(기존 규약 25° 는 충족), 빨강(ng) = 25° 미만. 무채색은 판정 제외. 표는 토글과 무관하게 A·B 두 안을 모두 보여주며(선택된 안만 "(선택됨)" 표기), "인접 단계" 행의 B안 값(0°·3°·4°·2°)은 단색조 설계상 의도라 주황으로 표시한다. 기사 유채색 =그린 142° · 시안 199° · 퍼플 271° · 크림슨 0°. 궁수 비교 대상 = 궁수 A/B 두 안의 대표색 전부. 기사 4색과 궁수 색이 차지한 색상환의 빈 구간 중 양쪽 모두에서 31° 이상 떨어질 수 있는 곳은 인디고 230°~240° 대역뿐이다(그 외 빈 구간 폭은 56°~59° 라 한가운데도 최대 28°~29°).

4. 전투 미니 프리뷰 — 우선 표적 사냥 + 슬립 이탈 + 스킬 3종

금색 점선 = 공격 사거리 1.6 · 붉은 점선 = 군중 판정 반경 2.0(3마리 이상이면 슬립) · 푸른 점선 = 사냥 반경 9.0. 영웅 위 붉은 마름모 = 현재 우선 표적(DPS÷현재HP 최상위: 원거리 > 근접 > 빠른 > 탱커 순으로 몬스터 데모 블록을 매김). 한 표적과 2.8초 교전하거나 군중이 3마리 이상이면 0.2초 무적 슬립(3.5 이동, 쿨 5.0s)으로 빠진 뒤 다시 사냥한다. 몬스터(청회색 탱커 5HP / 붉은 근접 3HP / 보라 빠른 2HP / 황색 원거리 2HP 는 4.0 거리에서 사격)는 데모용 블록이며 실제 몬스터 시안이 아니다. 영웅이 쓰러지면 자동 리셋된다. 수치는 연출 확인용 단순 모델이라 참고만, 판정은 qa-simulator.

7. 핵심 결정 요약

  • 같은 "해골" 세계관: 뼈 색 · 형광 눈(3-1·3-2 는 기사/궁수와 같은 초록, 3-3~3-5 는 단계 발광색) · 검은 외곽선 유지. 기사의 "낮은 캡 + 대각 소검", 궁수의 "뾰족 후드 + 세로 활" 대신 복면 + 가로로 길게 날리는 목도리 + 쌍단검 + 낮은 자세가 정체성이다.
  • 공격 = stab 행 9프레임 15fps(0.600s): F0~F1 웅크림 → F2 돌진 → F3 앞 단검 찌름 = strike(0.200s) → F4~F5 뒷 단검 베기(연출) → F6~F8 복귀(F8 = 대기 F0 와 같은 포즈라 이음새 없음).
  • 이동 = walk(0.8s 루프)·run(0.571s 루프). 슬립과 그림자 습격은 run 클립 + 잔상 FX 로 표현(별도 클립 없음).
  • 5단계 규약은 기사/궁수와 같다: 외곽선 베이크(3-2 #F8FAFC · 3-4 팔레트별 · 3-5 #FDE047), 발광(3-3~3-5), 3-5 만 루트 스케일 1.20.
  • 단계별 파츠: 두건(둥근 두건 → 뒤로 뾰족 → 쌍 뾰족 → 양뿔 → 칼날 왕관) · 목도리(짧은 천 → 제비꼬리 → 찢어진 외투 → 이중 → 거대 외투) · 단검(단검 → 곡도 → 발광 → 대형 → 흑요 낫칼) · 등 칼집(없음 → 1 → 1 → X자 → 대형 X자).
