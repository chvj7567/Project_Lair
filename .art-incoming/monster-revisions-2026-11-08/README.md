## 공통 기준

- 레이아웃: 6열×5행, 행 순서 Idle / Attack / Death / Spawn / Walk. 원본 크기와 셀 크기는 실제 파일 기준으로 확인한다.
- 승인된 그림을 새로 생성하지 않는다. 위치 정렬은 정수 픽셀 이동으로 하고 프레임별 배율 변경을 금지한다.
- 높이 고정은 기준 위치(root/몸체)의 불필요한 드리프트 제거다. 날갯짓·몸체 변형·소멸·등장까지 동일한 바운딩박스로 강제하지 않는다.
- Reaper의 낫은 하나의 동일한 무기로 취급한다. 날·자루를 줄이거나 따로 변형하지 않는다.
- 셀 경계에 효과가 닿으면 잘라 숨기지 말고 위치·동작 범위를 조정한다.
- 가장자리 잡색만 제거하며 Hex의 금빛 몸체와 Reaper의 붉은 망토는 유지한다.
- 실제 원본 비교와 미리보기 검수 결과를 종족별 JSON 보고서에 기록한다. 게임 적용·게임 내 재생 확인과 이미지 파일 검수를 구분한다.

## 완료 결과

- 6종 모두 1374×1145 RGBA PNG로 저장했다. 같은 이름의 `.png` 파일이 수정본이다.
- Phantom·Plague·Wisp: Idle/Walk만 정수 픽셀 수직 정렬. 기준 위치 오차 최대 0.5px 이내. Attack/Death/Spawn은 원본 RGBA와 동일하다. 정렬을 위해 제거한 잡픽셀은 Plague 409개·Wisp 286개이며 모두 알파 1/255였다. 나머지 유효 픽셀은 원본 색·알파를 보존했다.
- Hex: 붉은 잡색 제거, 원본 Attack 4열에서 5열로 넘어가던 탄을 14px 안쪽으로 이동했다. 5·6열의 원래 소품은 유지하며 공격 6셀 모두 알파 전체 기준 최소 4px 여백을 확인했다.
- Reaper: 망토를 유지한 채 외곽 잔색을 제거하고, 고정된 낫 하나로 공격 동작을 다시 합성했다. 공격 몸체는 이전 무기 제거 중간본을 사용해 기존 자루 조각을 남기지 않았다. 30셀 모두 최소 5px 여백을 확보했다. 공격 몸체의 원본 픽셀 동일성은 주장하지 않는다.
- Wraith: 원본 형상과 알파를 유지하면서 파랑·마젠타를 중성 회색·흰색으로 바꿨다. 정의한 파랑·마젠타 검출 기준 잔여 0개. 저알파 연기 픽셀은 보존했다.
- 이미지 생성 수정 후보는 요청 조건을 충족하지 않아 채택하지 않았다. 최종본은 원본을 기준으로 부분 정리·색상 변환·좌표 정렬·고정 무기 합성을 적용했다. 후보용 지시는 `PROMPTS.md`에 기록했다.

`alignment-report.json`, `reaper-report.json`, `hex-wraith-report.json`에 원본 해시·처리 방식·수치 검수 결과가 있다. PNG 전체를 눈으로 확인했고 GIF 파일의 프레임 구조를 검사했다. Unity 임포트·게임 내 재생은 수행하지 않았다.
