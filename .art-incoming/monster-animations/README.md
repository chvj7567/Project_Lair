# 몬스터 애니메이션 시트

기존 6종 몬스터 이미지를 참조한 제작 원본입니다.

각 종족별 6열 × 5행, 동작당 6프레임을 요청해 이미지 생성 도구(image_gen)로 제작합니다. 참조 이미지는 `.art-incoming/monster-quality-up/<종족>_QualityUp.png`입니다.

| 행 (위에서부터) | 동작 | 재생 |
|---|---|---|
| 1 | Idle | 반복 |
| 2 | Attack | 1회 |
| 3 | Death | 1회, 마지막 상태 유지 |
| 4 | Spawn | 1회 |
| 5 | Walk | 반복, 제자리 이동 동작 |

제안 미리보기 속도: Idle 8fps, Attack 12fps, Death 10fps, Spawn 10fps, Walk 12fps. 런타임 공격 속도와 타격 이벤트를 바꾸는 지시가 아닙니다.

| 종족 | 동작 특징 |
|---|---|
| Wisp | 불꽃 흔들림, 불꽃 돌진, 불씨로 소멸·등장, 부유 이동 |
| Wraith | 무거운 부유, 사슬 타격, 갑옷과 유령 붕괴, 흉부 문양에서 형성 |
| Reaper | 망토 흔들림, 낫 가로 베기, 붉은 천으로 소멸·등장 |
| Hex | 모자 흔들림, 금빛 저주탄, 금빛 불씨로 소멸·등장 |
| Plague | 젤리 압축·팽창, 독 방울 발사, 웅덩이로 소멸·등장, 도약 이동 |
| Phantom | 날갯짓, 날개를 접고 돌진, 푸른 안개로 소멸·등장, 비행 |

## 적용 상태

6장 모두 실제 크기는 1374×1145 RGBA PNG입니다. 논리 셀은 229×229이며 눈으로 확인한 동작 배치는 6열×5행입니다. 생성된 캐릭터의 위치는 완벽하게 균일하지 않습니다. Reaper는 별도 배경 제거를 거쳤습니다. Wraith·Hex·Phantom의 효과 및 외곽선 주위에 색 번짐이 보이며 Plague 공격 효과는 인접 셀에 가까워 추가 정리가 필요합니다. 루프 재생 검증은 하지 않았습니다.

제작 원본이며 기존 스프라이트·클립·프리팹을 수정하지 않습니다. AI가 그린 셀 위치, 프레임 크기, 루프 연결성, 외곽선과 알파 정리는 적용 전 추가 검수가 필요합니다. 요청한 1536×1280 크기와 실제 생성 크기는 다를 수 있으며 실제 파일을 확인해야 합니다.

Walk는 기존 move에 대응합니다. 이 원본에는 hit 행이 없으며 Spawn이 추가되어 기존 idle/move/attack/hit/death 시트를 직접 덮어쓸 수 없습니다. 임포트 전 행 재배치, hit 확보, 클립 타이밍과 공통 피벗 정렬이 필요합니다.
