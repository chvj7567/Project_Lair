# 몬스터 애니메이션 아트 제작·수정 규칙

작성일: 2026-11-08

적용 대상: Project Lair 기존 6종(Wisp·Wraith·Reaper·Hex·Plague·Phantom)의 이미지와 애니메이션 제작 원본. 이번 Reaper 수정에서 확인한 무기 일관성·부분 수정 원칙을 다른 무기와 소품에도 적용한다.

상위 스타일 기준은 [art-resource-rules.md](../../docs/design/art-resource-rules.md)다. 이 문서는 제작 중 무기 변형과 불필요한 전체 재생성을 막기 위한 세부 규칙이다. 제작 원본과 Unity에 적용한 최종 리소스를 구별하며, 기존 클립·판정·타이밍을 이 문서만으로 변경하지 않는다.

## 1. 기준 이미지와 수정 범위

1. 사용자가 이미지를 첨부하면 **그 첨부 파일을 수정 원본으로 사용한다.** 다른 버전이나 현재 프로젝트 파일로 임의 교체하지 않는다.
2. 행·열 번호는 **왼쪽 위부터 1번**으로 센다. 예: 2행 5열 = 공격 행의 다섯 번째 이미지.
3. 작업 전 대상 종족, 동작, 프레임, 수정할 요소를 확정한다. “2행 5번째 무기만”이면 그 무기와 제거·복원에 필요한 영역만 수정한다.
4. 지정하지 않은 프레임, 몸체, 얼굴, 손, 의상, 색상, 위치, 캔버스 크기는 보존한다. 전체 행의 위치·자세를 바꾸려면 사용자가 그 범위를 요청해야 한다.
5. 수정 원본은 보관하고 결과는 별도 파일로 저장한다. 사용자가 교체를 요청한 경우에만 해당 파일을 덮어쓴다.

## 2. 무기·소품 형태 고정 — 필수

**한 무기는 모든 프레임에서 같은 물체여야 한다.** 회전 때문에 화면상 가로·세로 길이가 달라지는 것은 허용하지만, 실제 날·자루의 길이와 비율이 바뀌는 것은 금지한다.

| 요소 | 유지할 항목 |
|---|---|
| 날 | 전체 길이, 곡률, 두께, 끝 모양, 색과 재질 |
| 자루 | 전체 길이, 두께, 재질, 장식 위치 |
| 결합부 | 날과 자루의 연결 위치·각도, 고정부·리벳 |
| 비율 | 날:자루 비율, 캐릭터 대비 무기 크기 |
| 개수 | 원래 무기 개수 유지. 잔여 조각·중복 무기 금지 |

- 기준 무기 이미지를 **하나의 투명 레이어**로 분리해 재사용한다.
- 허용 변환은 **고정 배율에서의 회전·이동**이다. 프레임별 확대·축소, 늘리기, 휘기, 원근 찌그러뜨리기를 금지한다.
- 방향 전환에 전체 좌우 반전이 필요한 경우 무기 **전체**를 일관되게 반전한다. 날과 자루를 따로 뒤집거나 프레임마다 방향을 임의 변경하지 않는다.
- 무기를 회전할 때 날과 자루를 한 덩어리로 움직인다. 프레임별로 무기를 다시 그려 형태를 추측하지 않는다.
- 도트 회전은 Point/최근접 기준으로 처리하고 계단·외곽선을 검수한다. 회전 후 모양을 보정한다는 이유로 무기 구조를 바꾸지 않는다.
- 손이 자루를 실제로 잡아야 한다. 손 뒤에 가려지는 부분은 가능하지만, 날·자루가 잘려 다른 무기로 보이는 구도는 사용하지 않는다.
- 무기가 셀에 안 들어가면 무기 크기를 줄이지 않는다. 동작 각도나 캔버스·정렬 변경 필요성을 확인하고, 요청 범위를 넘는 변경은 임의 적용하지 않는다.

### Reaper 고유 규칙

- 긴 갈색 나무 자루 + 긴 은색 곡선 날 + 금속 고정부를 유지한다.
- 장대낫이 짧은 손낫·도끼 등으로 바뀌면 반려한다. **손 뒤로 이어지는 자루도 전체 무기의 일부**다.
- 바깥쪽 공격을 요청한 경우 날과 타격 궤적은 캐릭터 몸 안쪽이 아니라 **공격 대상 방향(기본 화면 오른쪽)**을 향한다.
- 이전 무기를 지운 후에는 기존 날, 짧은 자루, 금속 조각, 외곽선 잔여물이 남지 않아야 한다.
- 새 낫을 붙이면서 무기가 두 개처럼 보이거나 손과 무기가 떨어져 보이면 반려한다.
- 사용자가 승인한 공격 미리보기의 낫 방향을 후속 수정에서도 유지한다. GIF와 전체 시트의 공격 행은 동일한 프레임 배열에서 만들고, 서로 다른 방향·구버전을 함께 제공하지 않는다. 갱신 결과에는 버전이 구분되는 파일명도 제공해 이전 미리보기와 혼동하지 않게 한다.

## 3. 종족별 동작 원칙

기존 종족의 특징을 움직임으로 표현하되 무기·신체·소품의 구조를 새로 만들지 않는다.

| 종족 | Idle | Attack | Death | Spawn | Walk |
|---|---|---|---|---|---|
| Wisp | 불꽃·몸체의 작은 부유 | 몸을 모았다 불꽃 돌진 | 불씨로 축소·소멸 | 불씨에서 몸체 형성 | 불꽃이 뒤로 흐르는 부유 |
| Wraith | 무거운 부유·사슬 흔들림 | 사슬을 뻗고 회수 | 유령·갑옷이 가라앉음 | 흉부 문양에서 몸체 형성 | 갑옷과 사슬이 따라 흔들리는 활주 |
| Reaper | 망토 흔들림·낫 안정 유지 | 같은 낫으로 준비→베기→회수 | 망토와 낫이 쓰러짐 | 붉은 영체와 낫이 나타남 | 낫을 든 채 망토가 흐르는 부유 |
| Hex | 모자·금빛 소품의 작은 흔들림 | 금빛 저주 에너지 발사 | 금빛 불씨로 소멸 | 불씨와 모자 아래 몸체 형성 | 모자 끝이 뒤따르는 부유 |
| Plague | 젤리 몸체 압축·팽창 | 몸을 모아 독 방울 발사 | 웅덩이로 가라앉음 | 웅덩이에서 부풀어 등장 | 다리 없이 압축·도약·착지 |
| Phantom | 작은 날갯짓·호버링 | 날개를 접고 돌진·회복 | 푸른 어둠·안개로 소멸 | 안개에서 날개와 몸체 형성 | 일관된 상하 날갯짓 비행 |

Idle·Walk는 제자리 반복 동작으로 제작한다. Attack·Death·Spawn은 진행 순서가 읽히는 단발 동작으로 제작한다. 소멸·등장 때문에 작아지는 몸체나 효과를 셀에 맞춰 다시 크게 확대하지 않는다.

## 4. 이번 제작 원본의 시트 배치

| 항목 | 값 |
|---|---|
| 열×행 | 6×5 |
| 동작당 프레임 | 6 |
| 위에서부터 행 순서 | Idle → Attack → Death → Spawn → Walk |
| 현재 생성 원본 크기 | 1374×1145px |
| 논리 셀 | 229×229px |
| 배경 | 실제 알파 투명 PNG. 검정색으로 채운 배경·체커무늬 금지 |

이는 **이번 제작 원본**의 배치다. 현재 런타임 시트의 `idle/move/attack/hit/death`와 순서·구성이 다르며, hit도 포함하지 않는다. 그대로 덮어쓰거나 프레임 수·타격 이벤트를 바꾸지 않는다. Unity 적용 시 기존 SheetSpec·클립·공통 피벗에 맞춰 별도 정규화한다. 생성 원본의 일부 효과는 논리 셀 경계를 넘어갈 수 있으므로 실제 적용 전에 재배치한다.

## 5. 부분 수정 절차

1. 원본과 기준 무기 이미지를 확인한다.
2. 바꿀 프레임과 무기 영역을 표시한다. 새 무기가 차지할 투명 여백도 수정 영역에 포함한다.
3. 기존 무기와 잔여 조각을 제거한다. 가려졌던 몸체는 필요한 부분만 복원한다.
4. 동일한 기준 무기를 회전·이동해 손의 잡는 위치에 맞춘다.
5. 손이 앞에, 자루가 뒤에 놓이는 등 실제 가림 관계를 정리한다.
6. 수정 영역만 원본에 합성한다. AI가 전체 이미지를 다시 생성했더라도 그 결과로 원본 전체를 교체하지 않는다.
7. 지정 영역 밖의 **RGBA 픽셀 차이가 0인지** 검사한다. 색상 채널과 알파를 모두 비교한다.
8. 무기 형태, 긴 자루, 손의 연결, 잔여 조각, 잘림을 확대 이미지와 연속 프레임에서 확인한다. 동작을 수정했다면 GIF로 연결성도 확인한다.
9. 최종 전체 PNG와 확인용 확대 이미지 또는 GIF를 제공한다.

무기를 제거한 몸체 레이어, 마스크, 합성 전 후보는 작업용 중간 결과다. 중간 결과를 최종 수정본으로 안내하지 않는다. 자동으로 표시된 경우 작업 중간 이미지임을 명확히 알린다.

## 6. 검수·반려 기준

- [ ] 사용자 첨부 파일과 정확한 행·열을 기준으로 작업했다.
- [ ] 모든 무기 프레임이 같은 기준 무기·고정 배율을 사용한다.
- [ ] 날·자루·결합부가 분리 변형되거나 다른 무기로 바뀌지 않는다.
- [ ] 손이 자루를 잡고 있으며 무기 누락·중복·잔여물이 없다.
- [ ] 지정된 공격 방향을 향하고 무기가 부자연스럽게 몸을 찌르지 않는다.
- [ ] 무기가 잘리지 않고 도트 외곽선·알파가 깨끗하다.
- [ ] 요청하지 않은 몸체·얼굴·손·자세·다른 프레임의 변경이 없다.
- [ ] 지정 영역 밖 RGBA 동일성을 실제로 검사했다.
- [ ] 확인한 내용만 보고한다. 실제로 보지 않은 재생·게임 적용을 완료했다고 쓰지 않는다.

## 8. 작업 지시에 포함할 고정 문구

> 첨부 원본의 지정 프레임과 지정 요소만 수정한다. 무기는 기준 이미지 한 개를 고정 배율로 재사용하며 회전·이동만 허용한다. 날 길이·곡률·두께, 자루 길이, 연결부와 비율을 바꾸지 않는다. 기존 무기 조각을 완전히 제거하고 손과의 연결을 유지한다. 바깥쪽 공격이면 날을 공격 대상 방향으로 향한다. 지정하지 않은 캐릭터와 프레임은 원본 RGBA 픽셀 그대로 보존한다. 무기를 제거한 중간 결과를 최종본으로 제출하지 않는다. 수정된 전체 PNG와 검수용 확대 이미지 또는 GIF를 제공한다.
