## § 헤더

- **목표**: 도감 몬스터 탭에서 **미해금 칸**(그리고 미해금 칸을 선택한 상세 큰 미리보기)의 등급 이펙트(2~3 오라 / 4 측면 기둥 / 5 후광+기둥)를 몸처럼 **검은 실루엣**으로 보여 준다. 해금하면 이펙트도 실루엣에서 컬러로 바뀐다. 1등급은 이펙트 없음을 유지한다.
- **검증 가설**: 몸만 실루엣이던 미해금 칸에 이펙트 실루엣이 더해지면 "저 칸을 열면 어떤 모습인지" 가 칸에서 바로 읽혀(특히 4·5등급) 해금 욕구와 수집감이 오른다.
- **현재 단계 범위 적합성**: **범위 밖 -> 승격 필요**(사유: §8 "몬스터 도감 개편" 항목이 "1등급·미해금 칸은 효과 없음" 으로 규정). §1.3 개정 문구를 메인이 반영하면 범위 안이다. 신규 몬스터·신규 시트·신규 화면·저장 변경은 없다.
- **핵심 메커니즘**: 칸 이펙트 `Image` 는 가산 머티리얼(`Mat_GradeFx`)이라 검정 틴트로는 보이지 않는다(가산에서 검정 = 0 더하기). 그래서 미해금 칸은 이펙트 `Image` 의 **머티리얼을 기본 UI 머티리얼(알파 합성)로 바꾸고 색을 검정 + 알파 0.7** 로 둔다(시트 알파 모양 = 이펙트 실루엣). 칸은 정지 프레임(첫 프레임)이라 이펙트 슬롯(`GradeFxBudget`)을 쓰지 않는다. 해금 연출에서는 실루엣이 서서히 사라진 뒤 가산 머티리얼로 되돌려 컬러가 켜진다. 상세 미리보기는 미해금이어도 해당 등급 프리팹을 그려 이펙트가 나오고, 기존 검은 틴트(RawImage)가 전체를 검게 만든다.

## 2. 현행 동작 실측 (2026-11-18, 코드 직접 확인)

### 2.1 미해금 칸

| 항목 | 현행 |
|---|---|
| 몸 | `_body.color = open ? Color.white : Color.black`(`ApplyBody`) - 일반 UI 머티리얼이라 검정 틴트 = 검은 실루엣 |
| 이펙트 | `ApplyStaticFx(data, open)`: `spec = open && Grade > MinGrade ? SpecOf(...) : null` -> 미해금이면 spec null, 오라·후광·기둥 전부 `SetActive(false)` |
| 이펙트 Image | 프리팹에서 `Mat_GradeFx`(가산) 참조(`CodexMonsterCell.prefab` 7곳: 오라 1 + 후광 1 + 기둥 4 + 해금 연출 추정 1). 색은 `SetFxAlpha` 로 알파만 변경(RGB 불변) |
| 애니 | `IsFxCandidate = Open && Grade > 1` -> 미해금은 후보가 아님(슬롯 0) |
| 해금 연출 | `BeginUnlock`: 몸 검정, `SetFxAlpha(0)`. `TickUnlock`: 몸 `Lerp(black, white, fade)`(1.4초), 이펙트 알파 0 -> 1 은 `cellFxFadeDelaySec` 뒤 `cellFxFadeSec` 동안 |
| 재사용 | 풀 셀 `OnEnable`/`ResetTransient` 가 `SetFxAlpha(1)`, 레이어 상태 리셋 |

### 2.2 미해금 상세 미리보기

- `CodexDetailPreview.ShowAsync(monster, baseMonster, tier, silhouette, tiers)`: `key = silhouette ? baseMonster : monster` -> 미해금은 **기준(1등급) 프리팹** -> `MonsterLookApplier.Apply` 가 `GradeOf(key) > 1` 이 아니라 등급 연출을 건너뜀(이펙트·등급 크기 없음). 실루엣 = `_image.color = Color.black`(RenderTexture 를 보여 주는 `RawImage` 전체를 검게).

### 2.3 알파 가정 (L1-A 성립 조건)

- A 안은 시트 PNG 알파가 이펙트의 실제 모양을 따라야 한다. `GradeFxAdditive` 는 `tex.a` 를 쓰고 임포트 `alphaIsTransparency: 1` 이지만, 현행 시트가 RGB 만 있고 알파가 전부 불투명(검정 배경 렌더)일 가능성이 남아 있다(가산 합성은 그래도 정상으로 보임). 불투명이면 A 의 실루엣은 **검은 직사각형**이 된다.
- 병행 기획 `grade-fx-species.md` §7.3 의 새 시트는 알파 = max(R,G,B)(직선 알파)라 A 가 항상 성립한다.
- 판정: 구현 착수 첫 단계에서 게이트 X-L1(현행 18장 알파 측정)을 돌린다. 통과면 A. 실패면 현행 시트에 한해 **B**(신규 셰이더 `GradeFxSilhouette`: 알파 합성, 알파 = max(R,G,B) x 틴트 알파, 검정 출력 + 머티리얼 `Mat_GradeFxSilhouette` 1개)를 쓴다. B 에서는 `ApplyStaticFx` 의 머티리얼 교체 대상이 `null` 대신 이 머티리얼이고 나머지 흐름은 같다. B 가 필요해지면 §8 문구에 "실루엣 머티리얼 1" 을 추가로 승격한다(메인이 사용자와 합의).

## 3. 규칙

### 3.1 칸 (매트릭스)

| 상태 | 이펙트 Image | 머티리얼 | 색(RGBA) | 프레임 | 슬롯 |
|---|---|---|---|---|---|
| 1등급 | 전부 끔 | - | - | - | 0 |
| 2~3등급 미해금 | 오라 | 기본 UI(`null`) | (0,0,0,0.7) | 첫 프레임 정지 | 0 |
| 4등급 미해금 | 오라 + 기둥 2 | 기본 UI | (0,0,0,0.7) | 정지 | 0 |
| 5등급 미해금 | 오라 + 후광 + 기둥 4 | 기본 UI | (0,0,0,0.7) | 정지 | 0 |
| 해금(비애니 칸) | 위와 같은 구성 | `Mat_GradeFx`(가산, 프리팹 원본) | (1,1,1,1) | 첫 프레임 정지(현행) | 0 |
| 해금(애니 칸) | 위와 같은 구성 | `Mat_GradeFx` | (1,1,1,1) | 애니(현행) | 1 |

- 어떤 이펙트(오라·후광·기둥 수)가 켜지는지는 해금 칸과 같은 `GradeFxDatabase.SpecOf(종족, 등급)` 기준이다(칸의 위치·크기·정렬은 프리팹 그대로).
- 기둥 개수 매핑·`ShowFxFrame(0)` 은 현행 `ApplyStaticFx` 와 같다(미해금도 `ShowFxFrame(0)` 로 첫 프레임을 채운다).
- 머티리얼 원본은 셀이 `Awake` 에서 이펙트 `Image` 의 현재 머티리얼을 1회 캐싱한다(Rule 02 §5 - 런타임 반복 탐색 금지). 풀 재바인딩 때마다 위 표대로 **머티리얼·색을 모두 명시적으로 설정**한다(해금 칸에 실루엣 상태가 남는 누수 방지).
- 몸 실루엣과 함께 보이므로 이펙트 실루엣은 몸 뒤(기존 레이어 순서 그대로).

### 3.2 해금 연출 (미해금 -> 해금 전환)

`t` = 스태거 대기를 뺀 연출 시간.

| 구간 | 몸 | 이펙트 |
|---|---|---|
| `t = 0` | 검정 | 실루엣 상태(기본 UI 머티리얼, (0,0,0,0.7)) |
| `0 < t < cellFxFadeDelaySec`(1.4초) | 검정 -> 흰색 페이드 | 실루엣 알파 `0.7 x (1 - t / cellFxFadeDelaySec)` |
| `t = cellFxFadeDelaySec` | 컬러 | 머티리얼을 `Mat_GradeFx` 로 교체, 색 (1,1,1,0)(이 순간 알파 0 이라 깜빡임 없음) |
| `cellFxFadeDelaySec < t < cellFxFadeDelaySec + cellFxFadeSec`(0.6초) | 컬러 | 알파 0 -> 1 (현행 `fxAlpha`) |

- 머티리얼 교체는 1회만(플래그). `cellFxFadeDelaySec` 가 0 이하면 시작 즉시 교체한다.
- 연출 중 팝업을 닫거나 탭을 바꿔 중단되면 `ResetTransient` 가 3.1 표의 상태를 다시 적용한다.

### 3.3 상세 큰 미리보기

| 선택 칸 | 로드 프리팹(`key`) | 이펙트 | 틴트 |

| 미해금 1등급 | 1등급 프리팹(= 기준, 현행) | 없음 | 검정 |

- 슬롯: 상세는 칸 상한과 별도로 먼저 확보되는 기존 경로(`monster-codex.md` §5.4)를 미해금에도 그대로 쓴다. 등급 프리팹이 `Configure` 에서 `GradeFxBudget` 슬롯을 스스로 얻는다(전투·쇼케이스와 같은 경로). 획득 실패 시 이펙트 생략(몸만 실루엣).
