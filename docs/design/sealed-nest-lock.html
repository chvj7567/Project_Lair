2. 눌러 보면

봉인된 둥지를 누르면 전투가 잠깐 멈추고 작은 안내창이 뜹니다. 시간이 흐르지 않으니 천천히 읽어도 됩니다.

봉인된 둥지

저주술사 둥지가 봉인되어 있다.
영웅 HP가 50% 이하가 되면 봉인이 풀린다.
현재 영웅 HP 73% (23%p 더 깎으면 해제)

확인
  • 닫는 법: 확인 버튼, 창 밖 어두운 곳 터치, 뒤로가기(ESC) 모두 가능
  • 닫으면 멈췄던 전투가 바로 이어지고, 2배속이었다면 2배속 그대로입니다
  • 뒤로가기로 안내창만 닫히고, 전투 종료 창이 이어서 뜨지는 않습니다

3. 봉인이 풀리는 순간

무엇이어떻게
자물쇠살짝 커지면서 사라집니다 (약 0.5초)
몬스터 그림다시 밝아집니다
아래 글자"봉인 - ..." 대신 다음 소환까지 남은 초가 보입니다
기존 연출사슬이 풀리고, 몬스터가 한꺼번에 나오고, "봉인이 풀렸다!" 알림이 뜨는 것은 그대로입니다

한 번 풀린 봉인은 영웅이 회복해도 다시 걸리지 않습니다.

4. 달라지지 않는 것

  • 봉인 규칙과 해제 HP 수치, 난이도, 몬스터 능력치는 그대로입니다
  • 새 화면이나 새 메뉴가 생기지 않습니다 (기존 확인창을 그대로 활용)
  • 카드로 불러낸 몬스터는 봉인과 상관없이 나옵니다
  • 챕터, 데일리, 무한의 탑 모두 같은 방식입니다
