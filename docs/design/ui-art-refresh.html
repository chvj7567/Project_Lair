게임 UI 그림을 화면별로 새로 그립니다

도감에서 먼저 확정한 그림체를 기준으로, 모든 화면을 같은 느낌으로 바꿔 갑니다.

달라진 방침

처음에는 작은 도트 조각을 같은 크기로 덮어쓰는 계획이었지만 폐기했습니다. 이제는 화면(팝업) 하나마다 전용 고해상도 그림 세트를 새로 만들어 그 화면에 끼웁니다. 도감이 첫 사례로 이미 확정되었습니다(세부는 다음에 다듬음).
지금 느낌
창 / 버튼
작은 도트, 단순한 테두리
새 느낌(예시)
창 / 버튼
굵은 외곽선, 3단 음영, 금색 이중 테두리, 입체감

어떻게 만드나요

  1. 공통 세트: 탭, 닫기, 버튼, 별, 진행 바 같은 여러 화면이 함께 쓰는 것은 한 번만 그려서 모두가 나눠 씁니다.
  2. 화면 전용 세트: 마을 화면 메뉴 타일·출격 버튼처럼 그 화면에만 있는 것은 화면별로 따로 그립니다.
  3. 화면의 기능·위치·버튼 개수는 그대로이고, 그림만 바뀝니다. 데이터도 건드리지 않습니다.
  4. 한 화면 세트마다 미리보기 그림을 먼저 보여 드리고 승인하면 끼워 넣습니다.

제일 먼저: 마을 화면

게임을 켜면 제일 먼저 보이는 화면이라 첫 번째로 바꿉니다. 상단 바, 경험치 바, 재화 칸, 왼쪽 메뉴 타일과 아이콘, 침입자 카드, ◀▶ 버튼, 방어하기 버튼까지 약 35장입니다. 미리보기 화면(.mockups/village-hud-art.html)에서 구성을 확인해 주세요.

전체 약 250장 규모입니다. 그림은 AI 이미지 생성으로 뽑는데, 사용량 제한에 걸린 적이 있어 한 번에 몰아서 하지 않고 화면 하나씩 진행합니다.

안 바꾸는 것

월드맵 장면 그림(메달·달·실루엣·안개), 몬스터·영웅 그림, 글꼴, 카드 일러스트, 유물 그림은 이번 계획에 포함하지 않습니다. 도감 그림 중 다른 화면과 함께 쓸 만한 것은 도감 다듬기가 끝난 뒤 공통 부품으로 옮깁니다(그전에는 건드리지 않음).
