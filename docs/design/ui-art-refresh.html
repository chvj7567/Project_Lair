게임 UI 그림을 한 번에 새로 그립니다

버튼·창·바·배지·메뉴 아이콘이 새 몬스터·영웅 그림과 같은 느낌이 되도록 바꿉니다.

무엇이 바뀌나요

게임 전체가 함께 쓰는 UI 그림 117장(창 틀, 버튼, 경험치·체력 바, 배지, 링, 메뉴 아이콘)을 새로 그립니다. 몬스터·영웅 그림, 글꼴, 카드 일러스트는 건드리지 않습니다. 화면 구성·기능은 그대로이고 그림만 바뀝니다.

이번에 바꾸지 않는 것: 색만 입혀 쓰는 순백 사각형 1장, 월드맵 장면 그림 10장(나중에 따로), 안 쓰는 그림 5장(체력바·로딩바·타이틀·앱 아이콘 등).

지금
창 / 버튼 느낌
면이 매끈한 어두운 남색
바뀐 뒤(예시)
창 / 버튼 느낌
면이 3단계 색으로 또렷, 모서리 빛과 그림자가 선명

색 계열(남색 + 금색)은 그대로이고, 몬스터처럼 굵은 어두운 외곽선 + 또렷한 음영으로 다듬습니다. 소울 초록·피 빨강 같은 의미 색은 그대로입니다.

어떻게 교체하나요

  1. 시안 6장을 먼저 만들어 몬스터 그림 옆에 놓고 보여 드립니다(창, 버튼, 금 버튼, 바, 금테 틀, 배지).
  2. 마음에 들면 승인해 주세요. 승인 전에는 게임 파일을 바꾸지 않습니다.
  3. 승인 후 나머지를 묶음으로 만들어 바꿉니다: 창·틀 → 버튼 → 바·배지 → 링·장식 → 아이콘.
  4. 묶음마다 화면을 하나씩 확인하고, 이상하면 그 그림만 다시 만듭니다.
게임 파일 이름과 크기를 그대로 두고 그림만 덮어씁니다. 그래서 화면이 깨지거나 기능이 바뀔 걱정이 적고, 프로그램을 고치지 않습니다.

주의할 점

걱정대응
색을 입혀 쓰는 그림(등급색, 종족색 등)이 칙칙해질 수 있음그런 그림은 흑백으로만 그려서 게임이 색을 입힙니다
창 테두리·버튼이 늘어날 때 모서리가 일그러질 수 있음원래 크기와 모서리 두께를 똑같이 맞춰 만들고 늘려 보며 확인합니다
AI 그림이 픽셀 모양과 안 맞을 수 있음크게 뽑아 줄이고 색을 정리하는 후처리를 하고, 시안으로 먼저 확인합니다

도감 개편과의 관계

지금 만들고 있는 도감 개편과 부딪히지 않습니다. 같은 이름의 그림을 덮어쓰는 방식이라 도감 화면도 자동으로 새 그림을 씁니다. 도감용으로 새로 추가한 그림 3장(칸 테두리, 빛, 반짝이)은 새 화풍에 맞는지 같이 확인합니다.
결정되었습니다
  1. 색만 입혀 쓰는 순백 사각형 그림은 제외 (확정)
  2. 월드맵 장면 그림 10장은 이번에 제외, 나머지 117장 먼저 (확정, 월드맵은 후속)
  3. 시안 6장(창, 버튼, 금 버튼, 바, 금테 틀, 배지)으로 먼저 확인 (확정)

다음 순서: 시안 6장 생성 → 사용자 확인 → 승인되면 나머지 일괄 교체.
