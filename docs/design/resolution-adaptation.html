어떤 폰·태블릿에서도 모든 화면이 안 겹치고 안 잘립니다

마을뿐 아니라 전투와 로딩 화면, 그리고 팝업 전부를 하나하나 확인했습니다. 긴 폰(S25+ 등)에서 마을 버튼이 겹치고 침입 지도 아래가 잘리던 문제를 모든 화면에서 다시 일어나지 않게 정리합니다.

확인한 화면 요소: 47개 (마을·전투·로딩의 화면 틀 3개, 팝업과 HUD 25개, 목록 칸 18개, 로딩 문구·진행바 묶음 1개)

정정 안내
앞선 안내에서 "로딩 화면은 문제없다, 화면 옆·위아래 띠가 폰의 카메라 구멍·제스처 바를 가려 준다"고 했는데 틀렸습니다. 띠가 가려 주는 것은 양옆(긴 폰)과 태블릿 위아래뿐입니다. 긴 폰(S25+ 등)과 16:9 폰에서는 화면 아래 제스처 바 영역이 로딩 화면 안으로 들어와서, 진행바와 퍼센트 글자의 절반 이상이 제스처 바에 가려집니다. 같은 종류의 실수가 팝업에도 있었습니다. 유물 팝업·전투 결과창 아래쪽이 제스처 바에 걸쳐 있었습니다(마을 팝업 4종은 2만큼). 아래 계획에 반영했습니다.

이렇게 바뀝니다

1. 버튼 크기는 그대로, 빈 곳만 늘어남
긴 폰에서는 버튼 사이 빈 곳만 넓어지고, 태블릿에서는 위아래 빈 곳이 늘어납니다.
2. 카메라 구멍·제스처 바 피하기
마을 버튼이 폰의 카메라 구멍과 아래 제스처 바를 피해 안쪽에 놓입니다. 배경 그림은 화면 끝까지 그대로 보입니다.
3. 팝업은 항상 한가운데, 제스처 바 위
침입 지도, 데일리, 편성, 탑 팝업이 어느 화면에서도 정중앙에 뜨고 아래가 잘리지 않습니다. 팝업도 마을 버튼처럼 카메라 구멍·제스처 바를 피한 영역 한가운데에 뜹니다. 어두운 배경 막은 화면 끝까지 덮습니다. 유물 팝업은 3% 줄고, 전투 결과창은 조금 위로 올라갑니다.
4. 전투 화면은 거의 그대로
전투 구역과 띠 모양은 건드리지 않습니다. 오른쪽 빌드 창 두 개만 조금 위로 올려, 아래 제스처 바가 큰 폰에서도 아래 슬롯과 겹치지 않게 합니다.
5. 로딩 화면: 같은 크기 + 제스처 바 피하기
지금처럼 가운데 16:9 영역 안에 그려집니다. 크기 계산 방식을 고정해서 아주 긴 폰에서도 글자가 잘리지 않게 하고, 진행바·퍼센트·설명 글이 화면 아래 제스처 바 위로 올라오게 합니다(카메라 구멍이 위에 있으면 제목도 그 아래로). 배경 그림과 뒤 배경 연출은 그대로 화면 끝까지 채워집니다.
6. 하단 버튼 순서가 조금 바뀝니다 (마을)
오른쪽 위협도 카드와 겹치지 않도록 탑 버튼이 지도 버튼 왼쪽으로 옮겨갑니다. (탑 · 지도 · 방어하기)
