어떤 폰·태블릿에서도 모든 화면이 안 겹치고 안 잘립니다

마을뿐 아니라 전투와 로딩 화면, 그리고 팝업 전부를 하나하나 확인했습니다. 긴 폰(S25+ 등)에서 마을 버튼이 겹치고 침입 지도 아래가 잘리던 문제를 모든 화면에서 다시 일어나지 않게 정리합니다.

점검 결과 한눈에

확인한 화면 요소: 47개 (마을·전투·로딩의 화면 틀 3개, 팝업과 HUD 25개, 목록 칸 18개, 로딩 문구·진행바 묶음 1개)
결과개수내용
문제 있음7마을 화면 틀, 마을 메인 화면, 침입 지도·데일리·편성·탑 팝업(4), 유물 팝업
조건부 문제1전투 화면: 폰 아래쪽 제스처 바가 클 때 오른쪽 빌드 창이 아래 슬롯과 겹침
불안정1로딩 화면: 지금은 괜찮지만 아주 긴 폰(25:9 이상)에서 글자가 잘릴 수 있음
아직 확인 못 함2스킬 해금 배너가 아주 긴 폰에서 끝까지 닿는지, 체력바가 붙는 자리
문제 없음나머지마을 팝업 8개, 전투 팝업 4개, 확인창, 토스트, 전투 화면 틀. 목록 칸 18개는 부모 팝업을 따르며 칸 하나하나의 크기는 확인하지 못했습니다.

이렇게 바뀝니다

1. 버튼 크기는 그대로, 빈 곳만 늘어남
긴 폰에서는 버튼 사이 빈 곳만 넓어지고, 태블릿에서는 위아래 빈 곳이 늘어납니다.
2. 카메라 구멍·제스처 바 피하기
마을 버튼이 폰의 카메라 구멍과 아래 제스처 바를 피해 안쪽에 놓입니다. 배경 그림은 화면 끝까지 그대로 보입니다.
3. 팝업은 항상 한가운데
침입 지도, 데일리, 편성, 탑 팝업이 어느 화면에서도 정중앙에 뜨고 아래가 잘리지 않습니다. 유물 팝업도 잘리지 않습니다.
4. 전투 화면은 거의 그대로
전투 구역과 띠 모양은 건드리지 않습니다. 오른쪽 빌드 창 두 개만 조금 위로 올려, 아래 제스처 바가 큰 폰에서도 아래 슬롯과 겹치지 않게 합니다.
5. 로딩 화면은 어느 폰에서도 같은 크기
지금처럼 가운데 16:9 영역 안에 그려집니다. 크기 계산 방식만 고정해서 아주 긴 폰에서도 글자가 잘리지 않게 합니다.
6. 하단 버튼 순서가 조금 바뀝니다 (마을)
오른쪽 위협도 카드와 겹치지 않도록 탑 버튼이 지도 버튼 왼쪽으로 옮겨갑니다. (탑 · 지도 · 방어하기)

그대로인 것

전투 구역과 전투 화면의 띠 모양, 게임 규칙·밸런스, 랭킹 기록은 변하지 않습니다. 새 화면이나 설정 메뉴도 추가되지 않습니다.
결정해 주세요
  1. 마을 하단 버튼 순서를 탑 · 지도 · 방어하기 로 바꿔도 될까요?
    추천: 바꾼다 (대안은 순서 유지 + 오른쪽 스테이지 카드를 줄이기 — 카드 안 작업이 큼)
  2. 태블릿에서 버튼·팝업을 키우지 않고 여백만 늘려도 될까요?
    추천: 여백만
  3. 마을 팝업은 카메라 구멍을 직접 피하지 않고 "항상 한가운데 + 크기 제한"으로 보호할까요?
    추천: 그렇다 (긴 폰에서는 구멍과 겹칠 일이 없음)
  4. 카메라 구멍이 매우 큰 16:9 폰처럼 아주 좁은 경우는 지원 밖으로 둘까요?
    추천: 지원 밖
  5. 로딩 화면을 지금처럼 가운데 16:9 영역에만 그리고, 크기 계산만 고정할까요?
    추천: 지금처럼 (대안은 긴 폰에서 로딩도 전체 폭으로 넓히기 — 배경을 새로 손봐야 함)
  6. 전투 오른쪽 시너지·빌드 창을 조금 위로 올려, 아래 제스처 바가 큰 폰에서도 겹치지 않게 할까요?
    추천: 올린다 (대안은 그대로 두고 그런 폰을 지원 밖으로 — 16:9 폰 일부가 해당)
  7. 스킬 해금 배너가 아주 긴 폰에서 끝까지 안 닿으면, 팝업 어두운 막처럼 좌우로 늘릴까요?
    추천: 늘린다 (먼저 실제 화면으로 확인한 뒤 필요할 때만)
