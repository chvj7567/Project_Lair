어떤 폰·태블릿에서도 화면이 안 겹치고 안 잘립니다

긴 폰(S25+ 등)에서 마을 버튼들이 서로 겹치고, 침입 지도의 난이도 선택과 "이 스테이지로 선택" 버튼이 화면 아래로 잘렸습니다. 이제 화면 비율이 달라도 같은 모양이 그대로 유지됩니다.

이렇게 바뀝니다

1. 화면이 길어도 버튼 크기는 그대로
긴 폰에서는 버튼 사이 빈 곳만 넓어지고, 태블릿(4:3)에서는 위아래 빈 곳이 늘어납니다. 버튼이 커지거나 줄지 않습니다.
2. 카메라 구멍·제스처 바 피하기
폰 화면 한쪽의 카메라 구멍과 아래쪽 제스처 바를 마을 버튼이 피해서 안쪽에 놓입니다. 배경 그림은 화면 끝까지 그대로 보입니다.
3. 팝업은 항상 한가운데
침입 지도, 데일리, 편성, 탑 팝업이 어느 화면에서도 정중앙에 뜨고 아래가 잘리지 않습니다. 팝업 뒤 어두운 막은 화면 끝까지 덮입니다.
4. 하단 버튼 순서가 조금 바뀝니다
화면이 좁을 때 오른쪽 위협도 카드와 겹치지 않도록 탑 버튼이 지도 버튼 왼쪽으로 옮겨갑니다. (탑 · 지도 · 방어하기)

그대로인 것

전투 화면, 로딩 화면, 게임 규칙·밸런스, 랭킹 기록은 변하지 않습니다. 새 화면이나 설정 메뉴도 추가되지 않습니다.
결정해 주세요
  1. 하단 버튼 순서를 탑 · 지도 · 방어하기 로 바꿔도 될까요?
    추천: 바꾼다 (대안은 순서 유지 + 오른쪽 스테이지 카드를 줄이기 — 카드 안 그림 작업이 커짐)
  2. 태블릿에서 버튼·팝업을 키우지 않고 여백만 늘려도 될까요?
    추천: 여백만 (키우려면 태블릿용 크기를 따로 조정해야 함)
  3. 팝업은 카메라 구멍을 직접 피하지 않고 "항상 한가운데 + 크기 제한"으로 보호할까요?
    추천: 그렇다 (긴 폰에서는 구멍과 겹칠 일이 없음. 대안은 팝업 12종에 어두운 막을 따로 손보는 작업 추가)
  4. 카메라 구멍이 매우 큰 16:9 폰처럼 아주 좁은 경우는 지원 밖으로 둘까요?
    추천: 지원 밖 (대안은 화면 전체를 줄여 맞추는 방식 — 구현이 복잡)
