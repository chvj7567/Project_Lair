등급 이펙트, 종족마다 다른 모양으로

지금은 6종 모두 같은 불꽃 기둥과 룬 원에 색만 다릅니다. 앞으로는 종족의 설화에 맞는 모양이 됩니다.

한 줄 요약
몬스터가 2등급 이상으로 승급하면 발밑·옆·뒤에 빛 이펙트가 붙습니다. 이 이펙트를 도깨비는 도깨비불로, 원귀는 안개와 혼불로, 저승차사는 붉은 깃발로… 종족마다 다르게 그립니다.

그대로인 것 / 바뀌는 것

그대로

  • 2~3등급은 발밑 고리만, 4등급은 몸 양옆에 요소 2개 추가
  • 5등급은 뒤 후광 + 양옆 요소 4개 + 몸이 반짝 맥동
  • 이펙트의 개수·크기·위치, 전투 중 부담
  • 승급 방법, 능력치, 몬스터 몸 그림

바뀜

  • 발밑 고리, 양옆 요소, 뒤 후광의 모양이 종족 설화 모티프로
  • 새 몬스터 그림체에 맞춘 고해상도 그림
  • 색은 몬스터 몸 색과 같은 계열

종족별 이펙트 (시안 느낌)

아래 그림은 개념만 보여 주는 간이 그림이고, 실제는 GPT 로 그린 빛 그림이 움직입니다.

도깨비불 꼬마 도깨비

5등급 느낌
  • 발밑: 도깨비불 8개가 줄지어 도는 고리
  • 옆: 불덩이가 3단으로 쌓인 불기둥
  • 뒤: 도깨비불 화환 후광

망령 원귀

5등급 느낌
  • 발밑: 은빛 안개 고리와 도는 혼불 5개
  • 옆: 소복 천과 머리카락처럼 흐르는 안개 기둥
  • 뒤: 보름달 달무리와 흩날리는 천 리본

사신 저승차사

5등급 느낌
  • 발밑: 붉은 저승 명부 원진과 오랏줄 고리
  • 옆: 펄럭이는 붉은 적패지 깃발 빛
  • 뒤: 붉은 해무리와 칼빛 광선

저주술사 애기무당

5등급 느낌
  • 발밑: 5방위 부적진과 방울 고리
  • 옆: 오방 술이 달린 세로 부적 띠
  • 뒤: 오방기 5장이 부채꼴로 펼쳐진 후광

역병귀 역신

5등급 느낌
  • 발밑: 독 웅덩이 파문과 터지는 기포 고리
  • 옆: 조롱박 모양으로 피어오르는 독 안개
  • 뒤: 독 구름과 신라 금관 모양 후광

환령 그슨대

5등급 느낌
  • 발밑: 청색 빛으로 그린 박쥐 무늬 고리
  • 옆: 불어나는 그림자의 푸른 윤곽과 눈
  • 뒤: 박쥐 날개 한 쌍의 푸른 빛 후광

알아둘 점

빛으로만 그림 이펙트는 화면에 빛을 더하는 방식이라 어두운 부분은 투명하게 보입니다. 그래서 환령·망령처럼 어두운 종족은 "어둠의 푸른 테두리 빛" 으로 표현합니다.
부담 동일 이펙트 개수와 크기가 그대로라 전투 중 부담은 늘지 않습니다.
먼저 한 종족 도깨비불로 먼저 만들어 보고 괜찮으면 나머지 5종을 만듭니다.
보고 승인 게임에 넣기 전에 옛 이펙트와 새 이펙트를 나란히 보여 드리고 승인받습니다.

어떻게 만드나

단계내용
1종족마다 그림 3장(발밑 / 옆 / 뒤)을 AI 로 그립니다.
2그 그림을 돌리고 흔들고 겹쳐서 부드럽게 반복되는 움직임으로 만듭니다.
3도깨비불 먼저 -> 승인 -> 나머지 5종.
4옛 것과 새 것 비교 화면에서 승인 -> 게임에 교체.

결정해 주세요

  1. 모양만 다르게 vs 구성까지 다르게
    종족마다 이펙트 개수·위치까지 바꿀지, 지금 구성(고리 / 양옆 / 뒤 후광)은 두고 모양만 바꿀지.
    추천: 모양만 다르게 (구성까지 바꾸면 데이터·화면·코드를 크게 손봐야 합니다)
  2. 빛으로만 그릴까요
    지금처럼 빛이 더해지는 방식을 유지할지, 몬스터처럼 어두운 외곽선이 있는 불투명 그림으로 바꿀지.
    추천: 빛으로만 (불투명으로 바꾸면 이펙트가 몸을 가리고 전체 교체 작업이 커집니다)
  3. AI 그림 배경색
    몬스터 때는 분홍 배경을 썼지만 빛 그림은 검정 배경이 번짐 없이 깨끗합니다. 검정으로 해도 될까요.
    추천: 검정으로 (안 깨끗하면 분홍으로 되돌립니다)
  4. 그림 선명도
    화면 크기가 큰 망령(5등급)과 사신은 이펙트가 살짝 부드러워 보일 수 있습니다. 지금 크기 그대로 괜찮을까요.
    추천: 그대로 (너무 흐리면 나중에 크기를 키우는 별도 작업으로)
  5. 시험 종족
    어느 종족으로 먼저 만들어 볼까요.
    추천: 도깨비불 (이펙트가 작아 실패 부담이 적고 모티프가 쉽습니다)
  6. 오방색 포인트
    저주술사·사신에 오방색(청·적·황·백·흑)을 아주 조금(15% 이하) 섞어도 될까요.
    추천: 허용 (몬스터 그림에도 쓰고 있습니다)
