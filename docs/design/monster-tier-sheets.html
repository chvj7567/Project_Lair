몬스터 강화 외형, 전신 그림 교체

상점에서 몬스터를 강화하면 겉모습이 변합니다. 지금까지는 기본 몸 위에 뿔·왕관 같은 장식을 덧그렸는데, 앞으로는 강화 단계마다 몸 전체를 새로 그린 그림으로 통째로 바꿉니다.

어떻게 바뀌나요

기본(풋내기)강화 1~2
1단계 그림강화 3~4
2단계 그림강화 5
3단계 그림
  • 몬스터마다 그림이 4벌입니다: 기본 + 강화 1단계 · 2단계 · 3단계.
  • 강화 레벨 1~2는 1단계, 3~4는 2단계, 5는 3단계 그림을 씁니다(지금과 같은 기준).
  • 바닥에 생기는 강화 링, 빛나는 정도, 상점의 강화 레벨은 지금과 같습니다.

얼굴은 그대로, 장식만 커집니다

단계가 바뀔 때 몬스터가 갑자기 커지거나 위치가 튀지 않도록, 눈 사이 거리와 얼굴 위치를 기본 그림과 똑같이 맞춥니다. 모자·왕관·망토·날개 같은 장식만 얼굴 밖으로 더 크게 뻗습니다. 전체 크기는 기본의 1.55배(키)·1.6배(폭)를 넘지 않게 제한하고, 넘으면 그림을 다시 만듭니다.

그림 품질 점검 결과

몬스터찾은 문제정리 방법
도깨비불 1·3단계쓰러지는 장면에 잔 점, 튀는 연두색 번짐색이 튀는 가장자리와 잔 점 자동 제거
망령 3단계망토가 그림 칸 가장자리에 닿아 잘림그림 전체를 살짝 줄여 여백을 확보하고 화면에서 보이는 크기는 같게 보정
저주술사 2·3단계쓰러지는 장면의 붉은·노란 잡티붉은 잡티 전부 삭제, 반짝이는 노란 입자는 큰 것만 유지
환령 3단계쓰러지는 장면의 흰 잡티떨어져 있는 흰 점 삭제(푸른 입자는 유지)
사신 1단계기본 모습과 구분이 약함구분 기준에 못 미치면 다시 그리기를 요청
2·3단계 전체모자·왕관·망토 때문에 몸이 커 보임눈 기준으로 크기를 맞추고 상한 초과 시 다시 그리기
전체프레임 흔들림거의 없음. 이 방식으로 쓸 수 있습니다.

빛나는 부분

눈, 구슬, 룬, 왕관 보석처럼 원래 빛나던 곳을 새 그림에서 자동으로 찾아 빛나게 합니다. 금색 왕관·갑옷 같은 장식 자체는 빛나지 않고 보석만 빛납니다(강화 레벨이 높을 때 장식이 번져 보이지 않도록).

달라지지 않는 것

그대로

체력, 공격력, 사거리, 이동 속도, 카드 효과, 시너지, 강화 레벨 효과.

그대로

공격·맞는·쓰러지는 동작의 길이, 맞을 때 색 번쩍임, 체력바(높이만 새 그림에 맞게 조정).

참고

게임 용량이 약 4MB 늘어납니다(휴대폰용 압축 기준, 6종 합계 약 29MB). 강화 그림 4벌은 전투 시작 때 모두 불러옵니다.

결정해 주세요

  1. 사신 1단계처럼 기본 모습과 구분이 약한 그림은 다시 그려 받을까요, 그대로 쓸까요?추천: 구분 기준에 못 미치면 다시 그립니다.
  2. 강화 그림에도 "나타나는 장면" 줄을 남길까요? (남기면 용량이 약 17% 더 듭니다)추천: 남깁니다. 휴대폰 용량이 빠듯하면 뺍니다.
  3. 자동 정리로 못 지우는 잡티를 손으로 지우는 것을 허용할까요?추천: 허용합니다.
  4. 전투 시작 때 필요한 강화 그림만 불러와 메모리를 줄이는 작업을 이번에 같이 할까요?추천: 이번엔 안 합니다(4벌 모두 불러오기). 휴대폰 메모리가 넘치면 다음에 합니다.
