## 1. WraithBirth — "위스프의 탈피" (가칭)

- **카테고리**: 패시브 — 강화 (Tank 축)
- **효과 모델**: 필드 위 모든 위스프 개체가 영웅에게 피격 3회 누적 시 해당 위스프를 제거하고 동일 위치에 레이스 1마리를 즉시 소환 (HP 리셋, 레이스 스탯 적용). 글로벌 캡(18마리) 포함 — 캡 포화 시 소환 불발, 위스프 제거만 발생. 중첩 픽 시 변신 임계 감소: 2픽 → 2회 피격, 3픽 → 1회 피격.
- **수치 근거**: 영웅 공격력 50/타, 공속 1초. 위스프 HP 200. 피격 3회 = 최소 3초 생존 가정. 위스프 여러 마리 중 일부만 변신하므로 급격한 Tank 폭등 억제. 레이스 HP 500으로 전환 후 필드 내구력 크게 증가.
- **구현 패턴**: 각 Wisp 개체에 `hitCount` 로컬 카운터 추가. `IHealth.OnDamaged` 이벤트 구독 → 카운터 증분 → 임계 초과 시 `CHMPool.Push(wisp)` + `CHMPool.Pop(EMonster.Wraith, position)`. `IBattleContext.IsFieldCapReached()` 가드 필요. 구현 비용 3 (개체별 카운터 + 변신 로직 신규).
- **시너지 후크**:
  - `WispHpBoost` (Wisp HP ×1.5) — 위스프 내구도 증가 → 피격 3회를 더 쉽게 버팀 → 변신 확률 상승
  - `WraithDamageBoost` (Wraith HP ×1.5) — 변신 직후 레이스가 더 강해짐 → 이중 Tank 강화
  - `SpawnWisps` (Wisp 스포너 출력 +1) — 위스프 모수 증가 → 변신 후보 개체 늘어남
  - `Tank Tier 1 (3장)` — 빌드 카운트 누적 시 Wisp·Wraith HP ×1.3 추가 → 변신 전·후 모두 강화
- **구현 비용 추정**: 3 (개체별 피격 카운터, 변신 이벤트 → CHMPool 교체 로직)
- **중복 재검증**: ReplaceWispsToWraith는 스포너 생산 라인 변경 (픽 직후 영구 적용). 본 카드는 살아있는 위스프 개체가 전투 조건을 충족해야 변신 — 시간 차이와 전투 의존성이 핵심. 36개 파일 전부 검토 후 "피격 N회 → 종 변신" 조합 없음.

## 2. PlagueBloom — "독구름의 분열" (가칭)

- **카테고리**: 패시브 — 강화 (Swarm 축)
- **효과 모델**: 플레이그 개체가 영웅 반경 2u 이내에서 연속 5초 체류 시 해당 플레이그를 제거하고 동일 위치에 팬텀 2마리를 즉시 소환 (글로벌 캡 포함). 체류 조건 중 영웅이 이탈하면 카운터 리셋. 중첩 픽 시 소환 수 증가: 2픽 → 팬텀 3마리, 3픽 → 팬텀 4마리 (캡 초과분 불발).
- **수치 근거**: 플레이그 이동속도가 낮고 영웅 근처에 자연히 머무름. PlagueSlowBoost 와 함께 쓰면 영웅 이동속도 ×0.75 → 영웅이 도망치기 어려워 체류 조건 달성 수월. 팬텀 2마리 = 플레이그 1마리 손실, 빠른 팬텀 2마리 획득 (Swarm 밀도 전환).
- **구현 패턴**: 각 Plague 개체에 `proximityTimer` 누적. `Update` 또는 정기 체크(0.5s 간격)에서 `Vector3.Distance(plague.pos, hero.pos) < 2f` 분기 → 타이머 증분. 5초 초과 시 `CHMPool.Push(plague)` + `CHMPool.Pop(EMonster.Phantom, pos)` × 2. 구현 비용 3 (개체별 체류 타이머, 근접 거리 체크).
- **시너지 후크**:
  - `PlagueSlowBoost` (Plague SlowFactor ×0.75) — 영웅 이동속도 추가 감소 → 체류 조건 달성 쉬워짐
  - `PhantomMoveSpeedBoost` (Phantom 이동속도 ×1.5) — 분열 후 팬텀들이 빠르게 영웅을 추격
  - `SpawnPlagues` (Plague 스포너 출력 +1) — Plague 모수 증가 → 분열 대상 개체 늘어남
  - `Swarm Tier 2 (5장)` — 스포너 주기 ×0.85 → Plague 더 빨리 보충 → 연쇄 분열 지속
- **구현 비용 추정**: 3 (개체별 체류 타이머 + 근접 조건 + CHMPool 교체)
- **중복 재검증**: death-echo-spawn-trio의 PhantomBirth는 "사망 위치에 25% 확률 팬텀 소환" (사망 조건). 본 카드는 생존 중인 Plague가 5초 체류를 달성해야 분열 — 생존 조건, 확률 없음, 종 변환. 메커니즘 다름 ✓

## 3. HexReckoning — "원거리의 결기" (가칭)

- **카테고리**: 패시브 — 강화 (Dps 축)
- **효과 모델**: 헥스 개체가 영웅에게 공격 8회 성공 시 해당 헥스를 제거하고 동일 위치에 리퍼 1마리를 즉시 소환 (HP 리셋, 리퍼 스탯 적용, 글로벌 캡 포함). 중첩 픽 시 임계 감소: 2픽 → 6회, 3픽 → 4회.
- **수치 근거**: 헥스 공속 1초(기본), HexRangeBoost 미적용 시 원거리에서 공격 8회 = 약 8~12초 전투 (이동 시간 포함). 리퍼 DPS 40으로 전환 → 헥스 DPS 30 대비 딜 상승, HP 100으로 리셋 (헥스 HP 60 대비 내구도도 소폭 증가). 한 번 변신한 리퍼는 더 이상 카운터 없음.
- **구현 패턴**: 각 Hex 개체에 `attackCount` 로컬 카운터. `IAttacker.OnAttackHit` 이벤트 구독 → 카운터 증분 → 임계 초과 시 `CHMPool.Push(hex)` + `CHMPool.Pop(EMonster.Reaper, pos)`. 구현 비용 3 (개체별 공격 카운터 + 변신 로직).
- **시너지 후크**:
  - `HexRangeBoost` (Hex 사거리 ×1.4) — 원거리에서 안전하게 8회 채울 기회 증가
  - `ReaperAtkSpeed` (Reaper 공격 쿨다운 ×0.7) — 변신 후 리퍼 딜 극대화
  - `SpawnReapers` (Reaper 스포너 출력 +1) — 리퍼 모수 강화 빌드에서 진화 리퍼가 추가 전력
  - `Dps Tier 1 (3장)` — Reaper·Hex Power ×1.3 → 진화 전(Hex 딜↑ → 8회 더 빨리) + 진화 후(Reaper 딜↑) 모두 이득
- **구현 비용 추정**: 3 (개체별 공격 카운터 신규, IAttacker.OnAttackHit 훅 연동)
- **중복 재검증**: ReplaceReapersToHex는 "Reaper 스포너 → Hex 출력" (생산 라인 변경, 방향도 반대). 본 카드는 이미 있는 Hex가 공격을 쌓아 Reaper로 전환 — 방향·트리거·레이어 모두 다름 ✓

## 4. 공통 테마 고찰

**테마**: 현장 진화 — "생산 라인이 아닌 전투 개체의 변신"

현재 36개 기존 파일의 카드 아이디어를 관통하는 두 축은:
1. **글로벌 버프** — 픽 즉시 적용되는 영구 배율 (HP×, Power×, 스폰 속도×)
2. **이벤트 트리거** — 사망(OnDeath) / 피격(OnHit) / 처치(OnKill) / 시간(OnTimer) / 위치(OnProximity)

이번 3장은 두 번째 축의 "개체 상태 추적 + 종 변환" 을 처음으로 도입한다. 특징:
- **개체별 상태 추적** — 글로벌이 아닌 각 몬스터 인스턴스가 자신의 조건 달성 여부를 추적
- **살아서 변신** — 죽지 않고 전투를 통해 다른 종이 됨 (death-echo와 달리 사망 없음)
- **단방향 전환** — 변신 후 재변신 없음, 전략적 타이밍 존재

**QA 공백 분석**: 시뮬레이터가 차단된 상태라 픽률 데이터 없음. 설계 기반으로 판단할 때 Swarm 축의 Plague 카드는 "느린 진입 + 낮은 DPS" 로 단독으로는 승부력이 낮다. PlagueBloom은 Plague가 느린 속도로 영웅을 좇는 특성을 역이용해 "체류 → 팬텀 분열" 로 전환 — Plague의 약점을 강점으로 뒤집는 설계.

**선택 이유**: 36개 파일 전부 및 git log 21회차 검토 결과, Replace (생산 라인 변경) · death-echo (사망 후 소환) · stat-boost (수치 강화) · leader-aura (리더 조건부 강화) 는 반복 등장했지만 **"살아있는 개체의 종 전환"** 은 전무. 구현 비용 3 (개체별 카운터)으로 비교적 낮고, 게임 내 드라마틱한 장면(위스프가 갑자기 레이스로 변신하는 시각)을 만들어 전투 가독성을 높일 수 있음.

## 6. 쉬운 설명 (비개발자 요약)

지금 게임에서는 몬스터가 스폰될 때 종류가 결정되고, 그 종류 그대로 싸우다가 죽습니다. 오늘 제안하는 카드들은 **싸우는 도중에 몬스터가 다른 종으로 탈바꿈**하는 재미를 줍니다. 예를 들어 작고 약한 위스프가 영웅에게 세 대를 맞고도 살아있으면 갑자기 무시무시한 레이스로 진화하거나, 느릿느릿 영웅 주위를 맴돌던 플레이그가 5초를 버티면 폭발하며 팬텀 두 마리로 분열합니다. 영웅 입장에서는 "저 몬스터 다음에 어떤 종으로 바뀔지 모른다"는 불확실성이 생겨 방심할 수 없는 긴장감이 더해지고, 던전 주인 입장에서는 위스프처럼 약한 종도 잘 살려두면 레이스로 돌변하는 역전의 묘미가 생깁니다. 그래서 오늘 제안하는 카드 3장은: 전투 중 조건을 충족한 몬스터가 더 강한 종으로 직접 탈바꿈하는 "현장 진화 카드" 세트입니다.
