## 0. 오늘 제안 개요

- **테마**: 크로스 축 스포너 전환 — 한 축의 몬스터 생산을 다른 축으로 영구 전환하는 전략적 희생 카드들
- **목록**: ReplaceWispsToPhantom / ReplaceReapersToPlague / ReplaceWraithToHex
- **기존 25+5 회차와의 중복 회피 확인됨**:
  - 기존 MVP 카드 ReplaceWispsToWraith · ReplaceReapersToHex 는 모두 **같은 축 내 업그레이드** — 본 제안은 **축 경계를 넘는 전환**으로 개념 차별화 완료
  - 과거 루틴 14회차 커버 테마: 전투 상태 스케일링 / 종간 시너지 / 독 연쇄 / 영구 낙인 / DPS 심화 / 사망 메아리 소환 / 위스프 방진 / 딜-디버프 사냥 / 시간 급류 / 군단 밀도 / 레이스·팬텀 각성 / 도주 처벌 / 킬 카운터 처벌 / Tank 재생·분열 — 축 경계 교환 카드는 전 회차에 없음
- **QA 데이터**: 유일한 리포트(2026-05-22)는 시뮬레이션 차단 상태로 픽률 데이터 없음. 설계 추론 기반으로 Dps·Swarm·Debuff 축의 스포너 다양성 공백을 식별해 제안함

## 1. ReplaceWispsToPhantom — 위스프 생산선을 팬텀으로 전환

- **카테고리**: 패시브 — 교체 (Swarm 축)
- **효과 모델**: Wisp 스포너 1개의 출력 종을 Phantom으로 영구 변경. 이후 해당 스포너는 Phantom을 고정 주기로 지속 스폰. 전환 시 필드에 살아있는 Wisp는 그대로 유지 (즉살 없음). 추가 Wisp 스포너가 없으면 시각 피드백("전환 없음")만 표시하고 효과 종료.
- **구현 패턴**: `ReplaceWispsToWraithEffect` 와 동일 구조 — `IBattleContext.Spawners` 순회 후 `SpawnerType == EMonster.Wisp` 인 첫 스포너의 `OutputType = EMonster.Phantom` 변경. 기존 Spawner 교체 패턴 재사용.
- **시너지 후크**:
  - `PhantomMoveSpeedBoost` — 전환 직후 스폰되는 Phantom에 이속 버프 즉시 적용
  - `SpawnPhantoms` — 같은 픽에서 함께 고르면 Phantom 동시 출력 2배
  - `SpawnerHaste` — 스폰 주기 단축과 시너지 → Wisp 생산선 전환 + 가속 = 팬텀 홍수
  - `Swarm Tier 2 (5장)` — Swarm 빌드 카운트에 기여해 모든 스포너 주기 ×0.85 발동 가속
- **밸런싱 포인트**: Wisp(HP 200, 느림)를 Phantom(HP 30, 빠름)으로 교체 — 탱킹력이 크게 감소하는 대신 필드 머릿수·이동속도 급증. Tank 빌드를 완전히 포기하고 Swarm 올인을 선택할 때 사용하는 고위험 카드. 영웅이 범위 공격형이라면 역효과 가능 → 플레이어가 상황 판단 필요.
- **구현 비용 추정**: 1 (기존 교체 클래스 복사 후 대상 Enum만 변경)
- **중복 재검증**: ReplaceWispsToWraith는 Tank→Tank(동축 업그레이드). 본 카드는 Tank→Swarm(축 경계 전환). 기존 14회차 루틴에 Wisp→Phantom 교체 제안 없음.

## 2. ReplaceReapersToPlague — 리퍼 생산선을 플레이그로 전환

- **카테고리**: 패시브 — 교체 (Debuff 축)
- **효과 모델**: Reaper 스포너 1개의 출력 종을 Plague로 영구 변경. 이후 해당 스포너는 Plague를 지속 스폰. 전환 시 필드의 기존 Reaper는 유지. 추가 Reaper 스포너가 없으면 효과 없음 + 시각 피드백.
- **구현 패턴**: `ReplaceReapersToHexEffect` 와 동일 구조 — `SpawnerType == EMonster.Reaper` 첫 스포너의 `OutputType = EMonster.Plague` 변경.
- **시너지 후크**:
  - `PlagueSlowBoost` — 전환 후 Plague 수가 늘어나 SlowFactor ×0.75 둔화 스택이 빠르게 누적
  - `SpawnPlagues` — 이미 Plague 스포너가 하나 있는 상태에서 전환 카드까지 쓰면 Plague 생산 3경로 확보
  - `HeroPoisonAura` — 둔화로 영웅 이동 거의 봉쇄 + 독장판 DPS 지속 → 탈출 불가 콤보
  - `Debuff Tier 2 (5장)` — HeroAttackDown 자동 등록 발동 가속
- **밸런싱 포인트**: Reaper(DPS 40, 최고 딜러)를 Plague(DPS 5, 유틸)로 교체 — 순수 화력이 크게 줄어드는 대신 둔화 밀도가 폭증해 영웅 이동을 완전히 봉쇄 가능. 2~3분 이내에 적을 죽여야 하는 빠른 킬 전략을 포기하고 "느리게 갉아먹기" 전략으로 전환. 둔화 중첩이 최대화되면 영웅 이동속도가 사실상 0에 수렴 → 나머지 몬스터가 쉽게 딜.
- **구현 비용 추정**: 1 (기존 교체 클래스 복사 후 Enum 변경)
- **중복 재검증**: ReplaceReapersToHex는 Dps→Dps(동축 업그레이드). 본 카드는 Dps→Debuff(축 경계 전환). 2026-05-30 독 연쇄 루틴은 Plague 강화 수치 카드이며 교체 카드 아님. 중복 없음.

## 3. ReplaceWraithToHex — 레이스 생산선을 헥스로 전환

- **카테고리**: 패시브 — 교체 (Dps 축)
- **효과 모델**: Wraith 스포너 1개의 출력 종을 Hex로 영구 변경. 이후 해당 스포너는 Hex를 지속 스폰. 전환 시 필드의 기존 Wraith는 유지. 추가 Wraith 스포너가 없으면 효과 없음 + 시각 피드백.
- **구현 패턴**: 기존 교체 클래스 패턴 동일 — `SpawnerType == EMonster.Wraith` 첫 스포너의 `OutputType = EMonster.Hex` 변경.
- **시너지 후크**:
  - `HexRangeBoost` — 사거리 ×1.4 이후 전환으로 Hex 수 급증 → 원거리 포화 밀도 폭발적 증가
  - `ReplaceReapersToHex` + `SpawnReapers` — 세 경로에서 Hex 스폰 가능 (원래 Hex 스포너 + Reaper→Hex + Wraith→Hex) → 후방 원거리 포격 최대화
  - `Frenzy` (액티브) — 전체 공격속도 +50% 시 Hex 밀집 화력이 극대화
  - `Dps Tier 3 (7장)` — Reaper·Hex Range ×1.3 발동 가속
- **밸런싱 포인트**: Wraith(HP 500, 최강 탱커)를 Hex(HP 60, 원거리)로 교체 — 탱킹력 최대 감소. 영웅이 Wraith 벽을 돌파해오는 압박을 완전히 포기하는 대신, 원거리 Hex 밀집 화력으로 영웅의 HP를 원거리에서 집중 삭감. "벽 없는 총격대" 전략 — 영웅이 돌격하면 Hex가 밀집 화력으로 순식간에 녹임. 영웅이 근접 특화(고범위·고공속)면 Hex가 빨리 죽어 역효과.
- **구현 비용 추정**: 1 (기존 교체 클래스 복사 후 Enum 변경)
- **중복 재검증**: Wraith 교체 카드는 기존 MVP 28장에 없음 (ReplaceWispsToWraith는 대상이 Wisp이고 Wraith로 변환). 레이스·팬텀 각성(2026-06-07)은 스탯 부스터이며 교체 카드 아님. 중복 없음.

## 4. 공통 테마 고찰

**테마**: 크로스 축 스포너 전환 — "생산선 방향을 바꾸는 전략적 희생"

현행 MVP 28장의 교체 카드 2장(ReplaceWispsToWraith, ReplaceReapersToHex)은 모두 **같은 축 내 업그레이드** (Wisp→Wraith: 더 강한 탱커 / Reaper→Hex: 더 원거리 딜러)다. 플레이어는 교체 카드를 써도 여전히 같은 축 전략을 유지하게 된다.

본 3장은 이와 달리 **축 경계를 넘는 영구적 전환**을 제공한다 — 탱커 생산선을 팬텀(Swarm)으로, 딜러 생산선을 플레이그(Debuff)로, 최강 탱커를 원거리 딜러(Dps)로. 이 카드들은 "이 축은 포기한다"는 결단을 요구하며, v0.2의 더 풍부한 빌드 다양성의 핵심 레이어가 된다.

**QA 공백 분석 기반**: 실제 픽률 데이터는 없으나, 기존 교체 카드 2장이 같은 축 내 선형 선택지임을 감안하면 **"한 축을 다른 축으로 버리는 결단" 카드가 완전히 비어 있다**. 이 공백을 채우면 v0.2 빌드 다양성이 기하급수적으로 늘어난다 — 현재의 4축 × 순수 빌드 외에, "Tank 포기 + Swarm 올인", "Dps 포기 + Debuff 봉쇄", "Tank 반포기 + Dps 강화"가 추가 가능.

**선택 시 이 테마를 고른 이유**: 기존 루틴 14회차 전부를 검토한 결과, 스탯 부스터·DoT 조합·처벌 트리거·밀도 압박·지속 시너지는 여러 차례 다뤄졌으나, **생산 방향 자체를 뒤집는 교체 카드 심화**는 전무함. 구현 비용이 가장 낮은(1/5) 카드군이면서 설계 영향이 큰 레버리지 아이디어.

## 6. 쉬운 설명 (비개발자 요약)

지금 게임에서 카드를 고를 때, 같은 종류의 몬스터를 더 강한 같은 종류로 바꾸는 카드는 있습니다 (예: 약한 위스프 공장을 강한 레이스 공장으로 교체). 하지만 전혀 다른 종류의 몬스터 공장으로 바꾸는 카드는 아직 없습니다. 예를 들어 "느리지만 든든한 탱커 공장을 없애고, 빠르게 달리는 팬텀 무리 공장으로 교체" 같은 대담한 전략을 쓸 수 없습니다. 이런 카드를 쓰면 한 가지를 완전히 포기하는 대신 다른 전략에 올인할 수 있어서, "나만의 기발한 전술"을 만들 수 있습니다. 그래서 오늘 제안하는 카드 3장은: 위스프 공장을 팬텀 공장으로, 리퍼 공장을 플레이그 공장으로, 레이스 공장을 헥스 공장으로 완전히 바꿔버리는 "역발상 교체 카드"입니다.
