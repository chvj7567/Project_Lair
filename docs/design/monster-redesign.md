## § 헤더

- **목표**: 기존 몬스터 6종(도깨비불·망령·사신·저주술사·역병귀·환령)의 몸 그림 48장(풋내기·T1~T3 몸 시트 24 + 발광 마스크 24)을 **같은 규격·같은 파일**로, **한국 설화·민속 모티프**(도깨비·원귀·저승차사·무녀·역신·그슨대)를 재해석한 마스코트형 캐릭터로 다시 그린다.
- **검증 가설**: (1) 종족마다 설화 모티프 + 한 문장 성격 + 한국적 시그니처 소품(방망이·옷고름·갓·방울·호리병·노리개)을 주면 30px 크기 전투 화면에서도 6종이 즉시 구분되고 애착(도감·쇼케이스 체류)이 오른다. (2) 주색을 종족 색 계열에 묶어 두면 설화형으로 실루엣이 바뀌어도 카드·시너지 색·등급 이펙트와 어긋나지 않는다. (3) 그림만 바꾸고 PPU·슬라이스·클립·데이터를 동결해도 전투 판정·HP바·등급 연출이 그대로 동작한다.
- **현재 단계 범위 적합성**: **범위 안**. 기존 6종 시트의 그림 교체이며 신규 몬스터·등급별 몸 시트·신규 이펙트 시트·코드·프리팹·데이터 변경이 없다(§1). 몬스터 아이콘 6장·카드 아이콘은 범위 밖(§1.2, 결정 Q2).
- **핵심 메커니즘**: 규격·`.meta` 를 **동결**하고 픽셀 내용만 바꾼다. GPT(Codex CLI)로 ① 종족별 대표 정지 시안 → ② 진화 라인업 시안 → ③ 시트 24장(시트당 가로 이미지 2장, 원본 셀 256px)을 만들고, 기존 추출 도구를 **고정 PPU 모드**(기존 PPU 에 맞춰 그림 크기를 역산)로 돌려 48장을 만든다. 각 단계마다 사용자 승인 후에만 다음 단계로 가며, Assets 교체는 비교 페이지 승인 후 한 번에 한다.

## 6. T1~T3 진화 공통 규칙

`monster-2d-conversion.md` §6.3.3 의 단계 의미를 그대로 쓴다.

| 단계 | 상점 강화 Lv | 의미 | 정량 기준(X-T3, 풋내기 대비) |
|---|---|---|---|
| 풋내기 | 0 | 견습 | - |
| T1 | 1~2 | 시그니처·정체성 모티프 확대, 금 없음 | 실루엣 밖 새 면적 ≥ 6%, 최대 돌출 ≥ 3 texel |
| T2 | 3~4 | 금 장식 등장(S4 금 팔레트) | ≥ 14%, ≥ 5 texel |
| T3 | 5 | 몸 밖 요소로 실루엣 외곽 확대, 대장 위엄 | ≥ 25%, ≥ 7 texel |

- 모든 단계에서 **얼굴(눈 모양·간격·위치)·몸 주색·시그니처 소품은 유지**. 단계가 올라가도 같은 캐릭터로 읽혀야 한다.
- 상한: 높이 x1.55 · 폭 x1.60(§3.2), HP바 ±0.05u(R6).
- 금 장식은 발광하지 않는다(빛은 눈·보석·불꽃·기포·혼불·방울·부적 문양에만).
- **설화 맥락 진화 규칙**: T1 = 그 설화의 생활 소품이 늘어남(샅바·오랏줄·부적·매듭 술), T2 = 신분·격을 나타내는 금 장신구(금 비녀·갓 정자·금관·금 방울·금 노리개), T3 = 설화 속 우두머리 이름을 얻는 모습(도깨비 대장·아랑 원귀·강림차사·큰무당·역신 우두머리·큰 그슨대) + 몸 밖 요소(도깨비불·혼불·오방기·적패지 깃발·그림자 날개). 단청 문양은 T2 이상의 금 장식 테두리에만 쓴다.

## 7. 등급 이펙트와의 겹침·가독성

등급 연출(`monster-grades.md`)은 몸 그림 위·아래·뒤에 겹친다. 새 그림은 아래를 지킨다.

| 연출 | 위치 | 새 그림 규칙 |
|---|---|---|
| 몸 외곽 발광(2~5등급) | 몸 외곽선 바깥 | 외곽선이 닫혀 있고 어두워야 발광과 몸이 분리된다(S2). 외곽선 밖 반투명 번짐 금지(S8) |
| 바닥 오라(2~5등급) | 발밑 타원 | 몸 바닥 아래로 내려가는 큰 요소 금지(역병귀 드립 기포는 바닥선 아래 6px 이내) |
| 4등급 불꽃 기둥 2개 | 몸 양옆 | T3 폭 상한 x1.60 안에서 좌우 장식은 몸 높이의 아래 60% 에 둔다(기둥 윗부분과 겹침 최소화) |
| 5등급 햇살 후광 | 몸 뒤 머리 높이 | 머리 위 장식이 후광 중심을 가리는 면적 ≤ 후광 원 면적의 40%(비교 페이지 V-R5 에서 확인) |
| 몸 밝기 맥동(5등급) | 몸 전체 | 하이라이트가 이미 흰색(RGB ≥ 245)인 면적 ≤ 몸의 5%(맥동 시 날아감 방지) |
| 등급 크기 배율 x1.075~1.30 | 전체 | 그림 규칙 없음(코드 배율) |

주색이 등급 이펙트 색과 같은 계열(§3.3)이라 발광이 몸에 녹아들 수 있다. 그래서 외곽선 `#0A0D14` 와 몸 그림자 톤(주색보다 명도 30% 이상 낮음)이 필수다.

## 8. 발광 마스크 재생성

- 규약 불변: 연속값(0~255) 그레이스케일, 시트와 같은 크기·같은 인덱스, 반경 1.5px 가우시안 완화, 대기 F0 면적비(마스크 ≥ 128 ÷ 불투명 픽셀) **5~20%**(게이트 X7·X-T7), 금 장식 제외.
- 발광 부위는 §5 각 표의 "발광 부위" 행이 SoT 다.
- 현행 자동 추출 규칙(`monster_v4_mask.py`, 예: 망령 룬 RGB ≥ 235 · 저주술사 G ≥ 220)은 옛 그림의 색 임계값이라 **새 그림에 맞춰 종족별로 다시 정한다**. 생성 프롬프트가 발광 부위를 "그 종족에서 가장 밝고 채도 높은 고유 톤"으로 칠하게 하고(§9.3), 규칙은 그 톤의 색상·명도 범위 + 부위 ROI 로 잡는다.
- 자동 규칙으로 못 잡는 프레임은 수동 보정(사각형 추가/삭제) 허용(`monster-tier-sheets.md` Q3 선례). 적용 건수는 `measured.manualEdits`.

### 10.1 반복 규칙

- 종족별로 독립 진행한다. 승인된 종족은 잠그고(이후 단계 입력으로 고정) 다른 종족만 다시 뽑는다.
