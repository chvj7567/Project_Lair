씬 배경 리뉴얼

전투(챕터 1~5) · 마을 · 로딩 화면의 배경 그림 7장을, 길과 자리는 그대로 두고 더 정교하게 다시 그립니다. 게임 규칙·화면 구성은 바뀌지 않습니다.

지금 어떤 상태인가요

전투그림 5장

둥근 투기장 + 위쪽 석벽. 챕터마다 분위기(숲·성채·용광로·서리 성당)가 다릅니다. 영웅과 몬스터가 싸우는 5분 내내 보이는 배경입니다.

마을그림 1장

옥좌의 방. 상점·도감·게시판·묘비·왕관 받침대 같은 메뉴 소품이 그려져 있고 내 몬스터 6마리가 그 앞을 돌아다닙니다.

로딩그림 1장

신전과 마법진. 몬스터 6마리가 마법진 위에 서서 전투를 기다립니다.

세 화면 모두 이미 금테·소울 초록 톤으로 한 번 다듬어져 있습니다. 하지만 몬스터와 UI 는 새 그림으로 바뀐 반면 배경만 거친 도트 질감이라, 화면 안에서 질감 차이가 납니다.

무엇이 달라지나요

  • 돌바닥·벽·금속 장식의 질감과 디테일이 풍부해집니다.
  • 횃불·촛불·마법진 빛이 그림 속 같은 자리에서 그대로 빛납니다.
  • 몬스터가 서 있는 바닥은 지금처럼 차분하게 유지되어 유닛이 또렷하게 보입니다.
  • 분위기 빛(조명)은 지금처럼 게임이 실시간으로 얹습니다 — 그림 자체에는 빛을 굽지 않습니다.

달라지지 않는 것: 영웅이 오는 길, 스포너 위치, 메뉴 위치, 몬스터가 돌아다니는 자리, 버튼, 저장 데이터.

자리를 지켜야 하는 곳

초록 칸은 몬스터·영웅이 보이는 곳이라 바닥이 차분해야 합니다. 점선 칸은 화면 UI 가 덮는 곳입니다.

어떻게 그릴까요 — 세 가지 방법

A. 도트 그대로 정교하게

지금의 거친 격자를 유지한 채 디테일만 보강. 가장 안전하지만 질감 차이가 완전히 사라지지는 않습니다.

C. 새로 그린 뒤 도트로 맞추기추천

AI 로 풍부하게 그린 그림을 지금의 격자·색에 맞춰 줄여 넣습니다. 조명·위치가 그대로라 안전하고, 질감은 좋아집니다. 잘 안 되는 장은 A 로 되돌립니다.

B. 고해상도 회화풍

몬스터처럼 선명한 큰 그림. 가장 닮아 보이지만 지금의 빛 표현(계단식 조명)과 맞지 않아 화면 렌더링 방식을 바꿔야 하므로 이번에는 하지 않습니다.

진행 순서

1. 준비자리 지도(가이드) 만들기, 현재 상태 점검
2. 마을 시범한 장만 먼저 그려 보고 방식을 확정
3. 로딩같은 방식으로
4. 전투 1장투기장 기준틀 확정
5. 전투 2~5장챕터별 분위기만 바꿔서

장마다 화면을 직접 보여 드리고 승인받은 뒤 다음으로 넘어갑니다.

확인할 것들

결정해 주세요

  2. 분위기는? 지금의 석조 홀·금·초록 톤 유지 / 몬스터처럼 한국 설화 느낌 추가 — 추천: 지금 톤 유지
  3. 첫 장은? 마을 / 로딩 / 전투 — 추천: 마을
  4. 마을·로딩이 진행도에 따라 달라지게 할까요? — 추천: 아니요(이번엔 한 장씩만)
  5. 도트 거칠기는? 지금 그대로 / 더 곱게 — 추천: 지금 그대로
  6. 스포너 자리 금빛 링을 챕터 전체에서 통일할까요? (지금은 5장에만 그려져 있고 1장엔 없음) — 추천: 모두 빼기(게임이 따로 그림)
  7. 화면 가장자리(일반 16:9 에서 안 보이는 부분)의 디테일은 포기해도 될까요? — 추천: 포기
