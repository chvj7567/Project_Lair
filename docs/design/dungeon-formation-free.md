# 던전 자유 편성 — 기획서

> 2026-11-22 · Project Lair v0.3 · 사용자 승인 · 적용 기준 · 기존 기획 [던전 편성](dungeon-formation.md) · [플레이어 가이드](dungeon-formation-free.html)

## § 헤더

- **목표** — 상점에서 몬스터별 강화 티어를 직접 구매하고, 출격 전에 티어와 등급을 보고 보유 몬스터와 비워 둘 둥지를 정한다.
- **검증 가설** — 편성으로 바꾼 배치와 소환 밀도가 영웅별 대응을 바꾸고, 같은 카드 제안도 편성에 따라 다른 판단을 만든다.
- **현재 단계 범위 적합성** — v0.3 범위에 기존 6종·5등급·6둥지 자유 배치와 미배치, 상점 체급의 직접 티어 구매 및 관련 UI·세이브·전투 연동을 2026-11-22 승인했다. 이 개정안이 기존 종족 고정 편성 규칙보다 우선한다.
- **핵심 메커니즘** — 보유 몬스터를 배치하거나 빈칸으로 둔다. 같은 몬스터·같은 등급은 한 곳에만 놓는다. 전투 카드 후보는 편성·빈칸·봉인에 상관없이 기존 덱에서 무작위로 나온다.

## 1. 플레이어 규칙

| 상황 | 결과 |
|---|---|
| 보유한 군주 도깨비불과 정예 도깨비불 | 서로 다른 등급이라 함께 편성 |
| 군주 도깨비불과 군주 사신 | 서로 다른 몬스터라 함께 편성 |
| 선택한 둥지에 이미 배치된 후보 | ‘현재 배치’로 표시하고 다시 골라도 그대로 |
| 미배치 후보를 선택 | 선택한 칸에 배치. 그 칸에 있던 몬스터는 보유 목록으로 돌아감 |
| 다른 둥지에서 사용 중인 후보를 선택, 선택 칸이 비어 있음 | 몬스터가 선택 칸으로 이동하고 원래 칸은 빈칸 |
| 다른 둥지에서 사용 중인 후보를 선택, 선택 칸이 차 있음 | 두 둥지의 몬스터를 교환. 동일 몬스터·동일 등급은 중복되지 않음 |
| ‘이 둥지 비우기’ | 선택한 몬스터가 보유 목록으로 돌아가며 해당 둥지에서 자동 소환되지 않음 |
| 보유하지 않은 등급 | 목록에 표시하지 않고 출격 편성에 넣을 수 없음 |
| 배치 수 및 비용 | **0~6칸** 모두 출격 가능. 종족별 별도 상한·코스트 없음. 보유 등급이 다르면 한 종을 최대 5칸까지 배치 가능 |
| 모두 빈 채로 출격 | 출격 버튼 활성. ‘둥지에서 몬스터가 자동으로 소환되지 않아요’ 안내. 기존 전투와 카드 발동은 진행 |

영웅 한 명, 300초, HP 패시브 임계, 기존 액티브 발동 30/90/150/210/270초, 전투 중 카드 효과 기본 수치는 유지한다. 빈 둥지는 몬스터를 자동 생성하지 않으며 기존 글로벌 개체 수 제한에 몬스터를 기여하지 않는다. 몬스터 등급의 HP·공격력 배율은 유지한다.

## 2. 마을에서 출격까지

1. **1-1 클리어 전** — ‘방어하기’에서 기본 편성으로 바로 출격한다.
2. **1-1 클리어 이후** — ‘방어하기’가 편성 팝업을 연다. 첫 승급 전에도 위치 변경·비우기가 가능하다. 직전 저장 편성, 첫 선택 1번 둥지, 목록은 ‘전체’.
3. 둥지를 눌러 보유 몬스터를 고르거나 ‘이 둥지 비우기’를 누른다. 선택한 둥지와 목록 필터를 유지한다. 이미 배치된 후보는 선택 대상에 따라 이동하거나 교환한다.
4. ‘기본 편성’은 기존 순서와 종족별 보유 최고 등급으로 돌아간다. 선택은 1번 둥지, 필터는 ‘전체’. 기본 상태가 화면에 표시돼도 지금 출격해야 저장된다.
5. 닫기·뒤로 가기·Esc는 이번 편집을 버리고 마을로 돌아간다. ‘출격’만 편성을 저장한다. 편성 수정 없이 다시 싸울 때 팝업에서 ‘출격’ 한 번으로 진행한다. 0칸도 하단 안내와 함께 같은 흐름으로 출격한다.

기본 순서는 1 도깨비불 / 2 사신 / 3 저주술사 / 4 망령 / 5 역병귀 / 6 환령. 기본 순서는 초기 편성과 봉인 대체에 쓰인다. 기본 편성은 기존 6종의 보유 최고 등급을 원래 둥지마다 하나씩 배치하며 각 종의 현재 강화 티어를 사용한다.

## 3. 편성 팝업 UI

기준 화면 **1280×720**, 기존 큰 팝업 **1136×640**, 좌상단(72, 40)에서 시작. 가로 폭 1136 = 좌우 여백 44씩 + 내용 1048. 헤더 52, 본문 424, 하단 60, 두 간격 12, 위아래 여백 40씩을 합해 640. 본문 폭 **232 + 12 + 392 + 12 + 400 = 1048**. [공통 UI 아트 규격](ui-art-refresh.md)과 현행 회남색 바탕·금색 선택·붉은 출격·보라색 봉인 톤을 따른다.

| 영역 | 표시 및 조작 |
|---|---|
| 상단 | ‘던전 편성’과 닫기. 닫기 버튼 44×44 기준 |
| 왼쪽 · 침입 영웅 | 스테이지·난이도·초상·기존 규칙. 봉인 규칙의 실제 둥지 번호, 배치 몬스터, 해제 조건. 모든 둥지가 비면 ‘봉인할 둥지가 없어요’ |
| 가운데 · 둥지 6곳 | 실제 상대 위치를 위 3–2, 가운데 4–영웅–1, 아래 5–6으로 표시. 찬 칸은 번호·아이콘·이름·등급과 별도의 강화 티어 칩, 빈칸은 번호와 ‘빈 둥지’만. 선택은 금 테두리, 봉인은 보라색과 ‘봉인 예정’ 문구 |
| 오른쪽 · 보유 몬스터 | ‘N번 둥지’와 ‘이 둥지 비우기’. 빈 둥지를 선택하면 비우기 버튼 비활성. 전체 및 기존 6종 필터, 기본 종 순서·종 안 높은 등급 우선, 목록 높이 안에서 세로 스크롤. 아이콘·이름/등급·역할·강화 티어 칩·상태 표시 |
| 하단 | ‘N / 6 배치’, 조작 결과, ‘기본 편성’, ‘출격’. 0칸이면 조작 결과와 별도로 ‘둥지에서 몬스터가 자동으로 소환되지 않아요’ 표시. 출격 가능 |

- 보유 목록 행 높이 최소 48, 본문 글자 최소 13, 보조 글자 11. 짧은 가로 화면은 목록 우선 스크롤 및 하단 버튼 안전 영역, 좁은 브라우저는 요약 → 둥지 → 목록 순으로 세로 배치한다. 1280×720, 1280×800, 가로 모바일에서도 등급·강화 티어·봉인·비우기 안내를 읽을 수 있게 한다.
- 마우스와 터치는 같은 입력 흐름이다. 키보드 Tab으로 영역 접근, Enter/Space로 동작, Esc로 닫기. 교환·이동 직후 선택한 후보의 포커스와 목록 스크롤을 유지한다. 비우기 버튼이 비활성으로 바뀌면 선택한 둥지 타일로 포커스를 되돌린다. 닫기 후 ‘방어하기’에 포커스를 돌려준다.
- 상태 문구: ‘현재 배치’, ‘N번 사용 중 · 이동’, ‘N번 사용 중 · 교환’. 예를 들어 빈 3번에 4번 몬스터를 고르면 ‘4번 둥지의 몬스터를 3번으로 옮겼어요’. ‘이 둥지 비우기’를 누르면 ‘3번 둥지를 비웠어요’. 각각 상태와 봉인 예고를 즉시 갱신한다.
- 카드 안내는 편성 팝업에 ‘편성과 관계없이 카드가 무작위로 나와요’, 실제 카드 선택창에는 효과별 조건 안내를 둔다.

### 등급과 강화 티어 표기

- **등급**은 승급으로 보유하는 풋내기·견습·숙련·정예·군주다. 등급은 이름 옆이나 아래에 표시한다. **강화 티어**는 상점에서 기준 몬스터별로 `기본 → T1 → T2 → T3`를 직접 구매하는 몸 외형과 HP·공격력 강화 단계다. 둥지에서는 등급 옆에 작은 칩, 보유 목록에서는 이름 아래 역할 옆에 같은 칩을 표시한다.
- 기준 몬스터의 상점 구매 결과에서 현재 티어를 표시한다. 저장은 기존 `MetaProfile.ShopLevels`의 기준 몬스터 `Enhance_<기준 몬스터>` 항목을 재사용한다. 같은 종의 모든 등급이 하나의 구매와 티어를 공유한다. 예: 도깨비불의 T3를 구매하면 군주·정예 도깨비불 둘 다 **T3**이며, 두 등급은 서로 다른 배치 후보다.
- 중복 판단은 **몬스터와 등급**으로 한다. 티어는 표시 정보이며 해당 판에 저장하거나 배치 식별자로 사용하지 않는다. 기본/빈 표시를 구분한다. 배치된 미강화 몬스터에는 ‘기본’ 칩이 있고, 빈 둥지에는 티어 칩이 없다.
- 칩은 기존 프레임 계열과 읽을 수 있는 텍스트로 표현하며 색만으로 구분하지 않는다. 칩 문자 최소 11px(1280×720 기준), 등급과 한 그룹에서 좁은 칸에 줄바꿈 허용. 봉인 예정 표지와 같은 칩을 사용하지 않는다. 터치에서도 글자가 항상 보이며, 포커스/접근성 이름은 ‘군주 도깨비불, 강화 T3’처럼 두 속성을 독립적으로 읽는다. 상세 이름은 도감의 ‘기본 시트’, ‘강화 T1~T3’ 표현을 따른다.

상점과 편성의 짧은 표기는 **기본 / T1 / T2 / T3**, 상세 표기는 **기본 시트 / 강화 T1 / 강화 T2 / 강화 T3**. 레벨 범위는 구버전 저장 이행에서만 쓴다. 전투 스포너 상태 HUD의 기존 체급 배지 자리에는 T1~T3를 표시하고, 기본일 때 숨기는 기존 동작을 유지한다. 도감은 기존 등급×티어 열을 쓴다. 티어 해금 조건 문구만 ‘상점에서 강화 T2 구매’처럼 바꾸고 등급 보유·발견 등의 조건은 유지한다. 던전 중 카드에 따른 둥지 강화·시너지 티어는 각각 기존 이름을 유지한다.

### 상점에서 강화 티어 구매

‘몬스터 강화’의 기준 몬스터 6종에 있던 **체급 Lv1~5만 티어 강화**로 전환한다. 등급 승급과 각성·둥지·특성, 영주/전역 강화는 현재 재화·단계를 유지한다. 상점에서 특정 등급을 고르지 않고 몬스터의 이름과 현재 티어를 확인한다.

| 현재 → 구매 후 | 소울 | 보유 티어 누적 비용 | 구매 후 HP·공격력 배율 | 기존 대응 |
|---|---:|---:|---:|---|
| 기본 → T1 | 390 | 390 | ×1.3924 (+39.24%) | 기존 Lv2, 150+240 |
| T1 → T2 | 998 | 1,388 | ×1.93877776 (+93.88%) | 기존 Lv4, 384+614 |
| T2 → T3 | 983 | 2,371 | ×2.2877577568 (+128.78%) | 기존 Lv5, 983 |

- **상점 UI** — 기존 몬스터 강화 행의 체급 칸을 ‘티어 강화’로 변경한다. 현재 티어, 다음 티어, 소울 비용 및 구매 전후 HP·공격력 배율을 한 상자에서 보여준다. 예: ‘T1 → T2 · 998 소울’, ‘HP·공격력 ×1.39 → ×1.94’. 수치는 내부 정밀도로 적용하고 HUD 예고만 소수점 둘째 자리로 반올림한다.
- 다음 티어만 구매한다. 기본에서 T2/T3로 건너뛰는 구매는 없고 중간 Lv 경유나 별도 해금 조건도 없다. 클릭 전 잔액과 가격을 확인한다. 구매가 성공하면 잔액이 한 번만 줄고 티어와 배율 예고가 갱신된다. 소울이 부족하면 비용과 부족분을 표시하고 구매는 비활성. T3는 ‘최대 티어’와 현재 배율 표시. 구매 티어는 모든 보유 등급에 즉시 반영하며 다음에 얻는 같은 종의 등급도 같은 티어를 사용한다. 기존 티어에 필요한 데이터가 누락되면 임의 가격으로 구매하지 않으며 해당 구매만 비활성화한다.
- 기존 가격은 `floor(150 × 1.6^현재 Lv)`로 150/240/384/614/983, 효과는 종족별 `1.18^Lv`였다. 각 티어의 이전 마지막 Lv를 대표로 사용하므로 기존 만강 비용과 최종 성능은 같고, **첫 강화가 150→390으로 늦어지며 구매 횟수는 5회에서 3회로 줄어든다**. T2와 T3 가격은 기존 구매 단위 묶음으로 정했으므로 T3가 T2보다 15소울 낮다. 별개 등급 배율·각성·둥지·특성과 기존 곱연산 순서를 유지한다.
- 구버전 Lv1은 T1로, Lv3은 T2로 올라가며 기존 같은 티어 내에서 HP·공격력이 기존 대비 ×1.18이 된다. 이행 시 추가 소울 차감·환불 없음. 상향은 구매했던 외형과 전투 성능을 모두 유지하려는 비용이다. 기존 기록과 랭킹 규칙은 유지하며 등급·육성과 함께 성능 격차를 읽는다.

## 4. 전투 연계

| 항목 | 제안 |
|---|---|
| 카드 등장 | 각 패시브/액티브 트리거에서 해당 기존 카드 풀의 적격 후보를 기존 방식으로 무작위 추첨한다. 편성 종족·등급·빈칸·봉인은 후보 자격, 가중치, 추첨 난수에 영향을 주지 않는다. 현재 픽 제한과 데일리 시드는 유지한다. |
| 효과와 안내 | 카드 설명·선택은 유지한다. 선택 카드에 대상이 필요한 효과가 있고 그 효과의 대상이 없으면 ‘이 효과를 받을 둥지가 없어요’, ‘이 효과를 받을 몬스터가 없어요’처럼 **해당 효과만** 표시한다. 선택을 막거나 카드를 숨기지 않는다. 스포너 한정/필드 대상/독립 효과를 구별하고 복합 카드에 ‘카드 전체 효과 없음’을 붙이지 않는다. |
| 대상 변경 | 역병귀 둥지 소환수 증가 카드는 역병귀 둥지가 없으면 증가할 둥지가 없다. 도깨비불·망령 공격력 카드는 두 효과가 독립이며 일치하는 편성/필드 몬스터에 적용된다. 영구 효과는 기존 등록·후속 대상 적용 방식이 유지된다. 영웅과 필드에 직접 작용하는 기존 효과가 몬스터 미배치만으로 차단되지는 않는다. |
| 카드 후보 부족 | 기존 제외 조건으로 1~2장만 적격이면 가능한 만큼 표시. 0장이면 창을 열거나 시간을 정지하지 않고 그 트리거를 소비한다. 빈 편성만으로 후보 수가 줄지 않는다. |
| 봉인 첫 순위 | 대상 종의 모든 등급 중 **미봉인·채워진 최저 번호 1곳**. 예: 역병귀가 2번과 5번이면 2번을 봉인. |
| 봉인 대체 | 대상 종이 없으면 그 종의 기본 위치가 **채워져 있고 미봉인일 때** 해당 둥지 1곳, 아니면 가장 번호가 낮은 미봉인·채워진 둥지 1곳. 모두 비었거나 추가로 잠글 수 있는 채운 둥지가 없으면 봉인 없음. |
| 봉인 UI와 월드 | 편집 때 예고 갱신, 적용과 해제 안내에는 실제 대상 몬스터 표시. 빈 둥지는 편집 UI와 전투 HUD/제단에서 빈 상태로 읽히며 자동 소환·봉인·둥지 전용 효과 대상에서 제외. 기존 발동·해제 조건 유지. |

현행 `BattleController.IsCardExcluded`는 픽 상한과 `IsCardSpeciesAbsent`를 둘 다 본다. 후자를 **추첨에서 분리**한다. `SpawnPlaguesEffect` → `IncrementSpawnerOutput`은 배치된 일치 둥지 전체를 대상으로 삼는다. `WispWraithPowerBoostEffect`는 두 몬스터의 효과를 따로 등록한다. `Card_Species`는 복합 카드·효과 전체의 대상 명세가 아니므로, 그 테이블의 종 목록만 보아 무효 표지를 붙이면 안 된다. 카드 선택 시점의 효과 대상이 비었다는 안내이며 이후 활성 여부를 재정의하지 않는다. 편성만으로 기존 시너지 단계가 오르지 않는다.

## 5. 저장과 승급 — 승인된 데이터 구조

현행 `EMonster`에 비어 있음을 표현하는 값은 없다. 정수 0은 도깨비불이다. **채워진 둥지만 행을 저장**하고, 기본 편성인지 수동 편성인지 프로필 플래그로 구분한다.

| 항목 | 기존 | 제안 | 관계·호환 |
|---|---|---|---|
| `MetaProfile.HasCustomFormation` | 필드 없음 | bool 신규. 기본 `false`, 수동 `true` | `false`이면 빈 행 목록이고 기본 자동 편성, `true`이면 목록의 유무대로 배치한 편성 |
| `MetaProfile.Formation` | 0행=기본, 정상 수동 6행 | 기존 리스트, 수동에서 0~6행 | 1~6 중 행이 없는 둥지는 빈칸. 0행+수동은 전부 비운 상태 |
| `FormationSlotEntry.Slot` / `Monster` | 번호+몬스터 값명 | 필드·형 그대로 | `Slot`은 `FormationSlot.slot`을 참조하며 중복 금지, `Monster`는 기존 `Race_Monster`의 유일 종·등급과 연결 |
| `MetaProfile.Version` | 13 | 14 | 편성·티어를 한 번에 이행. v13 이하 정상 6행은 수동, 0행은 기본. 체급만 이전 Lv를 대표값으로 이행 |
| `MetaProfile.ShopLevels`의 기존 `Enhance_*` 6행 | `ItemId + Level`, 구입 Lv0~5 | 필드는 그대로, 저장 대표값 0/2/4/5 | 각각 기본/T1/T2/T3. `ItemId`는 `ShopItem`의 기준 종과 연결. 다른 상점 항목의 값과 재화는 손대지 않음 |
| 신규 `EnhanceTier` 단계 데이터 | 없음 | `tier` (PK, 1~3), `levelEquivalent` (2/4/5), `soulCost` (390/998/983) | 기존 `MonsterSpecies` 효과의 6항목이 공통으로 참조. 0=미강화는 미구매 상태에서 도출. 배율은 기존 `ShopItem_Mul` 값의 `levelEquivalent` 지수로 계산 |
| `Race_Monster` / `RaceGrades` | 종별·등급별 데이터와 보유 최고 등급 | 필드 기존 유지 | 몬스터 등급이 보유 최고 등급 이하일 때 선택 가능 |
| `FormationSlot.slot/race` / `FormationConfig.unlockClearedStage` | 고정 종족과 해금 스테이지 | 필드 기존 유지, 해금 값 1 | `race`는 기본 편성과 봉인 대체 자리만 찾는다. 잠금 해제는 1-1 클리어 |

- **0칸 저장 예** — `HasCustomFormation=true, Formation=[]`. **기본 저장 예** — `HasCustomFormation=false, Formation=[]`. 수동 저장 예 — 2번과 6번 몬스터의 기존 행 2개, 나머지는 빈칸.
- **수동 편성은 승급 후에도 빈칸과 현재 몬스터를 유지**한다. 승급은 보유 목록에 새 등급을 추가한다. 기본 편성만 자동으로 새 최고 등급을 따라간다. 출격 시 현재 편성이 모든 칸에서 기본 편성과 같으면 기본 추적 상태로 저장한다. ‘기본 편성’ 후 닫으면 기존 저장을 유지한다.
- 버전 전환은 로컬과 클라우드 모두 정상 v13 저장의 슬롯·몬스터를 그대로 보존한다. 수정형 복원에서는 미보유·잘못된 몬스터 행을 비우고, 동일 몬스터·등급 중 가장 낮은 유효 슬롯만 남긴다. 슬롯 번호 범위 밖 행은 제외하고 동일 슬롯에 여러 행이 있으면 최초로 읽힌 유효한 항목 하나를 택한다. 빠진 칸을 기본 몬스터로 채우지 않는다. 제시 문구는 ‘사용할 수 없는 몬스터의 둥지를 비웠어요’.
- 기존의 편성 저장/복원 복사 경로에 플래그를 포함하고, 기존 클라우드 충돌 처리는 그대로 쓴다. 티어를 위한 신규 프로필 필드는 없다. 신규 콘텐츠 JSON은 공통 3행 티어 데이터뿐이다. 구버전 앱은 부분 편성을 기본으로 해석하고 이전 레벨 구매를 할 수 있다. 최신 앱은 구버전에서 수정된 Lv1·Lv3을 읽는 경우 v14 여부와 무관하게 같은 티어의 대표값으로 맞춘다. 서로 다른 앱 버전에서 슬롯 편집·구매를 동시에 하면 기존 프로필 충돌 방식이 적용된다.

| 이전 체급 저장값 | 신규 표시 | 최신 앱 이행 후 저장값 | 구매 없이 달라지는 것 |
|---|---|---:|---|
| 없음·0 | 기본 | 기존 0행은 미저장 유지, 기존 0값은 0 | 없음 |
| 1 | T1 | 2 | 외형 그대로, HP·공격력 ×1.18 |
| 2 | T1 | 2 | 없음 |
| 3 | T2 | 4 | 외형 그대로, HP·공격력 ×1.18 |
| 4 | T2 | 4 | 없음 |
| 5 | T3 | 5 | 없음 |

**정규화 범위** — 위 맵은 정확히 기존 `Enhance_Wisp/Wraith/Reaper/Hex/Plague/Phantom`만 쓴다. 음수는 0, 상한 초과는 5로 보정한다. 중복 `ItemId`가 보이면 가장 높은 유효 값을 보존한 뒤 한 번만 대표값으로 바꾼다. 정규화는 두 번 적용해도 같은 값이고 소울을 건드리지 않는다. 구매는 동일한 단계 표에서 가격·다음 값을 한 번 검증하고 소울과 대표값을 함께 저장한다. 체급의 기존 `maxLevel=5`는 구 저장·전투 호환용 상한이고 상점에는 레벨과 5단계 구매를 표시하지 않는다.

## 6. 모드별 적용

|---|---|

현재 전투와 탑·데일리 진입은 같은 저장 편성을 읽는다. 챕터와 탑은 그 흐름을 유지하고 데일리만 기본 편성으로 맞춘다. 하루 단위 도전에서 빈칸·중복 종 조합 및 봉인 위치 조건을 공통으로 만들 수 있다. 보유 등급에 따른 능력치 차이는 기존대로 남는다. 모든 모드에서 카드 추첨은 편성과 분리돼 있다.

## 7. 승인된 결정과 비교 기준

| 결정 | 승인안 | 비교안과 영향 |
|---|---|---|
| 0칸 출격 | 허용하고 ‘둥지에서 몬스터가 자동으로 소환되지 않아요’ 표시 | 최소 1칸 강제는 실수 방지 효과가 있지만 의도적인 전부 비움과 빈 편성 저장을 막는다. |
| 티어 성능 이행 | 기존 티어 마지막 Lv의 성능과 묶음 가격 | 기존 티어 첫 Lv를 쓰면 예전 Lv2·4에서 성능이 하락한다. 구간별 Lv를 숨겨 유지하면 UI가 단순해져도 동일 티어의 성능이 달라진다. |
| 승급 시 | 기본만 최신 등급을 따르고 수동 배치와 빈둥지 유지 | 자동 교체는 편리하지만 의도적으로 비우거나 고른 자리에 개입하게 된다. |
| 봉인 대상 부재 | 채워진 기본 위치, 그다음 채워진 최저 번호, 없으면 봉인 없음 | 종 미편성으로 언제나 규칙을 회피하면 해당 종을 빼는 역할이 과도하게 유리하다. |
| 적용 모드 | 챕터·탑은 저장 편성, 데일리는 기본 편성 | 자유 편성을 데일리에 적용하면 봉인과 사용 둥지 차이가 날짜별 성적 비교에 더해진다. |

[기존 강화 QA](../qa-reports/2026-07-24.md)는 종별 육성 집중 시 전투 시간이 다르게 움직였음을 보여준다. 자유 편성의 실제 결과는 다음 조건으로 확인한다.

- 동일 영웅·육성·유물·시드에서 6종 분산, 1종 3~5칸 집중, 빈칸을 섞은 조합을 각각 비교한다. 봉인 있는 판과 없는 판에서 승률·승리판 중앙 처치시간·종별 카드 적용 둥지 수·스폰 캡 도달 시간·선택 카드 종류를 기록한다.
- 동일 트리거·난수 상태·선택 이력에서 0·1·6칸 및 봉인 여부를 바꿔 패시브/액티브 제안이 같은지 확인한다. 실제 런에서는 진행에 따라 도달한 HP 트리거와 플레이어 선택이 달라질 수 있다.
- 플레이테스트에서는 같은 영웅 두 판 후 ‘왜 이 둥지를 비웠는지’, ‘같은 카드에서 무엇을 골랐는지’, ‘다음 판에 어떤 조합을 할지’를 묻는다. 입력 의도가 결과로 이어지는지와 무수정 재출격 흐름을 확인한다.
- 필수 확인 사례는 비우기, 0칸 출격, 빈칸 이동 및 찬 칸 교환, 0행 기본·수동 구별, 구버전 6행 및 클라우드 복원, 수동 승급 시 빈칸 보존, 동일 종의 다른 등급이 같은 티어를 보이는지 및 기본·빈칸 구별, T1/T2/T3 가격·구매·재화 부족, 구레벨 Lv1~5 보존/상향, 중복 이행 시 소울 미변경, 미배치 카드 표시와 복합 효과의 독립 동작, 봉인 예고/전투 일치, 해상도·포커스다.

## 8. 구현 요청사항

- `FormationRules` / `FormationDatabase` / `FormationSave` — 기존 종·등급 유효성, 다중 슬롯 중복, 빈 상태, 저장/이행/복원, 기본 자리와 봉인 판정. `GradePromotion`은 수동 편성을 자동 변경하지 않는다.
- `FormationViewModel` / `FormationPopup` / `FormationNestTile` / `FormationSpeciesRow` — 기존 팝업과 아이콘으로 빈 둥지·비우기·이동/교환·카운터·봉인 예고 및 둥지/후보 양쪽의 강화 티어 표시. 티어는 기준 종 강화에서 읽고 별도 티어 저장 필드를 추가하지 않는다. 탑/데일리/상점 안내와 기존 카드 선택창의 효과 대상 상태 안내까지 포함한다. 조건 안내의 계산은 표시 모델에 둔다.
- `BattleController` / `MonsterLooks` / `StageRuleContext` — 편성 해석 뒤 실제 전투에서 빈 둥지의 자동 소환과 관련 효과를 비활성화하고, 있는 슬롯은 원래 번호를 보존한다. 빈 슬롯을 스포너 배열에서 제거해 번호를 당기지 않는다. 편성이 없다는 코드의 기존 의미와 명시적인 0칸을 구별한다. 외형/필드/HUD가 빈칸을 도깨비불로 치환하지 않게 한다. 기존 고정 로딩 쇼케이스는 유지, 실제 편성 쇼케이스에만 빈자리를 적용한다.
- 추첨에서 종족 필터를 제외하고, 카드 선택 후보가 빈 경우 정상 재개를 확인한다. 스포너 전용 효과는 실제 출력이 있는 슬롯만 대상으로 보며 카드의 기존 독립 효과·미래의 대상 적용 경로는 보존한다.
- `ShopService`와 상점 표시 모델은 기존 6개 체급 행의 가격·구매·다음 티어에만 공통 단계 데이터를 읽고, 나머지 상점 공식은 유지한다. `MetaBattleBonus`, `MonsterLooks`, `MonsterEnhancementVisual`, 도감 및 기존 스포너 UI는 같은 보유 티어와 대표값을 사용한다. 관련 문자열에서만 체급 Lv 표기를 티어 표기로 교체한다. 새 화면이나 아트는 필요 없다.
- 승인된 데이터 구조는 `MetaProfile.HasCustomFormation`과 `EnhanceTier`를 포함한다. 기존 에셋 키·SO 필드·공용 인터페이스 추가 없음. 신규 데이터 로딩용 Enum 키는 단계 표에 한정한다.
- **승격 승인 범위** — ‘기존 6개 둥지의 출격 전 편성에서 보유 몬스터의 자유 배치와 미배치를 허용한다. 동일 몬스터의 동일 등급은 한 곳에만 배치한다. 0~6칸 출격이 가능하며 카드는 편성과 무관하게 기존 덱에서 무작위 추첨한다. 챕터와 탑에는 저장 편성, 데일리에는 종족별 기본 편성을 적용한다. 이 범위의 UI·세이브·봉인·카드 연동을 허용한다. 기존 체급 6개 항목은 종족 공유의 T1~T3 순차 구매로 전환하며, 다른 강화·승급 규칙은 유지한다. 전환에 필요한 공통 단계 데이터·상점·편성·도감·기존 HUD 표기와 이전 체급 저장 이행을 허용한다.’
