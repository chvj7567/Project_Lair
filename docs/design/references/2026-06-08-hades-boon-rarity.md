## 1. 레퍼런스 메커니즘 분석

### 1.1 동작

Hades 에서 Zagreus 는 탈출 시도마다 올림포스 신들의 방을 거치며 Boon(보우니) 을 획득한다. 각 방에서 3장의 Boon 이 제시되는데, 각 카드는 **Common(흰) / Rare(초록) / Epic(보라) / Heroic(금)** 네 등급 중 하나가 결정된다. 기본 확률은 대략 Common 60% / Rare 25% / Epic 12% / Heroic 3% 이고, 키프세이크(Keepsake) 장신구나 Mirror of Night 업그레이드가 이 비율에 직접 가중치를 더한다.

같은 효과라도 등급이 높을수록 수치가 크게 강화된다 — 예를 들어 Zeus 의 Lightning Strike 는 Common 40 / Rare 55 / Epic 70 / Heroic 90+ 로, 동일한 픽이 "운이 좋았는가"에 따라 완전히 다른 세기로 작동한다. 이미 보유한 Boon 은 **Pom of Power** 라는 업그레이드 아이템으로 등급을 한 단계 올릴 수 있어, "나중에 더 강해진다" 는 2단 보상 경험이 추가된다.

특수 등급으로 **Duo Boon** 과 **Legendary Boon** 이 있다. Duo Boon 은 두 신의 Boon 을 각각 하나 이상 보유한 상태에서만 선택지 풀에 등장하는 조합 카드이고(예: Zeus + Poseidon → "Sea Storm"), Legendary Boon 은 특정 신의 Boon 3개 이상 보유 시 잠금 해제된다. 두 카드 모두 "플레이어가 이미 구축한 빌드 방향 안에서 자연스럽게 등장한다" 는 점이 핵심이다 — 기존 빌드가 촉매가 되어 더 강한 보상이 열리는 구조.

### 1.2 왜 잘 될까

첫째, **등급 차이가 명확한 시각 피드백** 을 준다. 카드 테두리 색(흰→초록→보라→금)이 즉각적으로 "이건 좋은 것" 이라는 신호를 전달하고, 수치 차이가 가시화되어 계산적 만족감이 생긴다. 플레이어가 Epic 이나 Heroic 을 보는 순간 느끼는 흥분 피크가 반복되면서 게임이 기억에 남는다.

둘째, **같은 28장 풀로 무한한 변주** 를 만든다. 등급이 다르면 실질적으로 다른 카드처럼 작동하기 때문에, 동일한 픽이라도 "Common vs Heroic" 은 완전히 다른 강도의 선택이 된다. 콘텐츠를 추가하지 않고도 선택의 깊이가 4배 확장된다.

셋째, **Duo / Legendary 의 "달성 가능한 멀리서 보이는 목표"** 효과다. 플레이어는 Duo Boon 이 등장하면 "내가 빌드를 잘 쌓아왔구나" 라는 보상을 느끼면서, 아직 부족한 신의 Boon 을 의식하게 된다 → 자연스러운 빌드 집중력 향상.

### 1.3 제약·한계

Hades 의 등급 시스템은 신 14명 × 다수 Boon 이라는 **콘텐츠 부피** 가 뒷받침되기 때문에 다양하게 작동한다. 카드 풀이 얕을수록 등급 변주로 생기는 실질 차이가 줄고 "Heroic 인데 너무 약함" 불만이 생긴다. MVP 28장 풀에서 전면 도입 시 UX 오버헤드(등급 이해 + 수치 계산) 대비 체감 변화가 부족할 수 있다. 또한 등급별 수치 차이 자체가 추가 밸런싱 레이어가 되어 QA 부담이 늘어난다.

## 2. Project Lair 적용 후보 (패턴 3개)

### 2.1 패턴 1: 절박도 연동 등급 가중치 (Desperation Rarity Bias)

- **적용 대상**: `CardSelectionViewModel` (또는 `CardPickerService`) — 3택 1 카드 선택지 생성 로직
- **구현 스케치**: 패시브 카드 픽 시 영웅 현재 HP% 를 기준으로 Common / Rare / Epic 3등급 가중치를 동적으로 조정한다. HP 100% 기준 Common 70 / Rare 25 / Epic 5 → HP 50% 기준 Common 50 / Rare 35 / Epic 15 → HP 20% 기준 Common 30 / Rare 40 / Epic 30 으로 선형 보간한다. 등급별로 수치 배율만 다르게 하고 카드 기획 ID 는 그대로 사용한다 — 카드 데이터 SO 에 `commonMultiplier / rareMultiplier / epicMultiplier` 필드를 추가하고, 런타임에 선택된 등급에 맞는 배율로 카드 효과 수치를 스케일한다. 시각적으로는 카드 테두리에 등급 뱃지만 추가한다. "영웅이 위험해질수록 더 강한 카드가 나온다" 는 역설적 반전이 Project Lair 의 역방향 던전 주인 시점과 정서적으로 정합한다.
- **구현 비용**: 3/5
- **MVP §11 호환**: O — 선택지 UX 정체성(3택 1, HP% 트리거) 은 그대로, 수치 다양성만 추가. 기존 28장 카드 구조·배수 변경 없음
- **적재 타이밍**: MVP 후반 (5분 풀 플레이 테스트 단계, §12 Step 6) — 밸런스 검증 후 투입
- **의존 패턴**: 기존 `CardSelectionViewModel` / `ECardId` / 카드 SO 스키마

### 2.2 패턴 2: 빌드 축 잠금 희귀 카드 (Synergy-Gated Rare Cards)

- **적용 대상**: 카드 풀 SO + 패시브 카드 선택 필터 로직 + `card-renewal.md` 기획서
- **구현 스케치**: 4축 각각에 "Tier2 잠금 희귀 카드" 1장씩을 추가 (총 4장, `ECardId` 확장). 이 카드들은 해당 축의 빌드 카운트가 5 이상(Tier2 달성)인 경우에만 선택지 풀에 등장한다. 예: Tank 축 Tier2 이상 시 "마왕의 분노(DemonFury)" — Wisp·Wraith 공격력 ×2.0 + 스폰 주기 ×0.7 복합 효과. 이 카드는 Tier2 달성 전에는 카드 풀에 없으므로, "내 빌드가 강해질수록 더 강한 카드가 잠금 해제된다" 는 구체적 목표가 생긴다. Hades Duo Boon 의 "기존 빌드가 촉매" 원리 그대로. 잠금 해제 여부는 `BuildSynergyTracker` 가 관리하는 빌드 카운트를 구독해 판단한다.
- **구현 비용**: 4/5
- **MVP §11 호환**: △ — 기존 28장에 4장 추가. MVP §11.2 고정 범위 초과이므로 game-designer 승격 필요
- **적재 타이밍**: Alpha — MVP 검증 후 콘텐츠 확장 단계
- **의존 패턴**: `BuildSynergyTracker` / `CardSelectionViewModel` / `card-renewal.md §4` 시너지 Tier 표

### 2.3 패턴 3: 카드 업그레이드 액티브 (Essence Boost — Pom of Power 모사)

- **적용 대상**: 액티브 카드 풀 + `IBattleContext` 의 픽 이력 관리 + 카드 선택 팝업 UI
- **구현 스케치**: Hades Pom of Power 를 모사한 새 액티브 카드 "정수 추출(EssenceExtract, `ECardId` 확장)" 을 도입한다. 선택 시 이번 런에서 픽한 패시브 카드 목록 중 1장을 서브 선택지로 보여주고, 선택한 카드의 효과 수치를 등급 배율만큼 상향(×1.0 → ×1.3) 한다. UI 는 기존 3택 1 카드 팝업을 재활용해 "업그레이드할 카드를 고르시오" 2단 선택으로 구성한다. 액티브 카드 3택 구성(저주 1 + 버프 1 + 와일드 1) 의 와일드 슬롯에 이 카드를 배치하면 기존 구성을 깨지 않고 투입 가능하다. "이미 쌓은 빌드를 더 깊이 판다" 는 플레이어 의사결정이 추가된다.
- **구현 비용**: 3/5
- **MVP §11 호환**: △ — 액티브 12장 초과 → game-designer 승격 필요. 와일드 슬롯 전용 카드로 범주 분리 가능
- **적재 타이밍**: Beta — 픽 이력 관리 API 가 안정화된 이후
- **의존 패턴**: `IBattleContext` (픽 이력 노출) / `CardSelectionViewModel` / 액티브 카드 SO 스키마 / 카드 선택 팝업

## 5. 쉬운 설명 (비개발자 요약)

Hades 는 그리스 신화의 신들에게서 특별한 능력(보우니) 을 받는 게임인데, 같은 능력이라도 "일반 → 희귀 → 전설" 등급이 있어 강할수록 수치가 크게 올라간다. 처음엔 평범한 흰 카드를 받지만, 운이 좋으면 반짝이는 금색 카드가 나오고 그 순간 느끼는 흥분감이 게임을 계속하게 만드는 핵심 동력이다. Project Lair 는 지금 모든 카드가 같은 무게감으로 나오는데, 영웅의 체력이 낮아질수록 더 강한 카드가 등장할 확률을 높이는 방식으로 이 흥분감을 설계에 녹일 수 있다. 그래서 이번에 참고하려는 것은: "위기일수록 더 강한 선택지가 보상으로 주어지는 Hades 의 등급 시스템을 Project Lair 에 적용해, 후반 카드 픽이 더 짜릿해지도록 만드는 방법"이다.
