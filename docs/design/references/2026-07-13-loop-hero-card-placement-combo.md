## 1. 레퍼런스 메커니즘 분석

### 1.1 동작

Loop Hero 에서 플레이어는 "카드" 형태의 지형 타일을 루프 맵 위 빈 칸에 자유롭게 배치한다. 단일 타일은 그 자체로도 효과가 있지만, **인접 배치·누적 밀도·특정 조합**이 충족될 때 변환(Transformation)이 발생하여 완전히 다른 새 타일이 생성되거나 보너스가 발동된다.

대표 예시:
- **Rock × 2 이상** 인접 → Mountain Range 타일 자동 생성 (Rock 단독보다 강한 스탯 부스트)
- **Forest × 4+ 동일 영역** → Thicket 변환 (이동속도 ↓, 골드 보너스 ↑, 새 몬스터 등장)
- **River × 여러 개 + Spider Cocoon 인접** → 수중 거미 조우 이벤트 (특수 전리품)
- **Village + nearby Outpost** → 방어력 보너스 복합 발동

변환은 플레이어가 카드를 두는 순간 즉시 발생하고, 변환된 타일은 원래 개별 타일을 대체한다. 이 때문에 "어떤 카드를 어디에 두느냐"가 단순 수량 누적이 아닌 공간·조합 퍼즐이 된다. 또한 일부 조합은 의도치 않게 등장하여 **세렌디피티(serendipity) 효과**를 준다 — 처음 보는 조합이 발동될 때 발견의 쾌감이 생긴다.

### 1.2 왜 잘 될까

**①  선택지의 의미 밀도 상승**: 타일을 놓는 단순 행위가 "기존 배치와의 조합 계산"을 즉시 촉발한다. 플레이어는 카드를 쥔 순간부터 "이걸 저기 놓으면 Rock이 2개 되는데..." 라는 입체 사고를 하게 된다. 선택 수는 같지만 각 선택의 인지적 무게가 늘어남.

**② 누적 → 변환 모멘트**: Rock 1개 → 2개 될 때 Mountain이 '탁' 생겨나는 시각·청각 피드백이 있다. 단순 수치 +2%가 아니라 **상태 전이(state transition)** 가 일어난다는 느낌 — 빌드가 "완성되는" 감각.

**③ 조합 발견의 무한 깊이**: 가이드 없이 플레이해도 조합이 튀어나온다. 레어 조합은 "아 이게 이렇게 되는구나" 하는 기억에 남는 순간을 만든다. 이것이 재플레이 동기.

**④ 위험-보상 균형 내재**: 타일을 많이 놓으면 적도 강해진다(Loop Hero 핵심 밸런스). 조합을 위해 타일을 욕심내면 자연스럽게 리스크가 늘어 — 고보상 조합일수록 위험 배치를 요구하는 설계가 자연스럽게 내장됨.

### 1.3 제약·한계

- **공간 의존성**: Loop Hero 의 조합은 맵 좌표(2D 그리드)에 의존. 공간이 없는 시스템에서 1:1 이식이 불가능.
- **복잡도 페이싱 문제**: 조합 규칙이 많아지면 플레이어가 압도될 수 있음. Loop Hero도 게임 중반까지 핵심 조합만 노출하고 후반에 확장.
- **세렌디피티 vs. 학습 곡선**: 발견의 즐거움은 "처음 발견"할 때만 강함. 같은 조합을 두 번째 마주칠 때는 기대감으로 전환 필요.
- **5분 런에서의 적용 한계**: Project Lair 는 런이 짧아 조합을 탐색할 시간이 Loop Hero(30분+)보다 훨씬 짧음 → 인접/공간 조합보다 **순서·임계 조합**으로 변형 필요.

## 2. Project Lair 적용 후보 (패턴 3개)

### 2.1 패턴 1: 카드 조합 반응 (Card Combo Reaction)

- **적용 대상**: `CardSelectionPopup`, `IBattleContext`, `HeroAuraRunner`, 카드 효과 처리 레이어
- **구현 스케치**: 패시브 카드를 픽할 때, **직전 3픽 이내에 특정 조합 패턴**이 충족되면 추가 "반응 효과(Reaction Effect)"가 발동된다. 예: `SpawnWraith` → `WraithDamageBoost` 를 연속 픽하면 "Reaper Tide: 다음 Wraith 스폰 시 HP 추가 +20% 1회" 가 자동 발동. 반응은 일회성 폭발 효과이므로 영구 버프가 아닌 즉발 보상으로 처리. `CardComboRegistry` ScriptableObject 에 (카드 A, 카드 B, 반응 효과, 윈도우 N픽) 를 등록하고, 픽 시점에 최근 픽 큐와 매칭. 반응이 터지면 팝업 상단에 "조합 반응!" 플래시 토스트 1초 표시.
- **구현 비용**: 3 / 5
- **MVP §11 호환**: O — 기존 카드 선택 플로우 위에 반응 레이어 추가. 기존 28장 카드 데이터 변경 불필요.
- **적재 타이밍**: Alpha (v0.2+)
- **의존 패턴**: `CardSelectionPopup`, `CardPickHistoryBuffer` (새 작은 큐 컴포넌트 필요), `IBattleContext.ApplyGlobalEffect`

### 2.2 패턴 2: 축 임계 → 던전 변환 (Axis Threshold → Dungeon Transformation)

- **적용 대상**: `HeroAuraRunner`, Synergy Tier 발동 시스템, 배틀 씬 환경

Debuff Tier 2 → 배경에 보라빛 독 안개 VFX 레이어 오버레이. Tank Tier 1 → Wisp 가 초록 → 짙은 초록으로 전체 색상 시프트. 변환은 되돌아오지 않으므로 빌드의 "흔적"이 씬에 쌓인다. `SynergyTierEventBus` 에서 티어 이벤트를 받아 `DungeonAtmosphereController` 가 처리 — 코드 최소 침습.

## 3. 우선순위 제안

**1순위: 패턴 2 (축 임계 → 던전 변환)**

구현 비용 2/5로 가장 낮으면서 효과가 즉각적이다. 현재 Tier 시스템은 수치만 바뀌는 조용한 이벤트인데, 배틀 씬의 외관 변화를 추가하면 "빌드가 진행되고 있다"는 체감이 강해진다. 이것이 개선되면 플레이어가 다음 Tier 를 향해 더 의식적으로 카드를 픽하게 된다 — 즉 기존 4축 시스템의 행동 유도력(affordance)이 강해짐. 신규 시스템 없이 기존 이벤트 버스에 VFX 구독 하나 추가하면 되므로 리스크도 낮다.

**2순위: 패턴 1 (카드 조합 반응)**

패턴 2 완료 후 Alpha 단계에서 추가. "조합 반응"은 18번 카드 픽 중 1~2회 터지는 보너스 순간을 만들어 각 픽의 텐션을 높인다. 단 조합 정의가 너무 많으면 관리가 어려우므로 처음엔 4~6개 조합만으로 시작.

**3순위: 패턴 3 (은닉 레시피 도감)**

v0.3 서버 연동이 완료된 후 Beta 단계 추가. 패턴 1의 조합 시스템이 먼저 안정화되어야 도감이 의미를 갖는다. 단독으로 구현하기보다 패턴 1 완성 후 자연스럽게 연결.

## 5. 쉬운 설명 (비개발자 요약)

Loop Hero 는 영웅이 자동으로 뛰는 길 주위에 플레이어가 카드처럼 생긴 땅 조각들을 붙여나가는 게임입니다. 중요한 점은 돌멩이 두 개를 붙여 놓으면 그냥 돌멩이 두 개가 아니라 "산맥"이 되어버린다는 것 — 그러니까 무엇을 얼마나 붙이느냐보다 **어떤 것들을 옆에 붙이느냐**가 훨씬 큰 효과를 냅니다. 처음엔 몰랐다가 "어? 이게 합쳐지네?" 하는 발견의 순간이 이 게임의 큰 매력입니다. Project Lair 도 지금은 카드를 고를 때 각자 따로 효과가 적용되는데, 특정 카드를 연달아 고르면 "반응 폭발"이 생기거나, 많이 고르면 던전 분위기가 바뀌는 등의 조합 재미를 넣으면 "이 카드 다음에 저 카드를 골라야지" 하는 계획의 재미가 생길 수 있습니다. 그래서 이번에 참고하려는 것은: **카드를 모아서 쌓는 것보다, 어떤 카드를 어떤 순서로 조합하느냐가 새로운 무언가를 만들어낸다는 설계 철학.**
