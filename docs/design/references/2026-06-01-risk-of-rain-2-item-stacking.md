## 1. 레퍼런스 메커니즘 분석

### 1.1 동작

Risk of Rain 2(이하 RoR2)의 아이템 시스템은 런 중 루팅한 동일 아이템이 **스택(stack)** 으로 누적되며, 각 아이템은 고유한 **스택 공식**을 갖는다. 크게 세 범주로 나뉜다.

**선형(Additive) 공식**: `효과 = 기본값 + (n-1) × 증가량`. 예: Soldier's Syringe — 공속 +15%/스택. 직관적이나 스택이 쌓일수록 수치가 선형으로 폭발적으로 커진다.

**쌍곡(Hyperbolic) 공식**: `효과 = 1 - 1/(1 + 기본값 × n)`. 예: Tougher Times — 블록 확률 15%/스택(공식 적용 시 1스택 ≈13%, 2스택 ≈24%, 10스택 ≈60%로 수렴). 초기 픽이 후기보다 가치가 높고, 무한 스택이 상한에 수렴한다. 밸런스 안전망 역할.

**곱산(Multiplicative) 공식**: `효과 = base × coefficient^n`. 예: Alien Head — 쿨다운 ×0.75/스택. 복리 누적으로 느리게 시작해 후반에 폭발적으로 가속. "헌신 보상" 카드에 적합하다.

아이템 등급(Common·Uncommon·Legendary)도 스택 공식과 맞물린다. Common은 빈도 높고 선형/쌍곡 공식으로 스택해도 밸런스가 유지되며, Legendary는 단 1개도 강력하지만 추가 스택이 런 전체를 바꾼다. 이 등급 차이가 "처음 줍는 것"과 "또 줍는 것"의 가치를 다르게 만든다.

### 1.2 왜 잘 될까

**"내 빌드" 각인 효과**: Crowbar 12개 = "나는 고HP 적 저격 빌드"처럼, 스택 숫자가 빌드 정체성을 명시적으로 표현한다. 런이 끝나도 "그 때 Syringe 20개"처럼 회상할 수 있는 명확한 앵커가 생긴다.

**공식 이해 없이도 체감 가능**: 선형 스택은 "쌓을수록 강해진다"는 직관이 즉각 작동한다. 실제 공식을 몰라도 픽할 때마다 데미지 숫자가 오르는 즉각 피드백이 보상을 전달한다. 복잡한 수학은 백엔드에 숨겨져 있고, 플레이어는 결과만 체감한다.

**임계 기대감 생성**: 일부 아이템은 특정 스택 수에서 추가 효과가 발동된다. "다음 스택에 뭔가 달라진다"는 예측이 선택지 순간에 긴장감을 높인다. 이 구조는 5분 안에 18번 결정을 내리는 Project Lair의 페이싱에 직접 이식 가능하다.

### 1.3 제약·한계

- 선형 공식 아이템은 스택이 충분히 쌓이면 게임 난이도를 무력화한다(소위 "hyperstack" 런). RoR2는 시간 스케일링(적도 같이 강해짐)으로 상쇄하지만, Project Lair의 5분 고정 런에서는 별도 안전 장치가 필요하다.
- 스택 공식 다양성은 선택지 가치 파악을 어렵게 만든다. "이 카드가 지금 몇 스택이고 추가 1픽이 얼마나 이득인가"를 실시간으로 계산하기 어려워 UI 보조가 필수다.
- 랜덤 루팅 기반인 RoR2와 달리 Project Lair는 3택 1 능동 선택이므로, 중복픽을 "의도적 선택"으로 설계해야 한다 — 실수로 하이퍼스택이 되는 구조는 피해야 한다.

## 2. Project Lair 적용 후보 (패턴 3개)

### 2.1 패턴 1: 축 임계 구간 등급제

- **적용 대상**: BalanceConfig.asset (Tier 보너스 수치) / 4축 빌드 시너지 시스템 (`card-renewal.md` §4)
- **구현 스케치**: 현재 Tier 1/2/3 발화 시 고정 효과가 임계(3/5/7장)에 1회 발동된다. RoR2 아이템 공식처럼 **각 Tier 보너스를 등급 감각으로 설계**한다 — Tier 1(3장)은 "가입 보너스"(소폭, ×1.1~1.2), Tier 2(5장)는 "빌드 정체성 확인"(중폭, ×1.3~1.5), Tier 3(7장)는 "전 픽 헌신 보상"(강폭, ×1.8~2.0 혹은 완전히 다른 효과 발동). 이를 통해 Tier 3에 도달한 플레이어가 RoR2 Legendary 스택처럼 "와, 달라졌다"는 체감을 얻는다. `BalanceConfig.asset` 에 `SynergyTier1Multiplier` · `SynergyTier2Multiplier` · `SynergyTier3Multiplier` float 필드를 분리해 인스펙터에서 즉시 튜닝 가능하게 둔다.
- **구현 비용**: 2
- **MVP §11 호환**: O (수치 조정만, 새 콘텐츠 없음)
- **적재 타이밍**: 프로토타입 (밸런싱 1차 라운드에서 바로 적용)
- **의존 패턴**: `docs/design/card-renewal.md` §4 시너지 Tier 표와 연동. qa-simulator 시뮬레이션 결과 후 수치 튜닝.

### 2.2 패턴 2: 중복픽 체감 가속 공식

- **적용 대상**: CardEffect 기반 클래스 / ScriptableObject 스키마 (`CardData`)
- **구현 스케치**: 동일 카드를 N번 중복 픽할 때 단순 선형(N배)이 아니라 **공식 선택지를 카드별로 부여**한다. 예: WispHpBoost 1픽=×1.5, 2픽=×2.55(곱산 체증), 3픽=×4.85 — "헌신하면 폭발적으로 강해진다." PlagueSlowBoost처럼 상한이 있어야 할 카드는 쌍곡 공식으로 "2픽이 1픽보다 30% 더 좋지만 4픽은 별 차이 없음"처럼 설계한다. 각 카드 SO에 `DuplicateFormula: enum{Linear, Hyperbolic, Multiplicative}` + `DuplicateCoefficient: float` 필드 2개를 추가하면 디자이너가 카드별로 스택 곡선을 인스펙터에서 제어할 수 있다. MVP에서는 선형 단순 구현으로 시작하고, Alpha에서 공식만 교체하는 방식으로 단계 분리한다.
- **구현 비용**: 4
- **MVP §11 호환**: O (새 콘텐츠 아님, SO 스키마 확장이지만 기존 카드 호환 유지 가능)
- **적재 타이밍**: Alpha (MVP에서 선형 구현 → Alpha에서 공식 다양화)
- **의존 패턴**: gameplay-programmer 의 CardEffect base 클래스 리팩터 선행 필요. 패턴 1 수치 베이스라인 안정화 후 진입.

### 2.3 패턴 3: 축 카운트 임계 접근 시각 신호

- **적용 대상**: BuildAxisTracker / 카드 선택 팝업 UI (`card-renewal.md` §8 빌드 카운트 바)
- **구현 스케치**: `card-renewal.md` §8에 이미 4축 빌드 카운트 바가 명세되어 있다. RoR2가 아이템 아이콘 우하단에 스택 숫자 버블을 표시해 "내가 지금 몇 개인지"를 즉각 노출하는 것처럼, Project Lair 빌드 카운트 바에 **"다음 Tier까지 N장"** 텍스트 또는 색 변화를 추가한다. 남은 거리가 1장일 때 바가 펄스(pulse) 애니메이션으로 긴장감을 유발한다. 구현 포인트: `BuildAxisBarView.cs` 에서 `remainingToNextTier <= 1` 조건 시 DOTween 펄스 트리거. 이 패턴은 패턴 1(Tier 등급제)이 실제로 체감되기 위한 전제 피드백이다.
- **구현 비용**: 3
- **MVP §11 호환**: O (프리미티브 UI 범위, 새 콘텐츠 아님)
- **적재 타이밍**: 프로토타입 (card-renewal 빌드 카운트 바 구현 PR과 동일 타이밍)
- **의존 패턴**: `card-renewal.md` §8 빌드 카운트 바 구현 선행. `CHText` 래퍼 필수 (Rule 03 §3).

## 3. 우선순위 제안

**패턴 3 → 패턴 1 → 패턴 2** 순서 추천.

패턴 3(시각 신호)은 card-renewal 빌드 카운트 바 PR에 묻어서 구현 비용이 사실상 0에 수렴하고, Tier 체감을 즉시 높인다. 패턴 1(Tier 등급제)은 수치 조정이므로 프로토타입 첫 플레이 피드백을 보고 바로 조정 가능하다. 패턴 2(중복픽 공식)는 SO 스키마 확장이 필요해 코드 영향이 가장 크므로 MVP 검증 이후 Alpha에서 착수하는 것이 안전하다.

## 5. 쉬운 설명 (비개발자 요약)

Risk of Rain 2는 "같은 아이템을 여러 개 모을수록 더 강해진다"는 게임이에요. 예를 들어 빨간 신발 1개를 가지면 10% 빨라지는데, 10개를 모으면 단순히 100%가 아니라 공식에 따라 300%가 되거나, 반대로 60%에서 멈추는 식으로 설계되어 있어요. "쌓을수록 얼마나 강해지는가"의 곡선 자체가 긴장감과 재미를 만들어요. Project Lair도 이제 같은 카드를 여러 번 고를 수 있는데(v0.6 업데이트), 그 때마다 얼마나 강해지는지, 언제 "이제 다음 단계 보너스가 터진다"는 신호를 보여줄지를 잘 설계하면 플레이어가 "이 카드를 계속 골라야겠다"는 전략적 쾌감을 더 즐겁게 경험할 수 있어요. 그래서 이번에 참고하려는 것은: Risk of Rain 2가 아이템을 반복해서 모을 때 강해지는 느낌을 어떻게 만드는지, 그 공식과 시각적 피드백을 Project Lair의 카드 중복 픽 시스템에 가져오는 것입니다.
