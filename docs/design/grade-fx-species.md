## § 헤더

- **목표**: 등급 이펙트 시트 18장(`Assets/_Lair/Art/Sprites/GradeFx/{Name}_aura.png`·`_g4.png`·`_g5.png`)을, 한국 설화풍으로 교체한 몬스터 6종의 화풍에 맞고 종족마다 **고유한 모양**을 가진 이펙트로 **같은 파일명·같은 규격으로 제자리 교체**한다.
- **검증 가설**: (1) 이펙트 모양만 종족별로 달라져도(2~3등급 aura, 4등급 측면 요소, 5등급 후광+측면 요소+맥동의 단계 구조는 그대로) 6종이 등급과 무관하게 "이 종족의 군주" 로 읽히고 애착이 오른다. (2) 그림 규격·프리팹·코드·스키마를 건드리지 않고도 화풍 불일치(임시안 한계 G8)가 해소된다. (3) 가산 합성(빛만 그리는) 제약 안에서 한국 설화 모티프(도깨비불·혼불·부적·오방기 등)가 판독된다.
- **현재 단계 범위 적합성**: **범위 밖 -> 승격 필요**(사유: `monster-grades.md` G8·Q3 와 CLAUDE.md §8 "몬스터 등급 2~5" 마지막 문장이 "종족별 등급 이펙트 차별화" 를 후속 별도 승격으로 금지, "몬스터 도감 개편" 항목이 "신규 이펙트 시트 제작" 을 금지). 사용자가 승격을 요청한 작업이므로 §1.3 의 최소 개정 문구를 메인이 §8 에 반영하면 범위 안이 된다. 반영 전에는 에셋 적용(§8 4단계)에 착수하지 않는다(시안 제작은 레포 밖 작업이라 가능).
- **핵심 메커니즘**: GPT(Codex `gpt-6-sol`)는 종족별 **정지 그림 3장**(바닥 판·측면 요소 판·후광 판, 검정 배경)만 그린다. 레포 밖 로컬 도구가 그 정지 그림을 **현행 프레임 격자(120 / 60 / 120 프레임)로 수학적 루프 합성**(회전·교차 디졸브·상승 입자)해 시트 18장을 만든다. 시트 크기·슬라이스·`.meta`·프리팹·코드·JSON 이 불변이라 PNG 18장만 덮어쓴다. 적용 전 비교 목업에서 사용자 승인을 받는다.

### 7.2 GPT 정지 그림 3장 (종족당, 검정 배경 1536x1024)

공통 머리말(영문, 모든 호출 맨 앞): `BACKGROUND RULE: the entire background is flat pure black #000000, no gradient, no floor, no grid lines. Draw ONLY light: glowing rim-lit shapes, soft translucent mist and bright cores that will be added on top of a game scene with additive blending. No dark outlines, no solid dark fills, no text, no readable Chinese characters or Hangul, no cast shadow. Same polished HD, cel-shaded, slightly cute Korean-folklore look as the attached monster sprite. Palette: <종족 주색 + 보조색 hex>. Keep every element at least 6% inside its panel.`

| 장 | 이름 | 구성(1536x1024 안) | 참조 첨부 |
|---|---|---|---|
| AUR | 바닥 판 | 왼쪽 768x1024 = 위에서 내려다본 **원형 바닥 링 1개**(지름 700px 이내, 중심 대칭, §4 aura 모양) · 오른쪽 768x1024 = **입자 8종**(2열 x 4행, 칸마다 중앙에 하나, 칸의 60% 크기, §4 입자) | 새 몬스터 대기 F0 크롭(`Assets/_Lair/Art/Sprites/Monsters2D/{Name}_Sheet.png`) 1장 |
| PIL | 측면 요소 판 | 512x1024 3열 = **세로 요소 자세 A·B·C**(같은 요소의 다른 순간, 바닥 중앙 고정, 높이 90%, §4 4등급 측면 요소) | 몬스터 F0 크롭 + 현행 `{Name}_g4.png` 첫 프레임(크기 참조) |
| HAL | 후광 판 | 왼쪽 1024x1024 = **후광 본체**(원형, 중심 방사, §4 5등급 후광) · 오른쪽 512x1024 = 위 512x512 **안쪽 링 1개**, 아래 512x512 **불씨 4종**(2x2) | 몬스터 F0 크롭 + 현행 `{Name}_g5.png` 첫 프레임 |

- 종족 블록은 §4 표의 해당 행을 영문으로 옮겨 붙인다(예: 도깨비불 AUR `A ring of eight small dokkaebi fires lit mint-jade #3FCF86 with white cores #E4FFF0, seen from straight above, an iron-stud dot pattern inside the ring ...`). 실제 텍스트는 `prompts/` 에 저장하고 CALLS.md 에 파일명을 남긴다.
- 호출 수: 종족 3장 x 6 = **기본 18회**. 같은 항목 최대 3회 생성(최초 1 + 재생성 2), 상한 18 x 3 = **54회**. 예상 소요: 파일럿 3회 + 나머지 15회 + 재생성 여유 6회 = 24회(시작값, 파일럿 실제 통과율로 갱신).
- 한도 대비: 호출은 종족 순차(몬스터 시트 때와 같은 한도 대기 상태가 생길 수 있음), 매 호출을 CALLS.md 에 기록하고 호출이 20회를 넘으면 메인이 사용자에게 한 줄 보고. 한도에 걸리면 완료된 종족까지의 산출은 보존하고 다음 종족부터 재개(종족 단위 독립).

### 7.3 로컬 루프 합성 (`grade_fx_bake.py`)

모든 합성은 가산(합 후 1.0 클램프). 변수의 시작값은 파일럿 비교 목업에서 사용자 확인 후 조정하며 한 종족을 확정하면 6종 같은 값을 쓴다.

| 시트 | 프레임 | 루프 합성 방식(시작값) |
|---|---|---|
| aura (120f, 4.0s) | 136x100 | ① 링: 바닥 판의 링을 **1바퀴/4.0s 등속 회전** 후 세로를 0.42 배로 눌러 타원(가로 128 x 세로 약 54px 이내) 배치, 중심 = 피벗 (68, 80). 밝기 숨쉬기 ±12%(1주기/4.0s). ② 입자: 16개, 각각 링 위 임의 위치에서 시작해 2.0s 에 60px 상승하며 불투명도 sin 포락(0 -> 1 -> 0), **주기 2.0s 이므로 루프 내 2회** 반복(시드 고정). ③ 빔: 중심에서 위로 퍼지는 종족색 소프트 그라데이션, 불투명도 0.25 +- 0.08(1주기) |
| g4 (60f, 2.0s) | 120x152 | ① 자세 A -> B -> C -> A 교차 디졸브(자세당 20프레임, smoothstep). ② 가로 전단 +-3px(1주기), 세로 신축 +-4%(1주기, 위상 90도 어긋남). ③ 불투명도 깜빡임 +-8%(2주기). ④ 입자 10개 상승(1주기). 요소는 높이 128px 에 맞춰 스케일, 발 중심 (60, 136) 고정 |
| g5 (120f, 4.0s) | 128x128 | ① 후광 본체 +360도/4.0s 회전. ② 안쪽 링 -360도/4.0s(반대 방향) 0.6 배. ③ 스케일 맥동 +-3%·불투명도 +-10%(**3주기/4.0s**, 몸 맥동 1.2s 와 비슷한 1.33s). ④ 불씨 12개 후광 둘레 공전(1주기) |

- 모든 위상 함수는 주기가 루프 길이(4.0s / 2.0s)의 약수이므로 마지막 프레임 -> 첫 프레임이 연속(C7).
- 정규화: 종족별로 점등 픽셀 평균 휘도를 현행 시트와 같은 값(+-15%)으로 맞추는 이득을 곱한다(불투명도 JSON 은 6종 공통이라 종족별 보정은 시트가 담당, §6).
- 출력: 직사각형 격자(§2.1) RGBA PNG. 알파 = max(R,G,B)/255, RGB = 색 / 알파(straight alpha). 프레임 가장자리 4px 는 알파 0 으로 비운다(밉맵 번짐 방지, X-F5).
- 호출 수 근거(F2): 같은 시트를 GPT 프레임으로 직접 받으면 120+60+120 = 300장을 일관되게 그려야 한다. 합성 방식은 18회로 끝난다.
