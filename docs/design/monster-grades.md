## § 헤더

- **목표**: 기존 6종족마다 2 견습 · 3 숙련 · 4 정예 · 5 군주 몬스터(24개)를 만들고, 상점에서 승급해 얻은 등급 몬스터를 둥지에 배치해 싸우게 한다.
- **검증 가설**: (1) 같은 몬스터가 등급마다 눈에 띄게 달라 보이면 "키워서 강해졌다"는 체감이 커져 재방문 동기가 생기는가. (2) 승급 비용을 기존 콘텐츠 재화(각성석·달빛 인장·심연 결정)에 묶으면 Normal/Hard·데일리·탑을 도는 이유가 하나 더 생기는가. (3) 승급이 던전 편성을 다시 열어 편성 화면이 "확인용"에서 벗어나는가.
- **현재 단계 범위 적합성**: **범위 안**(CLAUDE.md §8 "몬스터 등급 2~5 허용", 2026-11-01 승격). 신규 종족·6등급 이상·등급 전용 스킬/AI·신규 재화·유료 승급·아이콘 등급 변형·★ 목표는 계속 금지.
- **핵심 메커니즘**: 등급 몬스터 = 기존 몬스터와 같은 데이터·카드·육성을 이어받고 HP·공격력에만 등급 배율을 곱한 별도 몬스터(별도 프리팹 · 별도 `EMonster` 값). 외형은 등급마다 몸 시트를 따로 굽고 강화 덧그림도 등급 색으로 다시 굽는다. 승급은 상점 몬스터 강화 행의 5번째 칸에서 종족마다 한 단계씩 한다.

- 테두리 순서(밝은 테 → 현행+발광 → 종족색 테 → 금 테)와 군주 x1.30 은 영웅 5단계 규약(성기사 5-2 `#F8FAFC` · 5-4 팔레트색 · 5-5 `#FDE047`)과 같다.
- **크기는 시각만**: 등급 배율은 `Visual2D`(몸·덧그림)·`AuraGrade`·`AuraSigil` 에만 곱한다. 루트 스케일·콜라이더·사거리·판정은 기준 몬스터와 같다(판정 불변).
- **픽셀 밀도**: 2D 전환 규약(§3.2 "강화로 몸을 스케일업하지 않는다")에 대한 예외다. 등급 크기 배율은 사용자 확정(V1)이고, 영웅 5-5 x1.30 선례가 있다. 정수배가 아니라 텍셀 크기가 x1.05~x1.30 로 섞이는 것을 수용한다.
- **발광 하한**: 등급 3~5 는 강화 Lv0 이어도 발광이 켜진다(§3.2 합성식).

## 3. 강화 외형과의 합성 규칙 (V3)

### 3.1 그리는 순서 · 자리

| 층 | 내용 | 등급 반영 |
|---|---|---|
| 바닥 `Aura`(현행 종족 원판, 높이 0.005) | 그대로 | 없음 |
| 바닥 `AuraGrade`(신규, 높이 0.0055) | 등급 오라 - 채운 빛(§1) | 등급 4·5 만 켜짐 |
| 바닥 `AuraSigil`(현행 강화 링, 높이 0.006) | 강화 Lv2·4·5 링 - 선 | 지름 x 등급 배율 |
| `Visual2D` 몸 | 등급 몸 시트 | 등급 시트 자체 |
| `Visual2D/Enhance` 덧그림 | 등급 색으로 다시 구운 T1~T3 덧그림 | 등급 시트 자체 |

- 등급 오라는 채운 원, 강화 링은 선이라 겹쳐도 구분된다. 오라 위에 링이 그려진다.
- 덧그림 원화는 "같은 등급의 몸 + 강화 파츠"로 그린 프레임에서 "같은 등급의 몸만" 그린 프레임과 **색이 다른 픽셀만** 남긴 것이다(§4.4). 그래서 덧그림의 색·테두리가 그 등급 몸과 이어진다.

### 3.2 수치 합성

| 항목 | 식 |
|---|---|
| 발광 세기 | `max(등급 발광 하한[g], 강화 곡선[Lv])`. 등급 하한 = [0, 0, 1.5, 2.3, 3.2](g = 1~5), 강화 곡선 = [0, 1.5, 1.9, 2.3, 2.7, 3.2](Lv0~5, 현행 `_emissionByLevel` 앞에 Lv0 = 0). 결과 0 이면 `_EMISSION` 끔 |
| 발광 색 | 등급 1·2 = `SpeciesGlowColor`(현행) · 등급 3~5 = §2.2 등급 발광색 |
| 티어 선택 | 현행 그대로 Lv → [0, 1, 1, 2, 2, 3]. 오버레이 시트만 그 등급의 `_T1~_T3` |
| 바닥 링 | 현행 그대로 Lv → [0, 0, 1, 1, 2, 3], 링 색 `SpeciesGlowColor` α0.85(현행), 지름 = 현행 지름 x 등급 배율 |
| `Visual2D` localScale | 등급 배율 ÷ 루트 스케일(현행 1 ÷ 루트 스케일에 등급 배율을 곱함) |
| HP바 하단 월드 높이 | `(S − topY[g][tier] + 1) ÷ 48 x 등급 배율 + 0.08`. S = 등급 셀 크기(§4.1), `topY` = 대기 F0 의 최상단 불투명 행(덧그림 포함), 생성기가 `MonsterGrade_SheetSpec.json` 에 기록 |
| 등급 오라 | 지름(월드) = 오라 반경 텍셀 x 2 ÷ 48 x 등급 배율. 오라 반경 텍셀: 도깨비불 13 · 망령 28 · 사신 17 · 저주술사 15 · 역병귀 13 · 환령 11. 색 = 등급 발광색, 불투명도 등급 4 = 0.5 · 등급 5 = 1.0 |

- 검산 예(군주 도깨비불): 오라 지름 = 13 x 2 ÷ 48 x 1.30 = 0.704u. 발광(강화 Lv0) = max(3.2, 0) = 3.2, 강화 Lv5 = max(3.2, 3.2) = 3.2.

## 4. 시트 규격

### 4.1 등급 셀 (등급 2~5 공통, 1등급은 현행 셀 그대로)

등급 장식·잔상·입자가 들어갈 여백 `pad` 를 좌우에 1배, 위에 2배 더한다. 몸은 셀 안에서 오른쪽 `pad`·아래 `2 x pad` 옮겨 그린다 → 바닥선(셀 아래)과 가로 중심이 현행과 같아 피벗 하단 중앙(0.5, 0) 이 그대로 맞는다.

| 종족 | 현행 셀 N | pad | 등급 셀 S = N + 2 x pad | 시트(6열 x 5행) |
|---|---|---|---|---|
| 도깨비불 | 48 | 10 | 68 | 408 x 340 |
| 망령 | 88 | 10 | 108 | 648 x 540 |
| 사신 | 72 | 6 | 84 | 504 x 420 |
| 저주술사 | 56 | 6 | 68 | 408 x 340 |
| 역병귀 | 40 | 6 | 52 | 312 x 260 |
| 환령 | 40 | 12 | 64 | 384 x 320 |

- 환령 pad 12: 잔상 최대 11텍셀 + 테두리 2텍셀이 왼쪽으로 나간다. 날개 끝 셀 x 2(T3 + 테두리) − 11 = −9 → +12 = 3 ≥ 0.
- 시트 최대 648 x 540 ≤ Max Size 1024.
- 가장자리 클리핑 검사(§10 X2)에서 한 종족이라도 걸리면 그 종족 pad 를 2씩 늘려 다시 굽고, 이 표와 `MonsterGrade_SheetSpec.json` 을 함께 고친다.

### 4.2 레이아웃 · 프레임

- 6열 x 5행, 행 = 대기·이동·공격·피격·사망, 프레임 수·fps·모션 = 기준 몬스터와 같다(`monster-2d-conversion.md` §5.2). 등급은 모션을 바꾸지 않는다.
- 덧그림 시트(`_T1~_T3`)는 같은 등급 몸 시트와 같은 크기·같은 칸 배치(인덱스 동기, 현행 §6.3.6).
- 발광 마스크: 짝 원화와 같은 크기, 발광 부위 흰색 `#FFFFFF`, 나머지 검정 `#000000`. 발광 부위 = 현행 발광 부위 + 등급 장식 중 발광 표시된 것(§2.1) + 입자.

### 4.3 테두리 굽기

등급 2·4·5: 실루엣 바깥 1px 을 안쪽 테 색으로, 그 바깥 1px 을 `#0A0D14` 로 칠한다(2겹). 등급 1·3: 현행 1겹. 입자·고리 선처럼 외곽선 없음 표시된 요소는 테두리를 받지 않는다.

### 4.4 덧그림 굽기

덧그림 프레임 = `원화(등급 g, 티어 t)` 와 `원화(등급 g, 티어 0)` 를 같은 칸에서 비교해 색이 다른 픽셀만 남기고 나머지는 투명. 티어 파츠가 등급 몸 픽셀을 지우는 경우(티어 0 에서 칠해졌는데 티어 t 에서 투명)는 덧그림으로 표현할 수 없으므로 0건이어야 한다(§10 X3).

## 5. 승급 (U2)

### 5.1 흐름

1. 상점 「몬스터 강화」의 종족 행에 5번째 칸 **승급**이 생긴다(기존 4칸: 체급·각성·둥지·특성).
2. 칸은 다음 등급 이름("견습으로 승급")과 비용을 보여 준다. 재화가 충분하면 누를 수 있고, 누르면 기존 상점 칸과 같은 방식으로 바로 구매된다.
3. 구매하면 그 종족의 보유 최고 등급 +1, 편성의 그 종족 둥지에 새 등급 몬스터가 자동 배치되고, 행 머리 이름이 새 등급 이름으로 바뀐다.
4. 군주에 도달하면 칸은 "최고 등급" 최대 표시(구매 불가).
5. 승급 칸은 종족별 독립. 되돌리기·환급 없음.

### 5.2 비용 (종족 공통, 시뮬 시작값 - 최종값은 qa-simulator GR1~GR4 후 확정)

| 승급 | 소울 | 특수 재화 | 그 재화를 얻는 곳 |
|---|---|---|---|
| 1 → 2 견습 | 800 | - | 모든 전투 |
| 2 → 3 숙련 | 1500 | 각성석 30 | 챕터 Normal/Hard 승리 |
| 3 → 4 정예 | 2500 | 달빛 인장 30 | 데일리(1-5 클리어 후) |
| 4 → 5 군주 | 4000 | 심연 결정 40 | 무한의 탑(5-5 클리어 후) |

- 종족 6개를 모두 군주로 = 소울 (800 + 1500 + 2500 + 4000) x 6 = 52,800, 각성석 180, 달빛 인장 180, 심연 결정 240.
- 콘텐츠가 열리는 순서(Normal → 데일리 → 탑)대로 등급이 열린다. 별도 해금 조건은 두지 않는다(재화가 곧 해금).
- 유물 잔해 교환(3 → 각성석, 5 → 달빛 인장, 8 → 심연 결정)으로도 승급 재화를 모을 수 있다(기존 규칙 그대로).

### 5.3 던전 편성과의 맞물림

| 상황 | 결과 |
|---|---|
| 승급 전(모든 종족이 1등급만 보유) | 종족마다 고를 몬스터가 1개 → 편성 팝업 숨김, "방어하기" 가 바로 출격(던전 편성 확정 규칙) |
| 어느 종족이든 처음 견습으로 승급 | 그 종족에 몬스터 2개 → **편성 팝업 재개 조건 충족**(1-1 클리어 이후). 다음 "방어하기" 부터 편성 팝업이 열린다 |
| 승급 직후 | 새 등급 몬스터가 그 둥지에 자동 배치(편성 팝업을 열지 않아도 다음 판부터 적용) |
| 편성 팝업에서 | 종족 둥지마다 보유한 등급 몬스터 중 하나를 고른다. 보유하지 않은 등급은 보이지 않는다 |
| 저장된 편성이 보유하지 않은 등급을 가리킴(클라우드 복원으로 보유 등급이 내려간 경우) | 그 둥지는 보유한 최고 등급으로 대체 |
| 1-1 클리어 전 승급 | 승급은 상점 해금 규칙을 따른다. 편성 팝업은 1-1 클리어 전에는 열리지 않고 자동 배치만 적용 |

- 기본 편성(`MetaProfile.Formation` 0행)의 도출 기준이 "종족의 최저 등급"에서 **"종족의 보유 최고 등급"** 으로 바뀐다. 승급 전에는 보유가 1등급뿐이라 결과가 같다. `dungeon-formation.md` §0.2·§0.3 의 기본 편성 문장은 그 문서 담당 세션이 이 규칙으로 갱신한다(메인에게 전달).
- 카드 3택1 제외 규칙(출력되지 않는 몬스터 대상 카드 제외): 카드 대상은 기준 몬스터 단위이고(U4), 종족 둥지에는 항상 그 종족의 몬스터 하나가 출력되므로 제외는 계속 0 이다(휴면 유지).

## 8. 데이터 구조표 (Rule 00 데이터 구조 확인 게이트 · Rule 02 §11-1)

```
Grade (엔티티, 던전 편성에서 신설)  "등급 하나"                 <- 5행
 |-- grade       PK 1~5
 |-- prefixKey   (기존) -> Strings_Ko
 |-- hpMul       (신규) float, 필수 1:1 - 1등급 1.00
 +-- atkMul      (신규) float, 필수 1:1 - 1등급 1.00
     +-- Grade_Promotion (신규 관계, 복합키 grade + currency)  "이 등급으로 올리는 데 드는 재화 한 종"  <- 7행
            grade    -> Grade.grade (2~5 만 행 존재)
            currency -> ECurrency 값명
            amount   int

Race_Monster (기존, 복합키 race + grade)                         <- 6행 → 30행 (+24)
     monster -> EMonster 값명 (등급 몬스터 = <기준>G<등급>)

MetaProfile.RaceGrades : List<RaceGradeEntry { Race, Grade }>    (신규, Version 13)
     Race -> Race.race,  Grade -> 보유 최고 등급 (2~5). 행 없음 = 1등급만 보유
```

**§11-1 판정**
- `hpMul`·`atkMul`: 모든 등급이 항상 하나씩 가지는 값(1등급 = 1.00)이라 **필수 1:1 → `Grade` 직접 필드**. `Grade` 는 던전 편성 문서가 정의한 엔티티이므로 필드 추가는 그 문서 §0.5 에도 반영한다(메인 전달).
- 승급 비용: 1등급에는 비용이 없고(선택적), 한 등급에 재화가 여러 종(소울 + 특수 1종)이라 **선택적 관계 + 복합키 `grade + currency`** → `Grade_Promotion`(이름 `<부모>_<관계명>`). sentinel 없음.
- 보유 등급: 승급한 종족만 행이 있다(선택적). 1등급은 행 없음.

|---|---|---|---|---|
| `Grade.json` | `hpMul` | float | | 1.00 / 1.10 / 1.22 / 1.36 / 1.52 (시뮬 시작값, GR5·GR6 후 확정) |
| | `atkMul` | float | | 1.00 / 1.10 / 1.22 / 1.36 / 1.52 (같음) |
| `Grade_Promotion.json` (`EData.Grade_Promotion`) | `grade` | int | PK1, FK -> Grade | 2, 3, 3, 4, 4, 5, 5 |

| | `amount` | int | | 800 / 1500, 30 / 2500, 30 / 4000, 40 |
| `Race_Monster.json` | (+24행) | | | (Ignis, 2, WispG2) … (Ignis, 5, WispG5), (Lemur, 2~5, WraithG2~G5), (Nox, 2~5, ReaperG2~G5), (Hexia, 2~5, HexG2~G5), (Miar, 2~5, PlagueG2~G5), (Phantas, 2~5, PhantomG2~G5) |
| `MetaProfile` | `RaceGrades` | List<RaceGradeEntry> | | 기본 빈 목록 |

- **세이브**: `MetaProfile.Version` 12 → 13. 마이그레이션 = `RaceGrades` 빈 목록 추가(모든 종족 1등급). 클라우드 동기는 기존 전체 MetaProfile 단위(별도 병합 없음). 다른 기능이 13 을 먼저 쓰면 메인이 다음 번호로 조정.
- 등급 외형 수치(배율·발광·오라)는 프리팹 직렬화 정적 설정(시트 참조와 함께, Rule 02 §11 SO/직렬화 대상) - JSON 아님. 능력치 배율·승급 비용은 밸런스 수치라 JSON.
