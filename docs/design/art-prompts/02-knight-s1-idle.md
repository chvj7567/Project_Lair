# 단계 1-② 기사 S1 — 대기(idle) 8프레임 (4프레임씩 2회)

전제: 01 키포즈 승인본(`.art-incoming/step1/Knight/keypose_approved.png` 로 저장)을 첨부한다.
방향: 기존 게임처럼 몸이 정면에 가깝고 소검이 이미지 기준 오른쪽. 좌우 이동은 게임이 뒤집는다.
루프: 프레임 8 → 프레임 1 로 끊김 없이 이어진다. 움직임은 작게(숨쉬기 + 검 끝 흔들림).

## 프롬프트 A — 프레임 1~4 (복붙)

```
첨부 이미지는 승인된 해골 기사 키포즈다. 이 캐릭터를 그대로(캡, 어깨 천, 반바지, 소검, 초록 눈, 상아색 뼈, 외곽선 두께, 팔레트 동일) 유지한 대기 애니메이션을 그린다.

1024x256 캔버스를 256x256 칸 4개로 나눠 가로로 프레임 1~4를 그린다.
- 각 칸에 캐릭터 1명, 칸 중앙, 발바닥이 칸 아래에서 40px 위의 같은 바닥선에 놓인다. 칸 가장자리와 최소 24px 간격.
- 캐릭터 키(발~머리 꼭대기)는 약 190px로 4칸 모두 동일. 몸 방향은 키포즈 1번(대기)과 같다.
- 배경은 순수 마젠타 #FF00FF 단색. 글자·격자선·번호·바닥 그림자 금지. 안티앨리어싱·디더링·그라데이션·글로우 금지.
- 외곽선은 #0A0D14 2px 굵기를 모든 프레임에서 동일하게 유지.

프레임별 움직임(아주 작게, 호흡하는 느낌):
 1) 기본 자세 (키포즈 1번과 동일)
 2) 몸 전체가 4px 위로, 검 든 팔이 살짝 위로
 3) 몸 6px 위로(최고점), 어깨 천이 아래로 살짝 처짐, 검 끝이 약간 오른쪽으로
 4) 몸 4px 위로(내려오는 중), 검 끝이 원위치로 돌아오는 중
머리·몸통·다리의 모양과 크기는 변하지 않고 위치만 약간 움직인다. 발은 바닥선에서 떨어지지 않는다.
```

## 프롬프트 B — 프레임 5~8 (A 결과를 승인한 뒤)

A 결과 이미지와 키포즈 승인본을 같이 첨부하고 아래를 붙인다.

```
첨부 이미지: (1) 승인된 키포즈 (2) 방금 그린 대기 프레임 1~4. 같은 캐릭터·같은 크기·같은 바닥선으로 프레임 5~8을 이어서 그린다.
1024x256 캔버스, 256x256 칸 4개. 규격은 프레임 1~4와 동일.
 5) 몸 2px 위로(내려오는 중), 어깨 천이 원위치 방향으로
 6) 기본 자세로 복귀 (프레임 1과 같음)
 7) 몸 2px 아래로, 검 든 팔이 살짝 아래로 (숨을 내쉬는 느낌)
 8) 몸 1px 아래로, 다음 프레임 1로 자연스럽게 이어지도록 거의 기본 자세
```

## 제가 확인할 것
- 8프레임을 이어 붙였을 때 끊김 없이 반복되는가
- 프레임마다 머리·몸 크기와 발 위치가 같은가(최대 ±2px)
- 캐릭터 디자인(캡·눈·천·검)이 프레임마다 변하지 않는가
