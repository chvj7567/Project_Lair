# 기사 S1 — 행별 원본 제작 ① idle (8프레임, 원본 이미지만 받음)

방침(2026-11-07): 코덱스에는 그림만 요청한다(행당 1회, 8프레임 독립 작화, 후처리 없음). 키잉·축소·정렬·팔레트·검사는 Claude 가 한다.
첨부: ① `keypose_approved.webp` ② `ref_knight_s1_idle_sprite.png` ③ 스타일 레퍼런스 스크린샷 (이후 행은 통과한 이전 행 이미지도 첨부)

## 프롬프트 (복붙)

```
[목표]
첨부한 해골 기사(1번 승인 키포즈)의 "대기(idle)" 애니메이션 8프레임을 그린다. 그림만 그리고 후처리(크기 조정·색 줄이기·정렬·배경 제거)는 하지 않는다. 결과는 원본 이미지 1장만 준다.

[캐릭터 — 모든 프레임에서 불변]
1번 승인 키포즈와 같은 치비 해골 기사: 상아색 뼈, 크고 둥근 해골 머리(머리 40~45%), 초록 형광 눈 2개(#4ADE80)와 어두운 눈구멍, 보이는 갈비뼈, 어두운 2px 외곽선(#0A0D14), 정수리의 낮은 어두운 캡(어두운 남회색 + 초록 띠), 왼쪽 어깨의 "작은" 낡은 천 조각(몸을 덮는 큰 망토 금지), 어두운 반바지, 오른손(이미지 기준 오른쪽)의 은색 한손 소검.
2번 이미지는 이 캐릭터의 실제 게임 스프라이트다. 형태·장비 구성은 2번을 따르고 비율·외곽선·색감은 1번을 따른다.
스타일: 치비 고밀도 도트, 3톤 셀 셰이딩 + 하이라이트(빛은 왼쪽 위), 안티앨리어싱·디더링·블러·그라데이션·글로우 금지, 글자·번호·격자선·바닥 그림자 금지.

[레이아웃 — 정확히 지킬 것]
- 캔버스 2048x1024, 512x512 칸 2줄 x 4칸 = 8칸. 프레임 순서는 왼쪽→오른쪽, 윗줄 F0~F3, 아랫줄 F4~F7.
- 배경은 순수 마젠타 #FF00FF 단색(캐릭터 안에 마젠타 사용 금지). 칸 사이 선·번호 금지.
- 모든 칸에서 캐릭터 크기가 같다: 발바닥~캡 꼭대기 약 224px.
- 발바닥 기준선은 모든 칸에서 칸 위쪽에서 364px, 몸 가로 중심은 칸 왼쪽에서 216px 에 맞춘다(칸마다 똑같은 위치). 위아래 움직임은 이 기준에서 그린 그대로 두고 프레임마다 다시 맞추지 않는다.
- 도트 크기: 모든 그림의 1픽셀을 정확히 4x4 블록으로 그린다(나중에 정확히 1/4로 줄인다). 블록 크기가 섞이거나 흐릿한 경계 금지.
- 캐릭터의 어떤 부분(검 끝 포함)도 칸 가장자리와 8px 이내로 가까워지면 안 된다.

[눈]
눈은 어두운 눈구멍 안에 초록 점이 또렷해야 한다(눈구멍 약 12x12px, 초록 코어 약 8x8px). 모든 프레임에서 눈 모양·위치·크기를 같게 유지하고 뭉개지지 않게 그린다.

[동작 — 숨쉬기 루프]
8프레임이 서로 눈에 띄게 달라야 한다(복사 금지). 아래 값은 512 칸 기준 픽셀이다.
F0: 기본 자세(승인 키포즈 1번과 같음).
F1: 몸 전체 8px 위, 검 든 팔이 살짝 위.
F2: 몸 12px 위(최고점), 어깨 천이 아래로 처짐, 검 끝이 살짝 오른쪽.
F3: 몸 8px 위(내려오는 중), 검 끝이 돌아오는 중.
F4: 몸 4px 위, 천이 원위치 쪽으로.
F5: F0 와 같은 높이로 복귀, 검이 아주 살짝 아래.
F6: 몸 4px 아래(숨을 내쉼), 팔이 살짝 아래.
F7: 몸 2px 아래, F0 으로 자연스럽게 이어지는 자세.
머리·몸통·다리·검의 모양과 크기는 변하지 않고 위치·각도만 조금 바뀐다. 발은 바닥선에서 떨어지지 않는다.
```

- 기준선(발 y=364, 중심 x=216)이 칸마다 일치하는가
