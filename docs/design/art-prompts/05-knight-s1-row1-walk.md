# 기사 S1 — 행별 원본 제작 ② walk (8프레임, 원본 이미지만 받음)

첨부: ① `keypose_approved.webp` ② `ref_knight_s1_idle_sprite.png` ③ `row0_idle_raw.webp`(통과한 idle 행 — 크기·디자인·눈 기준) ④ 스타일 레퍼런스 스크린샷

## 프롬프트 (복붙)

```
[목표]
첨부한 해골 기사의 "걷기(walk)" 애니메이션 8프레임을 그린다. 그림만 그리고 후처리(크기 조정·색 줄이기·정렬·배경 제거)는 하지 않는다. 결과는 원본 이미지 1장만 준다.

[캐릭터 — 모든 프레임에서 불변]
3번 이미지(통과한 대기 8프레임)와 완전히 같은 캐릭터·같은 크기·같은 그림체로 그린다: 상아색 뼈 치비 해골, 크고 둥근 머리, 초록 눈(#4ADE80)+어두운 눈구멍, 갈비뼈, 어두운 2px 외곽선(#0A0D14), 어두운 캡+초록 띠, 왼쪽 어깨 작은 낡은 천, 어두운 반바지, 오른손(이미지 기준 오른쪽)의 은색 한손 소검.
캐릭터 크기는 3번 이미지의 대기 프레임과 똑같이 맞춘다(키·머리 크기·검 길이 동일). 몸 방향도 대기와 같은 정면에 가까운 시점이다.
스타일: 치비 고밀도 도트, 3톤 셀 셰이딩, 안티앨리어싱·디더링·블러·그라데이션·글로우 금지, 글자·번호·격자선·바닥 그림자 금지.

[레이아웃 — 정확히 지킬 것]
- 캔버스 2048x1024, 512x512 칸 2줄 x 4칸 = 8칸. 프레임 순서는 왼쪽→오른쪽, 윗줄 F0~F3, 아랫줄 F4~F7. 칸 사이 선·번호 금지.
- 배경은 순수 마젠타 #FF00FF 단색(캐릭터 안에 마젠타 사용 금지).
- 바닥선: 모든 칸에서 칸 위쪽 364px. **모든 프레임에서 바닥에 닿은 발의 바닥면이 정확히 이 선에 닿아야 한다.** 몸 전체가 떠서 두 발이 모두 바닥선 위로 떨어지는 프레임 금지(걸을 때 한쪽 발만 들 수 있고, 다른 발은 항상 바닥선에 닿는다).
- 몸 가로 중심은 모든 칸에서 칸 왼쪽 216px(걸음에 따라 다리는 벌어져도 몸통 중심은 고정).
- 도트 크기: 모든 그림의 1픽셀을 정확히 4x4 블록으로 그린다. 흐릿한 경계 금지.
- 캐릭터의 어떤 부분(검 끝 포함)도 칸 가장자리와 8px 이내로 가까워지면 안 된다.

[눈]
눈은 모든 프레임에서 대기 프레임과 같은 크기·모양으로 또렷해야 한다. 초록 점이 뭉개지거나 사라지면 안 된다.

[동작 — 제자리 걷기 사이클(앞뒤로 걷는 게 아니라 제자리에서 다리만 교차)]
8프레임이 서로 눈에 띄게 달라야 한다(복사 금지). 한 걸음 = 4프레임.
F0: 오른쪽 다리(이미지 기준 오른쪽)가 앞으로 뻗어 발이 바닥에 닿음(접촉), 두 다리가 가장 벌어진 자세. 몸 가장 낮음.
F1: 체중이 앞발로 이동하며 몸이 약간 내려앉음(가장 낮은 지점), 뒷발 뒤꿈치가 들리기 시작.
F2: 뒷다리가 앞으로 모이는 통과 자세(한 발로 서 있고 다른 발은 무릎을 굽혀 들림), 몸이 가장 높음.
F3: 들린 다리가 앞으로 뻗어 나가는 중, 몸이 내려오는 중.
F4~F7: F0~F3 과 같은 동작을 반대 다리로(왼쪽 다리 접촉 → 내려앉음 → 통과 → 앞으로 뻗음). F7 다음에 F0 으로 끊김 없이 이어진다.
팔·검: 검 든 오른팔은 몸 걸음에 맞춰 위아래로 살짝(약 6px) 흔들리고, 검 각도는 대기 자세와 거의 같다. 왼팔은 다리와 반대로 앞뒤로 흔들린다. 어깨 천은 걸음 박자에 맞춰 살짝 펄럭인다.
몸 위아래 움직임은 최대 16px(칸 기준), 머리·몸통·검의 모양과 크기는 변하지 않는다.
```

## 제가 확인할 것
- 대기 행과 같은 크기(F0 키 ±3%) · 디자인 유지 · 눈 선명도
- 모든 프레임에서 한 발이 바닥선에 닿는가(발 떠 있는 프레임 0개)
- 두 걸음이 대칭이고 F7→F0 반복이 자연스러운가 · 칸 경계 8px 이상
