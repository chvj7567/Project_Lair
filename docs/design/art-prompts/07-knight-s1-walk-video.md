# 기사 S1 — 걷기 영상 (이미지→영상, 첫 프레임만 고정)

첨부: `still_idle_f0_1024_magenta.png` (첫 프레임)
후처리: 영상에서 첫 프레임과 가장 비슷한 프레임을 찾아 한 사이클을 자르고 8등분해 추출(Claude 담당).

## 프롬프트 (복붙)

```
첨부한 이미지를 첫 프레임으로 하는 6초 영상. 도트 아트 해골 기사가 제자리에서 걷는다(앞으로 이동하지 않고 같은 자리에서 다리만 번갈아 움직이는 걷기 사이클을 계속 반복).

반드시 지킬 것:
- 카메라는 완전히 고정(줌·팬·흔들림·회전 없음). 캐릭터는 화면 같은 위치에 머문다.
- 배경은 첨부 이미지와 똑같은 순수 마젠타 단색 그대로. 배경 변화·조명 변화·그림자·새 물체·글자 없음.
- 캐릭터의 디자인(상아색 뼈, 초록 눈, 어두운 캡과 초록 띠, 작은 어깨 천, 반바지, 오른손의 은색 소검)과 크기는 영상 내내 절대 변하지 않는다.
- 도트 아트 스타일 유지: 픽셀이 큼직하고 선명한 블록, 부드러운 보정·블러·모션 블러·안티앨리어싱 금지.
- 걷는 동안 한 발은 항상 바닥선에 닿는다. 몸이 위아래로 아주 조금만 움직인다. 검 든 오른팔은 살짝 흔들리고 검 각도는 거의 그대로.
- 한 걸음에 약 0.5초, 두 걸음(왼발·오른발)이 한 사이클.
```

## 확인 사항
- 영상 도구가 mp4 를 주면 프레임 추출용 ffmpeg 설치 필요(`pip install imageio-ffmpeg`).
- 디자인 변형이 크거나 반복 지점이 없으면 정지 이미지 방식으로 되돌린다.
