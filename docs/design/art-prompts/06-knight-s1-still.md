# 기사 S1 — 정지 캐릭터 1장 (영상 첫/마지막 프레임용 기준 이미지)

첨부: ① `keypose_approved.webp` ② `ref_knight_s1_idle_sprite.png` ③ `row0_idle_raw.webp` ④ 스타일 레퍼런스 스크린샷

## 프롬프트 (복붙)

```
[목표]
첨부한 해골 기사(1-1 스테이지 영웅)의 "정지 캐릭터" 이미지 1장을 그린다. 애니메이션 영상의 첫 프레임이자 마지막 프레임으로 쓸 기준 이미지이므로, 가장 안정적인 기본 대기 자세로 그린다. 그림만 그리고 후처리는 하지 않는다.

[캐릭터]
3번 이미지(통과한 대기 8프레임)의 첫 프레임과 완전히 같은 캐릭터·디자인·그림체: 상아색 뼈 치비 해골, 크고 둥근 머리(머리 40~45%), 초록 눈(#4ADE80)+어두운 눈구멍, 보이는 갈비뼈, 어두운 2px 외곽선(#0A0D14), 어두운 캡+초록 띠, 왼쪽 어깨 작은 낡은 천, 어두운 반바지, 오른손(이미지 기준 오른쪽)에 은색 한손 소검(비스듬히 위로).
정면에 가까운 시점, 두 발은 어깨 너비로 바닥에 평평하게 닿고 몸은 곧게 선다. 좌우 대칭에 가까운 가장 중립적인 자세.
스타일: 치비 고밀도 도트, 3톤 셀 셰이딩 + 하이라이트(빛은 왼쪽 위), 안티앨리어싱·디더링·블러·그라데이션·글로우 금지, 글자·격자선·바닥 그림자 금지.

[레이아웃]
- 캔버스 1024x1024, 캐릭터 1명만.
- 배경은 순수 마젠타 #FF00FF 단색(캐릭터 안에 마젠타 사용 금지, 배경에 그라데이션·노이즈 금지).
- 발바닥 기준선은 위에서 728px, 몸 가로 중심은 왼쪽에서 432px(캔버스 가로 42%). 발~캡 꼭대기 높이 약 448px.
- 사방 여백 충분(검 끝 포함 어디도 가장자리에서 80px 이내로 가까워지지 않게).
- 도트 크기: 1픽셀을 정확히 8x8 블록으로 그린다. 블록 크기가 섞이거나 흐릿한 경계 금지.

[눈]
눈은 어두운 눈구멍 안에 초록 점이 또렷하게. 대기 프레임과 같은 모양.
```
