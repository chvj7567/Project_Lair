# 아트 리소스 제작 규칙 v2 (art-resource-rules) — 치비 고밀도 도트 스타일 전면 개편

> 외부 도구(코덱스 등)로 만드는 **모든 2D 리소스**의 규격 SoT.
> **v2 = 스타일 전면 교체(A안)**: 저밀도 도트(영웅 31도트) → **고밀도 치비 도트 + 두꺼운 외곽선 + 큰 아이콘 UI**. 기준 레퍼런스는 사용자 제공 스크린샷(모바일 치비 도트 RPG 마을 화면).
> 현행(v1) 수치는 §13 이관표에 보존한다. v1 파일의 실제 크기는 `Assets/_Lair/Art/Sprites/` 와 `*_SheetSpec.json` 이 증명한다. **v2 파일이 임포트되면 SheetSpec JSON 이 새 SoT** 이며, 어긋나면 JSON 을 따르고 이 문서를 고친다.
> 무기 형태 고정·종족별 동작·지정 프레임만 수정하는 세부 규칙은 [monster-animation-art-rules.md](../../.agents/rules/monster-animation-art-rules.md)를 함께 적용한다.
> 단계 제약(CLAUDE.md §8): 아트 교체는 허용. **신규 몬스터 종족·신규 영웅 직업·6등급 이상은 여전히 금지** — 이 문서는 기존 콘텐츠(영웅 5직업, 몬스터 6종족 x 5등급)의 *외형 교체* 규격이다.

## 0. 스타일 바이블 (모든 리소스의 공통 룩)

레퍼런스에서 뽑은 **"이 느낌"의 정의**. 규격보다 먼저 지킨다.

| # | 요소 | 규칙 |
|---|---|---|
| S1 | **비율** | 치비 2~2.5등신. **머리 높이 = 몸 전체의 40~45%**. 얼굴(눈·눈썹)이 한눈에 읽힌다. 손발은 작고 단순 |
| S2 | **외곽선** | **짙은 외곽선**(순수 검정 금지, 인접 색의 어두운 색조 이동값). 캐릭터 128셀 기준 **2px**, 아이콘 128 기준 **2px**, 작은 UI 파츠는 1px. 외곽선은 닫힌 형태, 끊김 금지 |
| S3 | **음영** | 면 **3단**(밝음/기본/그림자) + 하이라이트 1점. 광원은 **좌상단 고정**. 디더링·그라데이션 번짐 금지 |
| S4 | **색감** | **채도 중상**. 배경은 중채도(초록·청록·회남색 계열), **포인트는 따뜻한 고채도**(불·금·보석)로 시선 유도. 영웅=밝고 선명, 몬스터=종족 색 + 발광 눈/룬 |
| S5 | **팔레트** | 캐릭터 1벌당 **≤ 48색**(외곽선·그림자·하이라이트 포함). 직업·종족별 팔레트 파일을 SheetSpec 에 기록 |
| S6 | **도트 정합** | 한 이미지 안에서 **도트 크기가 일정**. 회전·비정수 확대로 도트가 섞이면 반려. 단, 배경 바닥은 **큰 블록 모자이크**(§5)로 의도적 저해상도 |
| S7 | **글자 금지** | 이미지에 글자를 굽지 않는다(타이틀 로고 예외). 라벨은 CHText(흰 글자 + 짙은 외곽선) |
| S8 | **테마** | 소재는 이 게임 것(던전·몬스터·모험가 영웅). 레퍼런스의 *숲 마을·플레이어 치비 주인공* 은 가져오지 않고 **렌더링 기법만** 가져온다 |
| S9 | **포인트 광원** | 불꽃·보석·룬 등 발광체는 **본 시트가 아니라 Emission 시트/FX** 로 분리(HDR·Additive 는 머티리얼이 처리) |

> 스타일 승인 게이트: 전체 제작 전에 **영웅 1직업(Archer S1) + 몬스터 1종족(Wisp)** 샘플을 실제 전투 씬에 넣어 사용자 승인을 받는다(§12 단계 1).

## 2. 영웅 (Heroes2D) — 5직업 x 5단계

직업: Knight · Archer · Assassin · Berserker · Paladin. 단계 S1~S5(S1 = 접미사 없음).

### 2.1 시트 규격

| 항목 | v2 값 | (v1) |
|---|---|---|
| 셀 | **128 x 128 px** | 72 |
| 열 x 행 | **8열 x 9행 = 1024 x 1152 px** (인덱스 = `row*8+col`) | 20x9, 1440x648 |
| 몸 높이 | **56 도트** (발~정수리, 모자·뿔 제외 몸 기준) | 31 |
| PPU | **56** (몸 56도트 = 월드 1유닛, v1 과 동일 크기) | 31 |
| 피벗 | 시트 공통 Custom Pivot, **초기값 (0.4236, 0.2917)** — 첫 시트 확정 때 SheetSpec 에 실측 기록 | 동일 |
| 외곽선 | 2px, 머리 40~45% | 1도트 |
| 파일 | `<직업>_Sheet[_S2..S5].png` + 각 `_Emission.png` | 동일 |

- 셀 128 안에서 몸 56도트 + 위 여백 약 35px(무기·모자·뿔·이펙트), 아래 여백 약 37px(발~바닥 피벗 위) — 몸을 셀 안에서 **가로 중앙(피벗 x 기준)** 에 둔다.
- 열이 8인 이유: 모든 애니메이션을 최대 8프레임으로 제한했다(2026-11-07 사용자 결정 — v1 의 slash/stab 9, spawn 16 을 8 로 축소). 텍스처 크기도 절반.

### 2.2 행(애니) 순서 — 고정 (프레임·fps 는 v1 과 동일, P9)

| 행 | 이름 | 프레임 | fps | 루프 | 비고 |
|---|---|---|---|---|---|
| 0 | idle | 8 | 8 | O | |
| 1 | walk | 8 | 10 | O | |
| 2 | run | 8 | 14 | O | |
| 3 | slash01 | 8 | 8 | X | **타격 = F4(0.5s), 종료 = F7** — 기사 실측: 기존 17프레임@15fps, `OnAttackStrike` 0.5s 유지. 락 해제는 `_attackEndFallback` 1.8s |
| 4 | slash02 | 8 | 8 | X | slash01/stab 복제(`copyOf`) 가능 |
| 5 | stab | 8 | 6.25 | X | **타격 = F5(0.8s)** — 기사 실측: 기존 20프레임@12fps×1.0204, `OnAttackStrike` 0.8s 유지 | 타이밍 동일 |
| 6 | hit | 6 | 12 | X | |
| 7 | death | 8 | 10 | X | 마지막 프레임 hold |
| 8 | spawn | 8 | 6 | X | 등장 연출, 기사 기존 16프레임@12fps=1.33초 길이 유지, 스폰 게이트는 fallback 1.8초 그대로 |

- 남는 셀은 완전 투명.
- 타격 프레임(F4)에서 무기가 목표에 닿는 포즈 — 옮기면 판정과 그림이 어긋난다.
- 시트 가장자리·셀 경계에 닿는 프레임 금지(여유 ≥ 2px). 불가피한 프레임은 SheetSpec `edgeClipFrames` 에 기록.
- **S2~S5 는 S1 과 같은 실루엣·같은 프레임 배치**. 장비·색·장식만 변한다. 단계가 높을수록 장식·발광 증가(승급 연출 대응). **S2~S5 시트는 AI 로 새로 그리지 않고 §2.4 방식으로 S1 에서 굽는다.**

### 2.4 영웅 단계(S2~S5) 생성 방식 — S1 1장에서 굽기 (확정)

외부(AI)로 만드는 영웅 시트는 **직업당 S1 한 장(총 5장)** 뿐이다. S2~S5 는 에디터 툴(`HeroTierBaker`, 신규)이 **S1 + 보조 시트 + 장식 스프라이트**를 합성해 **기존 파일명 그대로** 굽는다. 런타임·프리팹·클립은 변하지 않는다(여전히 `<직업>_Sheet_S2..S5.png` 를 읽는다).

| 입력 | 만드는 법 | 내용 |
|---|---|---|
| `<직업>_Sheet.png` (S1) | **AI 제작(5장)** | 기본 외형 전 프레임 |
| `<직업>_Sheet_Mask.png` | S1 에서 스크립트 반자동 생성 + 수작업 보정 | S1 과 같은 크기. 픽셀마다 **재질 인덱스**(1=갑옷/천, 2=금속, 3=가죽, 4=피부·머리는 변경 제외…)를 색으로 표시한 보조 시트 |
| `<직업>_Sheet_Anchor.png` | 수작업 | S1 과 같은 크기. 프레임마다 **부착 앵커 점**(머리 정수리, 어깨 좌우, 등, 무기 손)을 1픽셀 색점으로 표시 |
| `<직업>_Tier.json` | 수작업 | 단계별 설정: 재질별 **팔레트 스왑 테이블**(S2~S5), 부착할 **장식 스프라이트 목록**(앵커 종류·단계·레이어 순서·발광 여부) |
| `Heroes2D/Deco/<직업>_<장식>.png` | AI 또는 수작업 | 장식 소형 스프라이트(투구 장식, 어깨 갑옷, 망토, 무기 오라 등). 직업당 단계별 **약 2~3개**, 치비 외곽선 2px, 정면 기준 1장 + 필요 시 방향별 |

- **굽기 순서**: S1 복사 → 마스크 기준 재질별 **팔레트 스왑**(외곽선·피부·머리카락 제외) → 앵커 위치에 **장식 부착**(외곽선 재생성) → Emission 합성 → 가장자리 여백 검사 → `_S2..S5.png` 및 `_S2..S5_Emission.png` 출력.
- **차이는 색·부착물로 한정**: 실루엣이 크게 바뀌는 변화(체형·무기 교체)는 불가. 필요하면 해당 직업·단계만 예외로 AI 시트를 따로 추가(SheetSpec 에 `tierMode: "manual"`).
- **Emission**: S1 Emission 은 AI/수작업. 단계별 Emission 은 툴이 `Tier.json` 의 발광 장식·발광 팔레트로 합성.
- 장식을 새로 얹으면 **S1 프레임과 같은 프레임 수**가 앵커로 자동 대응되므로 프레임별 장식 시트를 그리지 않는다.
- 이 방식은 몬스터 강화 덧그림(`_T1.._T3`)과 같은 발상이다. 승급 연출(번쩍임·승급 컷)은 기존 그대로 동작한다.

## 3. 몬스터 (Monsters2D) — 6종족 x 5등급

종족: Wisp · Wraith · Reaper · Hex · Plague · Phantom. **신규 종족 금지**.
등급 2~5(견습·숙련·정예·군주)는 **1등급 베이스 시트를 `MonsterGradeAssetBuilder` 계열 생성기가 가공해서 굽는다**. 외부에서 만드는 것은 **1등급 베이스 시트 + Emission + 강화 덧그림(T1~T3)** 와 등급 오라 스프라이트다.

### 3.1 시트 규격

| 항목 | v2 값 | (v1) |
|---|---|---|
| 열 x 행 | **6열 x 5행** (인덱스 = `row*6+col`) | 동일 |
| 행 순서 | **idle, move, attack, hit, death** | 동일 |
| PPU | **96** (v1 48 의 2배, 월드 크기 불변) | 48 |
| 피벗 | **(0.5, 0)** 하단 중앙 | 동일 |
| 외곽선 | 2px, 3단 음영, 발광 눈/룬은 Emission | 1도트 |

셀 크기는 v1 의 **정확히 2배**(HP바·오라·판정 비율 보존).

| 종족 | 1등급 셀 | 등급 시트 셀 | idle | move | attack | hit | death |
|---|---|---|---|---|---|---|---|
| Wisp | **96** | 136 | 6f/8 | 6f/12 | 5f/12 | 3f/12 | 6f/12 |
| Wraith | **176** | 224 | 6/6 | 6/8 | 5/10 | 3/12 | 6/12 |
| Reaper | **144** | 168 | 6/8 | 6/12 | 4/12 | 3/12 | 6/12 |
| Hex | **112** | 136 | 6/8 | 6/12 | 5/12 | 3/12 | 6/12 |
| Plague | **80** | 104 | 6/8 | 6/12 | 5/12 | 3/12 | 6/12 |
| Phantom | **80** | 152 | 4/10 | 4/12 | 4/12 | 3/12 | 6/12 |

- 표기: `f/숫자` = 프레임/fps. 프레임 수·fps 는 v1 SoT 그대로(P9). 몬스터는 **작게 많이** 나오므로 프레임이 적은 게 정상.
- 시트 크기 = (6 x 셀) x (5 x 셀). 최대 Wraith 등급 224 → 1344 x 1120(한도 내).
- **셀의 55~65% 이내에 몸**(위 여백 = HP바 위치 `hpBarFormula`·`topY` 계산용). 몸이 셀 위쪽에 붙으면 HP바가 틀어진다.
- 등급 시트 셀이 더 큰 이유는 오라·덧그림 여백이다. **1등급 원본에는 이 여백을 미리 그리지 않는다.**
- 등급 표현(생성기 담당): 몸 색·외곽선 색·크기 배율(x1.05/1.10/1.18/1.30)·발광·바닥 오라·종족 모티프. 군주 금 왕관 금지. 1등급은 기본 외형.
- 몬스터도 **치비 비율 + 표정**: 눈·입의 개성이 읽혀야 한다(귀여움 + 약간의 위협). 종족 모티프는 실루엣으로 구분(Wisp=불꽃 방울, Wraith=망토 유령, Reaper=낫, Hex=마법진 문양, Plague=독 구름, Phantom=반투명 잔상).

### 3.2 몬스터 부속

| 리소스 | v2 규격 |
|---|---|
| 몬스터 아이콘 `MonsterIcons/<종족>.png` | **512 x 512** 유지(고해상도 일러스트 계열), 등급 변형 금지 |
| 등급 오라 `MonsterGradeAura.png` | 바닥 링 1장, 도트 크기는 몬스터 PPU 와 일치 |
| 강화 파츠 `_T1.._T3` | 베이스와 동일 셀·배치, 덧그림 영역만 불투명 |

## 4. 애니메이션 일반 규칙

### 4.1 프레임 수 기준표

| 용도 | 권장 | 허용 |
|---|---|---|
| 영웅 루프 idle/walk/run | 8 | 6~8 |
| 영웅 공격 | 9 (F4 타격) | 8~10, 타격 번호 고정 |
| 영웅 hit / death / spawn | 6 / 8 / 16 | 4~6 / 6~10 / 12~16 |
| 몬스터 idle/move | 6 | 4~6 |
| 몬스터 attack / hit / death | 5 / 3 / 6 | 4~5 / 3 / 6 |
| FX 단발 | 10~16 | 8~24 |
| UI 루프 FX | 3~8 | — |

### 4.2 타이밍

- fps 는 **8~15 정수**. 루프 8~10, 전투 동작 12~15.
- 공격: 선딜(F1~F3) → **타격(F4)** → 후딜(F5~). 후딜이 짧으면 연속 공격이 끊겨 보인다.
- 치비 스타일은 **과장된 포즈**가 매력이다 — 공격 선딜에서 몸을 크게 젖히고, 타격 직후 1프레임 **스쿼시/스트레치**(몸 높이 ±8% 이내, 발 위치는 불변).
- 사망/비루프는 마지막 프레임 hold(소멸은 런타임 페이드).
- 루프 애니는 마지막 프레임 → 첫 프레임이 자연스럽게 이어질 것.
- 프레임 수·fps 를 바꾸면 SheetSpec 클립 이벤트 시간을 함께 수정(P9 로 원칙적 금지).

### 4.3 Emission 시트 (영웅·몬스터)

- 본 시트와 **동일 크기·동일 배치**. 발광 픽셀만 불투명(눈·룬·불꽃·보석), 나머지 투명.
- 발광 색 = 본 시트 해당 색과 같거나 더 밝은 색.
- 발광 없는 캐릭터는 Emission 시트를 만들지 않는다(SheetSpec `emission:false`).

## 5. 배경 (Backdrop2D) — 저해상도 모자이크 바닥 + 고디테일 소품

레퍼런스의 핵심 질감: **바닥은 큰 블록 모자이크(의도적 저해상도), 수풀·벽·소품은 고디테일, 가장자리는 어두운 비네트**. 캐릭터가 고밀도라 배경이 더 저해상도여야 캐릭터가 뜬다.

## 10. 제작·정규화 파이프라인 (외부 도구/AI 산출물)

AI 는 균일 그리드·프레임 일관성·도트 정합을 못 지킨다. **아래를 의무로 한다.**

### 10.1 캐릭터 제작 순서

1. **캐릭터 확정 시트(턴어라운드)**: 정면·측면·3/4 후면 1장씩 + 팔레트(≤48색) 확정. 이후 모든 프레임은 이것을 참조.
2. **키 포즈**: 직업·종족당 idle 중립 / 공격 타격(F4) / 피격 / 사망 마지막 4장을 먼저 확정.
3. **프레임 생성**: 키 포즈를 참조 이미지로 넣고 **한 번에 최대 4~6프레임**. 8프레임 통생성 금지.
4. **한 시트 = 한 종류**, 한 캐릭터 안에 서로 다른 셀 크기 섞기 금지.

### 10.2 프롬프트 필수 항목

- 셀 크기·열x행·행 순서·프레임 수(본 문서 표)
- 오른쪽 향함, 발 위치 고정, 몸 크기 고정
- 배경: 단색 마젠타 `#FF00FF`(FX 는 검정 `#000000`)
- 스타일 문구(고정): `chibi 2.5-head proportion, thick dark 2px outline, 3-tone cel shading with top-left light, high-saturation palette, crisp pixel art, no anti-aliasing, no dithering, no text`
- 금지: 텍스트, 격자선, 라벨, 프레임 번호

### 10.3 정규화 스크립트 순서

1. 프레임 단위 컷 → 마젠타/검정 크로마키 제거 → 알파
2. 몸 바운딩 박스 기준 **목표 해상도로 최근접 다운스케일**(영웅 몸 56도트, 몬스터는 종족 표)
3. **팔레트 양자화**(≤48색, 외곽선 색 고정)
4. **외곽선 정리**: 외곽선 2px 일정, 끊김 보정
5. 피벗 정렬 후 셀 패킹, 가장자리 여백 ≥ 2px 확인(`edgeClipFrames` 검출)
6. 사용 안 하는 셀 투명, 시트 크기 = 열x셀 / 행x셀 일치 확인

### 10.4 검수 체크리스트

- [ ] 시트 크기·셀 크기가 본 문서와 일치
- [ ] 모든 프레임 몸 크기·발 위치 동일(±0)
- [ ] 머리 비율 40~45%, 외곽선 2px 일정
- [ ] 팔레트 ≤ 48색, 반투명 번짐 없음(FX·글로우 제외)
- [ ] 공격 타격 프레임 번호 = 규격(영웅 F4 / 몬스터 SheetSpec)
- [ ] Emission 동일 크기, 발광 부위만 불투명
- [ ] 오른쪽 향함
- [ ] **게임 안 크기 비교**: 같은 월드 크기에서 v1 대비 크기가 달라지지 않음(P1)

### 10.5 임포트

Point · 밉맵 off · sRGB on · `alphaIsTransparency` on · 압축 PC none / 모바일 ASTC 6x6. 슬라이스·피벗·PPU 는 SheetSpec 값. 클립·컨트롤러 생성은 기존 에디터 파이프라인(SheetSpec 기반)을 사용한다.

```
  Backdrop2D/      Battle_Backdrop[_챕터].png, Village_*, Loading_*, Altar2D_*, Shadow_R*, Flame_*_Sheet.png, Vignette_Overlay.png, Backdrop2D_SheetSpec.json
  UiDot/ (→ 개편 후 Ui/)  Ui_* 파츠
  CardArt/  CardIcons/  MonsterIcons/  HeroIcons/  VillageIcons/  Currency/  SynergyIcons/  Relic/
```

- PascalCase, 접미사: `_Sheet`(애니) / `_Emission`(발광) / `_S2..S5`(영웅 단계) / `_T1..T3`(몬스터 강화) / `_R<n>`(반경).
- Addressable 주소 = 파일명. 새 파일은 Enum(`CommonEnum.cs`) + Addressable 등록을 같이(Rule 03 §2).
- 레거시 3D 파일(`Skeleton_*`, `Witch Hat*`, `Kid Ghost*`, `Falchion*`)은 참조 금지.

## 12. 도입 순서 (전면 교체 로드맵)

전면 교체는 한 번에 갈아끼우면 위험하므로 **단계마다 사용자 승인 게이트**를 둔다.

**한 화면이 끝날 때까지 다음 화면으로 가지 않는다**(한 화면에 v1/v2 혼재 금지). 별도 브랜치에서 작업하고 화면 단위로 합친다.

| 단계 | 내용 | 산출 | 끝나는 조건 |
|---|---|---|---|
| 0 | **준비(코드·툴)**: 정규화 스크립트, 영웅 슬라이스 `row*20`→`row*8`, `MonsterGradeAssetBuilder` 상수 v2 화, **`HeroTierBaker`(§2.4) 신규**, 임시 이미지로 애니 재생 확인 | 툴·테스트 | 임시 시트로 영웅·몬스터 애니 정상 |
| 1 | **스타일 샘플**: Archer S1(전 애니) + Archer 마스크/앵커/Tier.json + 단계 2개 굽기 시험 + Wisp 1등급 + 마을 메뉴 아이콘 3개 + `Ui_LabelPlate`/`Ui_Pill` | 샘플 + 게임 안 스크린샷 | **스타일 승인** |
| 2 | **전투 화면**: 영웅 5직업(AI 시트 **5장** + 마스크·앵커·Tier + S2~S5 굽기) + 영웅 아이콘, 몬스터 6종족 + T1~T3 + 등급 24종 재생성, FX 전수, 전투 배경 5장, 전투 HUD | 전투 일체 | 전투 한 판이 새 스타일만으로 표시 |
| 3 | **마을 화면**: 마을 배경, 메뉴 아이콘 12종, 월드맵, 마을 HUD, 팝업 파츠 | 마을 일체 | 마을·팝업 전부 새 스타일 |
| 4 | **로딩**: 배경·레이어 부품·진행바 | | |
| 5 | **카드·유물·재화**: 카드 28장, 유물 16종, 재화·시너지·난이도 아이콘 | | |

- 매 단계 종료 시 EditMode 테스트·해상도 대응 테스트·스크린샷 확인. 코드는 gameplay-programmer, 테스트는 test-engineer.

**코드/에디터 영향(아트 규칙 문서 범위 밖, 별도 작업)**
- 영웅 클립 빌더·`MonsterGradeAssetBuilder`: 셀·열 수·PPU·피벗 상수와 `topY`·`bodyOffset`·`auraRadiusTexel` 재측정.
- `Heroes2D` 20열 → 8열: 슬라이스 인덱스 `row*20+col` → `row*8+col`.
- 몬스터 프리팹 PPU/스케일, HP바 공식 재검증, FX 프리팹 스케일.
- 프리팹 UI: `Px_*` → `Ui_*` 교체(스프라이트 참조 일괄).
- `resolution-adaptation` 테스트 재실행.
- 위 작업은 **gameplay-programmer 위임**, 이 문서는 아트 규격만 다룬다.

## 14. 하지 말 것

- 사이드뷰 배경 · 플레이어 치비 주인공(던전 영주가 마을에 서는 건 별도 기획 필요) · 레퍼런스 소재 복제(숲 마을 구도·캐릭터 얼굴).
- 신규 몬스터 종족 / 영웅 직업 / 6등급 이상 / 등급별 아이콘 변형.
- 해상도만 올리고 PPU 를 안 올리는 것(월드 크기 폭주).
- 프레임 수·fps·타격 번호 변경.
- 이미지에 글자 굽기(타이틀 제외).
- 프레임마다 몸 크기·발 위치가 다른 시트.
- SheetSpec 갱신 없이 시트 추가.
- 한 화면에서 v1 `Px_*` 와 v2 `Ui_*` 파츠 혼용.
- 좌향 프레임 별도 제작.
