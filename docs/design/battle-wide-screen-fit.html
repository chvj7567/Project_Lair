배틀 화면이 폰 전체를 쓰게 됩니다

긴 폰(20:9 등)에서 마을은 화면을 가득 채우는데 전투 화면만 양옆이 비어 보였습니다. 이제 전투도 화면 끝까지 채웁니다.

이렇게 바뀝니다

1. 배경이 꽉 찹니다
던전 바닥과 장식이 화면 양 끝까지 이어집니다. 불티도 끝까지 날립니다.
2. 전투 구역은 그대로
영웅과 몬스터가 싸우는 자리는 어느 폰에서나 똑같습니다. 넓은 폰이라고 유리하지 않습니다.
점선 안이 모든 기기에서 같은 전투 구역입니다.
3. 버튼과 정보는 가장자리로
체력, 타이머, 시너지 같은 정보가 화면 모서리에 붙습니다. 노치·홈바에 가려지지 않게 안쪽으로 비켜 줍니다.
4. 팝업은 지금 그대로
결과창, 카드 선택 등은 지금 크기로 화면 한가운데 뜨고, 배경만 양옆까지 어두워집니다.

화면 비율별 모습

화면모습
일반 16:9지금과 같음
긴 폰 (19.5:9 ~ 21:9)전체 화면 사용
더 긴 폰 (22:9 이상)양 끝에 얇은 검은 띠가 조금 남음
태블릿 (4:3, 16:10)위아래에 띠가 남음 (지금과 같음)

그대로인 것

마을·로딩 화면, 전투 규칙과 밸런스, 랭킹 기록은 변하지 않습니다.
결정해 주세요
  1. 아주 긴 폰(22:9 이상)에서 양 끝 얇은 띠를 허용할까요?
    추천: 허용 (대안은 화면을 확대해 위아래가 잘리게 하는 것 — 전투 구역이 달라져 비추천)
  2. 태블릿의 위아래 띠를 그대로 둘까요?
    추천: 그대로 (없애려면 세로로 더 긴 배경 그림을 새로 그려야 함)
  3. 체력·버튼 같은 정보를 화면 맨 가장자리에 붙일까요?
    추천: 가장자리 (대안은 전투 구역 가장자리에 고정 — 긴 폰에서 가운데로 몰림)
