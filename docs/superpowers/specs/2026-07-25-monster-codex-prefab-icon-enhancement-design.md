# 몬스터 도감 — 프리팹 렌더 아이콘 + 강화 레벨/발광 반영 Design Spec

- **작성일**: 2026-07-25
- **단계**: v0.3 (범위 내 — 신규 몬스터 제작 아님, 기존 프리팹의 UI 표현 + 기존 발광 SoT 재사용)
- **분류**: UI/도감 표현 + 에디터 아이콘 베이커
- **문서 성격**: spec — 무엇을 만들지의 골격 + 결정 락. 수치·스타일(밝기/스케일 곡선·배지)은 game-designer 기획서가 확정.

---

## 1. 의도

플레이어의 **투자 보상감**(§brainstorming Q1=A): 몬스터 강화에 소울을 투자할수록 그 몬스터가 눈에 띄게 강해 보이게 한다. 도감(몬스터 메뉴)에서 (a) **실제 몬스터 원본**을 아이콘으로 보여주고, (b) 강화 **레벨과 그 레벨의 발광**을 반영해 "내가 키운 몬스터"가 도감에서 확연히 다르게 보이도록 한다. 전투의 `MonsterEnhancementVisual` 발광과 **같은 색 SoT**를 써서 "도감 = 전장" 일치를 유지한다.

## 2. 범위

### 포함
- **Part 1**: 6종 몬스터 프리팹을 렌더해 도감 아이콘 스프라이트로 굽는 에디터 베이커 → `MonsterIcons/{6종}.png` 갱신(실제 원본 반영).
- **Part 2**: 도감 몬스터 셀에 강화 레벨(Lv N/5) 표시 + 아이콘에 그 레벨의 발광색·밝기·스케일 반영.

### 비포함 (명시적 제외)
- **레벨별 개별 스프라이트/형태 제작** — 종족당 아이콘 1장(원본)만, 레벨은 셀 표현(틴트·밝기·스케일)으로. (신규 리소스 0, §8 준수)
- **전투 몬스터 형태 변화** — 강화는 계속 발광만 바꾼다(형태 불변). 도감도 그 사실과 일치(형태 아이콘 아님).
- **신규 몬스터/카드/영웅 리소스 제작** — 없음. CLAUDE.md·스코프 변경 불필요.

## 3. 핵심 결정 (락)

1. **아이콘 = 프리팹 원본 렌더** — 손그림이 아니라 실제 몬스터 프리팹을 카메라로 찍은 스프라이트. **스켈레톤 영웅 아이콘 캡처와 동일 방식**(그 일회용 툴은 Rule 04 §3로 삭제됨 → git 히스토리 참조해 미러링).
2. **종족당 아이콘 1장** — 레벨 표현은 런타임 셀에서 발광색·밝기·스케일로. 레벨별 스프라이트 굽지 않음.
3. **발광색 단일 SoT 재사용** — `Lair.Data.SpeciesVisual.SpeciesGlowColor(EMonster)`. 전투 발광·상점 셀·도감 셀이 전부 같은 색을 읽는다.
4. **레벨 소스** — `MetaProfile.ShopLevels`의 `Enhance_<EMonster>`(상점 「몬스터 강화」와 동일 소스). Lv0 = 미강화(발광 off, 순수 아이콘).
5. **베이커는 일회용** — 생성 후 삭제(Rule 04 §3). 단일 진실은 구워진 PNG + .meta.

## 4. Part 1 — 아이콘 베이커 (에디터 툴)

- 6종 몬스터 프리팹(`Art/Characters/{Wisp,Wraith,Reaper,Hex,Plague,Phantom}.prefab`)을 RenderTexture + 카메라로 렌더 → `ReadPixels` → `EncodeToPNG` → `Art/Sprites/MonsterIcons/{종}.png` 덮어쓰기(투명 배경).
- 프레이밍/조명/카메라 각도는 **영웅 캡처 툴과 동일 규약**(git 히스토리의 삭제된 hero 아이콘 베이커 참조). 6종 일관 프레이밍.
- 실행: gameplay-programmer 작성 → 메인이 UnityMCP 메뉴로 실행 → 육안 확인 → 툴 삭제.
- 스프라이트 임포트 설정(Sprite 타입·pivot·알파)은 기존 MonsterIcons 관례 유지 → 도감/상점 셀이 그대로 로드.

## 5. Part 2 — 도감 레벨/발광 반영

- `CodexPopup` 몬스터 셀 데이터(`CodexCellData`)에 **강화 레벨** 추가. `BuildMonsterCellData`가 `profile.GetShopLevel("Enhance_"+type)`로 채움.
- 셀 표시:
  - **레벨 배지/텍스트** — 강화 Lv N/5 (Lv0이면 숨김 또는 "미강화" — 기획서 확정).
  - **아이콘 발광/틴트** — `SpeciesGlowColor(type)` 색을 레벨 밝기(level/Max 또는 곡선)로 아이콘에 반영. 상점 「몬스터 강화」 셀 글로우 프레임과 동일 원리·동일 색.
  - **스케일** — 레벨 높을수록 아이콘 살짝 확대(만렙 정점감). 곡선은 기획서.
- 미해금(SeenMonsters 미포함) 실루엣 처리와의 상호작용: 미해금이면 강화 표시 없음(실루엣 우선) — 기획서 확정.

## 6. 아키텍처 정합

- 발광색은 `SpeciesVisual.SpeciesGlowColor` 단일 SoT(전투·상점·도감 공유) — Character↔UI 역참조 없음(`Lair.Data` 최하위).
- 아이콘 로드는 기존 `CodexPopup.SpeciesIcon` 인스펙터 switch resolver 관례 유지(Enum 키 로드 아님).
- 레벨 소스는 `ShopLevels`(클라우드 동기 대상) — 별도 저장 신설 없음.

## 7. game-designer가 확정할 것

- 레벨별 **밝기·스케일 곡선**(선형 vs 곡선, 만렙 정점 강조 정도).
- **레벨 배지** 위치·스타일·Lv0 표기 방식.
- 미해금 실루엣 ↔ 강화 표시 **상호작용** 규칙.
- 베이커 **카메라 프레이밍/조명**이 영웅과 톤 일치하는지(육안 기준).

## 8. 테스트 관점

- `BuildMonsterCellData` — 강화 레벨이 셀 데이터에 정확히 매핑되는가(Lv0/중간/만렙, 미해금 시 처리).
- 발광색 = `SpeciesGlowColor`와 일치(회귀).
- 아이콘 베이크 결과는 육안 검증(에디터) — 자동 테스트 대상 아님.
