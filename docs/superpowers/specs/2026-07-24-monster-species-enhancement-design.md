# 몬스터 종족별 강화 (상점 「몬스터 강화」 탭) — Design Spec

- **작성일**: 2026-07-24
- **단계**: v0.3 (메타 진행 — §8 기존 리소스 재조합 범위 내)
- **분류**: 메타 진행 신규 시스템 (상점 확장)
- **문서 성격**: spec — *무엇을* 만들지의 골격 + 결정 락. 구체 수치(배수 곡선·가격·발광 세기)는 game-designer 기획서(`docs/design/`)가 확정한다.

---

## 1. 의도

기존 상점의 몬스터 강화는 **전종(全種) 글로벌 스탯 배율**(예: "모든 몬스터 HP +5%")뿐이라, 5개 보스 스테이지가 사실상 하나의 플레이 경험이 되는 것과 마찬가지로 강화 선택도 단조롭다. 플레이어가 **자기 취향의 종족을 골라 키우는** 축을 추가해 메타 진행의 깊이·재방문 동기를 강화한다. 강화한 종족이 **전장에서 눈에 띄게 빛나** 보이도록 하여 "내가 키운 게 실제로 보인다"는 피드백을 만든다.

v0.3 가설(재방문·경쟁·기기이전)의 **재방문** 축을 메타 콘텐츠로 보강한다.

## 2. 범위

### 포함
- 6종(Wisp / Wraith / Reaper / Hex / Plague / Phantom) **각각 개별 강화** (Lv0 → Lv5)
- 강화 레벨 = 해당 종족의 **HP·공격력 배수**(레벨당 곱연산)
- 강화 단계별 **시각 표시** — 전투 몬스터 + 강화 메뉴 카드 양쪽
- 상점 UI **2탭 분리**: 「스탯 강화」(기존 글로벌) / 「몬스터 강화」(신규 종족별)

### 비포함 (명시적 제외)
- 종족 × 스탯 매트릭스(6종 × 6스탯) — YAGNI, 항목 폭증
- 강화 대상 스탯을 HP·공격력 이외로 확장(이속·사거리 등)
- 전투 중 실시간 강화
- 리더보드/랭킹 연동
- 신규 몬스터·카드·영웅 리소스 제작 (§8 금지 — 기존 6종 + 발광 채널 재사용으로만 구현)

## 3. 핵심 메커니즘 (결정 락)

1. **종족별 개별 강화** — 한 탭 항목 = 한 종족. 스탯 강화 탭(전종 글로벌)과는 다른 축.
2. **강화 효과** = HP·공격력 배수만. 보스 스테이지 variant(`HpMultiplier`·`PowerMultiplier`)와 대칭 모델.
3. **곱연산 3축 독립** — 최종 스탯 = `기본 × 스탯강화(전종 글로벌) × 종족강화`. 세 축은 서로 독립적으로 곱해진다.
4. **5단계** — Lv0(미강화)~Lv5. 보스 5스테이지와 대칭.
5. **시각 = 강화감 얹기** — 종족 고유 외형을 유지하고, 레벨이 오를수록 **발광·아웃라인 세기만 escalate**(틴트는 절제). Lv0은 발광 0. 보스처럼 종족 전체를 단계 색으로 덮지 **않는다**(종족 정체성 유지 + Lv5끼리 혼동 방지).

## 4. 아키텍처 — 기존 상점 인프라 재사용

신규 병렬 시스템을 만들지 않고, 완성된 상점 파이프에 **효과종류 1개**를 얹는다.

기존 파이프:
```
ShopItemDef (효과종류+레벨) → MetaProfile.ShopLevels (저장/클라우드동기)
  → ShopService (구매/가격/만렙) → MetaBattleBonus (전투 시작 배율 집계)
  → BattleController.ApplyMonsterStats (raw × 배율 적용)
```

### 4.1 데이터
- `EShopEffectKind`에 **`MonsterSpecies`** 추가.
- `ShopItemDef`에 대상 **`EMonster Species`** 필드 추가 (`EffectKind == MonsterSpecies`일 때만 사용). `PerLevelMul`은 이 종족의 HP·공격력에 함께 적용되는 레벨당 배수로 재사용.
  - (HP·공격력을 각각 다른 배수로 하려면 필드 분리 여지 있음 — 기획서가 단일/분리 여부를 확정한다. 기본안: 단일 배수.)
- 종족 강화 항목 6개를 `MetaConfig.ShopItems`에 등록. Id 규약: `Enhance_<EMonster>` (예: `Enhance_Wisp`).
- 저장은 기존 `MetaProfile.ShopLevels` 그대로 → **클라우드 동기 자동 포함**(신규 저장 필드 없음, 마이그레이션 불필요).

### 4.2 전투 적용
- `MetaBattleBonus`에 **종족별 HP/공격력 배수 맵**(`Dictionary<EMonster, (float hp, float power)>` 성격) 추가. `From()`에서 `MonsterSpecies` 항목을 `PerLevelMul^level`로 집계.
- `BattleController.ApplyMonsterStats(character, key, …)`가 기존 글로벌 배율에 **해당 종족 배수를 한 번 더 곱함**. 모든 몬스터 스폰·소급 경로가 이 메서드 하나를 통과하므로 소급 적용도 자동.

### 4.3 시각
- 신규 컴포넌트 **`MonsterEnhancementVisual`** — 보스 `HeroStageVariantApplier`의 발광/아웃라인 로직을 몬스터용으로 재사용/이식. 참조는 `[SerializeField]` 인스펙터 와이어링(Rule 02 §5).
- 입력은 **강화 레벨(1~5)** → 레벨별 발광 강도·아웃라인 세기(설정값)를 적용. Lv0은 발광/아웃라인 off.
- **틴트는 건드리지 않는다**(종족 base color 유지) — 발광/아웃라인만. `HitFlash`의 baseline 색과 충돌하지 않도록, 몬스터는 발광 채널만 사용.
- 적용 시점: 전투 스폰(풀 Pop) 시 해당 종족의 현재 강화 레벨로 1회 적용. 풀 재사용 리셋 규칙 준수(OnEnable에서 상태 리셋 — Rule 03 §4).
- 강화 메뉴 카드도 같은 발광 세기로 **미리보기**(현재 Lv 및 다음 Lv 힌트).

### 4.4 UI — 상점 2탭
- `ShopPopup`에 탭 전환 UI 추가: **「스탯 강화」** / **「몬스터 강화」**.
  - 「스탯 강화」 = 기존 글로벌 항목(`MonsterStat` / `SpawnerPeriod`)만 노출.
  - 「몬스터 강화」 = `MonsterSpecies` 항목(6종족)만 노출.
- 항목 필터는 `EffectKind` 기준. 기존 `ShopItemPoolingScrollView`/`ShopItemCell`은 재사용하되, 셀이 종족 강화(발광 미리보기·종족 아이콘)를 표현하도록 확장하거나 종족 전용 셀을 둔다 — 세부는 기획서/plan이 확정.
- `CHPoolingScrollView` 사용 시 BuildModal 패턴(정적 prefab + 인스펙터 참조) 준수(Rule 03 §3).

## 5. 경제 / 밸런스 (game-designer 기획서가 확정)

- **통화**: 소울 — 기존 상점과 동일 지갑.
- **가격**: 기존 공식 `BasePrice × PriceGrowth^level`(`ShopService.PriceOf`) 재사용. 종족별 `BasePrice`/`PriceGrowth`는 기획서 값.
- **배수 곡선**: 종족별 Lv1~5 HP·공격력 배수. 보스 variant 곡선(1.0 / 1.25 / 1.55 / 1.9 / 2.3 류)을 참고 기준선으로.
- **발광 세기 5단계**: Lv1~5 발광 강도·아웃라인 세기.
- 밸런스가 게임플레이에 크게 영향 → 구현 후 qa-simulator 별도 호출을 마무리에서 제안한다.

## 6. 테스트 관점 (test-engineer 확정)

- `MetaBattleBonus.From()` — `MonsterSpecies` 항목이 종족별 배수로 정확히 집계되는가(레벨 0/1/5/만렙클램프, 미등록 종족은 1.0).
- 3축 곱연산 독립성 — 기본 × 글로벌 × 종족이 곱으로 맞물리는가.
- `ShopService` — 종족 항목 구매/가격/만렙/소울부족 경로가 기존 항목과 동일하게 동작.
- 세이브 하위호환 — 구버전 프로필(종족 강화 엔트리 없음)은 전부 Lv0으로 로드.
- 시각은 PlayMode에서 레벨별 발광 적용/풀 재사용 리셋 검증(가능 범위).

## 7. 열린 결정 (기획서가 닫는다)

- HP·공격력을 단일 배수로 볼지 각각 분리할지 (기본안: 단일).
- 종족 강화 셀을 기존 `ShopItemCell` 확장으로 할지 종족 전용 셀 신설로 할지.
- 발광 세기 표현을 emission intensity 단일 축으로 할지 outline까지 병행할지.
